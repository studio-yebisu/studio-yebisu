      デモを初期状態に戻しますか？

      このデモで追加・編集した内容が消え、4件のサンプルに戻ります。

      このデモについて

      複数の制作と、その次のタスクを整理する操作サンプルです。実際のプロジェクト・サービスには接続していません。

      1. 制作を選ぶと、詳細とタスクが開きます。
      2. 状態・優先度を変えたり、タスクの完了をチェックできます。
      3. 右上から新しい制作を追加できます。

      保存について

      入力内容は、このブラウザのlocalStorageに保存します。他端末との同期や外部への送信はありません。ブラウザのデータを消すと保存内容も消えます。

      試したあと

      「デモを初期状態に戻す」で、サンプルだけをリセットできます。このデモ以外のブラウザデータには触れません。

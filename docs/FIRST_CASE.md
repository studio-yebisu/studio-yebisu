# 最初の一件：ひと言を、作れる依頼に。

制作対象は `data/cases/brief-to-demo.json`。入力は、イベント受付のUI、書店の読書会スライド、新機能の説明動画という3つの短い依頼です。

`brief-to-demo` を読み、利用者・目的・素材・制作スキル・成果物・完成条件を持つJSONへ具体化します。Opus 5.5がブリーフ、操作できる作例、説明動画のコード、統合サイトの画面を担当します。統合側はカタログの取得、掲載データ、描画と動画出力、実際の動作確認と公開を担当します。

制作・描画・公開の確定結果は `data/production/brief-to-demo.json` に記録します。ソース生成の成功、技術確認、画面・映像の確認、公開URLの確認を区別します。

説明動画は日本語字幕で流れを示す、音声なしの28秒です。音楽・ナレーションは制作範囲に含めません。

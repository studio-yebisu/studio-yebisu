# Yaoyorozu-AI Toolbox

サイトの表示名は **Yaoyorozu-AI Toolbox**。日本語の添え名は **やおよろずのAI道具箱**、サイトの案内は「作例から、AIの道具を選ぶ。」とします。表示名の正本は `data/projects.json` の `title` です。

2026-10-21の改名は、トップ、記事、カタログ、同梱ガイドと作例ページの表示が対象です。GitHubの組織・リポジトリ・公開URL、ローカルのフォルダー名とスキルIDは維持します。

原典の作者名、著作権表示、固定した入力・実行結果・制作記録、動画と画像に含まれる制作当時の表記は保ちます。画面の文言を変更した作例は `data/production/` の `display_revisions` に変更前後のハッシュと範囲を記録し、元のモデル実行や動作検証をやり直したことにはしません。

`scripts/sync_catalog.py` は同梱する専門ガイドの表示に `scripts/branding.py` を適用します。元のリポジトリの内容を変更せず、同期で旧サイト名に戻ることを防ぎます。

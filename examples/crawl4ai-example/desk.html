取り出し方と設定を見る

3ページとも同じ設定で crawler.arun() を1回ずつ呼びました。何を手がかりに取り出したかは、次の4つのセレクターだけです。

  1. 本文を絞る

    css_selector="main#guide"

    Markdown の元にするのは main#guide の中だけ。excluded_tags=["nav", "footer"] でナビとフッターも除きます。

  2. JavaScript を待つ

    wait_for='css:#guide[data-ready="true"]'

    書き出しページは、最後の節をページの JavaScript が後から足します。足し終えた印が付くまで待ってから読みます。

  3. 節ごとに取り出す

    baseSelector="article.doc-section"

    各節の h2 を heading、p.keypoint を keypoint に。JsonCssExtractionStrategy は JavaScript 実行後のページ全体からこの節を探します。

  4. 分けて保存する

    success かつ HTTP 200

    両方を満たしたページだけを受理。存在しないページへの診断は 404 として別に記録し、成功には数えません。

手元で実行し直す

このページから実行はできません。結果を作り直すときは、Python 3.10 以上と、インストール済みの Google Chrome を使い、この作例のフォルダで次を順に実行します。APIキーやアカウントは不要です。

  1. 新しい仮想環境を作って有効にする

    python -m venv .venv-crawl4ai

    有効化：Windows（PowerShell）は .venv-crawl4ai\Scripts\Activate.ps1、macOS・Linux は source .venv-crawl4ai/bin/activate

  2. 固定版の Crawl4AI を入れる

    python -m pip install https://github.com/unclecode/crawl4ai/archive/6192d5e5b59cb21f9ca418fd6b798de47c0741d3.zip

  3. 作例のフォルダの外にある、新しい空のフォルダを指定して実行する

    python workflow.py --work ../crawl4ai-run-1 --channel chrome

    すべての確認が通ると、指定したフォルダの publish/ に outputs/runs.json・outputs/result.md・samples.json ができます。このフォルダの同じ場所へ写してから、次の手順で開きます。

  4. このページを開く

    python -m http.server 8000

    ブラウザで http://127.0.0.1:8000/ を開きます。file:// で直接開くと JSON を読み込めません。

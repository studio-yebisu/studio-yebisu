# Diagram Design 紹介映像（32秒・無音）のソース

`index.html` は編集用のページ、`video.js` が映像の本体です。canvasだけで描き、音声・読み上げ・字幕・音声ファイルはありません。

紹介ページ（`../index.html`）と同じ `../concept.js?v=visual-r1` のレイアウトと描画関数を使い、1つのつながった図をカメラで寄り引きします。

1. 指針の本（6つの見出し）
2. 依頼（3担当の帯）
3. AIが執筆
4. HTML（SVG入り）
5. 制作担当（点検）
6. HTML・SVG・PNG
7. 実際の図
8. 開く・編集

## 形式

| 項目 | 値 |
| --- | --- |
| 長さ | 32秒（30fps・960フレーム） |
| 縦（優先） | 720×1280 |
| 横 | 1280×720 |
| 動きの終わり | 28.9秒。28.9〜32秒は同じ静止画 |
| ポスター | 31秒 |
| 音 | なし（`audioEvents: []`） |

縦と横は、同じ時間割のまま、配置を縦用・横用に別々に組んでいます（`portraitLayout` / `wideLayout`）。

## 場面

| 秒 | 見出し | 画面で起きること |
| --- | --- | --- |
| 0–4 | 関係を読み、図の形を選ぶ | 本が開き、6つの見出しが順に出る。手順書・参照・ひな形・補助の印 |
| 4–8 | 指針＋依頼 → AI | 依頼の3担当の帯、分岐と戻りの印、目的・不足・戻り・完了の印。本のページと帯がAIへ合流 |
| 8–14 | AIが形を選び、HTMLに描く | 「スイムレーン」の札（下に45種類から1つの格子）。同じ帯がHTMLの段に広がり、9工程と破線の戻り2本 |
| 14–20 | AIが執筆 / 制作担当が実行 | 補助の印が制作担当へ移る。点検の印、12条件の照合は別の注記。HTMLは正本のまま、SVG（export_svg.py）とPNG（ブラウザー撮影）へ分岐 |
| 20–26 | 実際の図：戻り道と完了 | 保存済みの intake.png が大きく出る。帯がPNGの段にそろい、E04、E10、E09→R5 を記録の座標で重ねる |
| 26–29 | 開く・編集に使う | 図が出力の枠へ戻る。3つの札と「開く・編集」がつながる。ファイルの大きさを表示 |
| 29–32 | 指針＋依頼 → AIが図を書く → 確認・書出し → 使う | 全体図の静止画 |

場面の移動ボタン（`data-jump`）は 0・4・8・14・20・26・29 秒です。詳しい入出の状態は `storyboard.json` にあります。

## 素材と照合

- `../concept/manifest.json` を読み、SHA-256 が `fc782021a55f03dec70a20fdfbd01d743ac55d19ae0b188889a803f012f8e201` と一致することを確かめます。
- 目録の27ファイルについて、組・大きさ・SHA-256を照合します。
- 照合する中身は次のとおりです。
  - 原典の引用6行（CRLF/LFどちらでも行で照合）
  - 固定コミット・MIT・同梱の第三者ライセンス表記
  - 工程9・矢印10・段3、段をまたぐ矢印8・戻り2・朱2
  - 依頼の断片18・業務の事実12・解釈4
  - 経路4件（並び・中身・記録ファイル）
  - HTML/SVGの工程・矢印ID、viewBox 1280×720
  - PNGの2560×1440
- HTMLとSVGは DOMParser で構造だけを読みます。実行も埋め込みもしません。
- 画面の実際の図は、照合したPNGのバイトを `blob:` URL の画像として表示します。描き直したSVGや新しい書き出しは使いません。
- どれかが合わないと `motionReady` は拒否され、代わりの図は描きません。操作は「もう一度読み込む」だけが使えます。

元の作例の照合を再利用しているだけで、このページで検査スクリプトを新しく実行したことにはなりません。ブラウザーがPythonを呼ぶこともありません。

## 時間の契約（Motion Reel）

- `window.motionConfig = {duration: 32, fps, width, height, posterTime: 31, audioEvents: []}`
  - `window.renderConfig` の幅・高さ・fpsがあればそれを使います。幅が高さ以上なら横、それ以外は縦の配置です。
- `window.seek(t)` は t だけから1枚を作ります。呼ぶ順番、壁時計、前のフレームには依存しません。各フレームで `save`/`restore` を行い、フレームごとの通信や音はありません。
- `window.motionReady` は、フォント、27ファイルの照合、PNGの復号が済むと解決します。
- `window.__MOTION_RENDER__` が真のときは、プレビューの再生（requestAnimationFrame）を止めます。
- `?render` または `__MOTION_RENDER__` のときは、操作パネルを隠してcanvasだけを表示します。
- 向きを変えられるのは `button[data-orient]` だけです。`?orient=wide` で横から開くこともできます。

## 範囲

- 動く紙・帯・札は説明用の図解です。AI・検査・書出し・撮影を再実行したものではありません。
- 原典の図に新しいアニメーションは加えていません。原典の template-motion の仕組みも使っていません。
- 経路は架空の手順として描いたもので、実際の問い合わせを処理した記録ではありません。
- 6つの見出しは説明のための整理で、原典の形式ではありません。
- 旧映像の `legacy.html` と `scene.js` はそのまま残しています。

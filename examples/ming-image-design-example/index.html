    実行の範囲と、まだ確かめていないこと

    何を動かし、何を動かしていないか
    • 動いたのは、原典READMEのDemoリンク（hugging-apps/…）から移った公開Space inclusionAI/ming-image-0-1-design-demo @367085c です。実行のbuildは送信の前後で同じでした。中身は独自のMingImagePipeline（vLLM-Omni PR #8021に準拠）で、原典のinfer.py・CLI・ローカルのモデルは動かしていません。
    • 送信は制作担当が標準ライブラリだけのクライアントで匿名に1回。Authorization・HFトークン・Cookie・アカウント・クレジット・課金はありません。自動の再試行・選び直し・seedの変更・promptの拡張・後からの修正もしていません。
    • Layer（レイヤー分解）・編集・PPT・Design Skillなどの別の手順、ComfyUI、手元のGPUは使っていません。手元の環境も変えていません。
    • ブラウザーは保存済みのファイルを照合して表示・保存するだけで、モデルの実行やAPIの呼び出しはしません。
    版と出典
    • 原典：inclusionAI/Ming-Image @3515cd7（MIT）。選んだ6ファイルを原文のまま vendor/ming/ に同梱しています。
    • 実際の経路：公開Space @367085c。ソースは非公開で読んで確かめただけで、一般的な再配布の条件が見つからないため同梱もMITへの付け替えもしていません。
    • モデルのHubメタデータ：inclusionAI/Ming-Image-0.1-Design @c57c496（公開・ゲートなし・MIT）は送信の前後で同じでした。ただしSpaceのローダーはrevisionを指定していないため、サーバーが実際に読み込んだ重みの版は確認できません。
    • Spaceの説明文には「原典は非公開」「透過の合図の語は未公開」とありますが、固定した原典は読めて語も載っています。古い記述として採用していません。
    • 無料の枠：ZeroGPUの公式説明の現行の記載では、匿名の目安は1日2分、xlargeは2倍の消費です。空きや残りの枠は保証されません。ハードのラベル zero-a10g とアプリの xlarge 指定は観察で、実際に割り当てられたGPUは測っていません。
    まだ確かめていないこと
    • 字形：会場の「図」が「圖」のような字形に見え、原稿との一致は確かめられていません。ほかの3つも目で読めるという記録で、文字コードの一致や組版の品質の保証ではありません。
    • α：透明な画素は0、半透明が90,578画素あります。依頼した完全に不透明な背景にはなっていません。
    • 時間：サーバーの「9.9s」はサーバーの申告で、14.941秒・20.532秒はキューと通信を含む手元の時計です。内部の各段の時間は測っていません。
    • 品質・自然さ・印刷適性・権利・独自性・性能・人の審美的な承認、ほかの入力での振る舞いは確かめていません。実際のイベントに使う前には、人が文字・日付・会場と透過を確かめてください。
    • この新しいページと編集用ソース・32秒の無音動画は、作者の執筆の後に制作担当が表示・描画して確かめる段階で、まだ確認済みではありません。実機のiOS・Safari・VoiceOver・200%拡大も未確認です。

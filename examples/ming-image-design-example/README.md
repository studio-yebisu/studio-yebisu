# Ming Image 0.1 Design 作例：架空の読書会のポスター

Ming Image 0.1 Design は、UI・ポスター・図解のような文字の多い絵を作る**画像生成モデル**と、手元で動かすPythonの手順です。SKILL.md・チャットAIのチーム・ホスト型の製品・編集できるデザイン形式ではありません。

この作例では、原典READMEが案内する**無料の公開デモ（Hugging Face Space）へ匿名で1回だけ**依頼を送り、返ってきた**実際のPNG 1枚**を保存しました。ページはその1枚と記録を使い、モデルの中の流れ（1回読む→2本の条件→ノイズから12回→4チャンネルのVAE）を1枚の構造図で見せます。

## 開き方

照合にSHA-256を使うため、https か localhost で開きます。たとえばこのフォルダで次を実行し、`http://localhost:8000/` を開きます。

```bash
python -m http.server 8000
```

ページを開くと、`concept/manifest.json` を固定のSHA-256と照合し、そこに載った20ファイルの大きさとSHA-256、原典6か所の引用と同梱ファイルの該当行、依頼・送った文・記録・PNGのヘッダー・αの数え方・文字の読合せの関係を確かめてから表示します。1つでも合わなければ、画像・保存・リンクを止めて理由と「もう一度確かめる」を出します。秘密の値や鍵はどこにもありません。

## 読み方

- **①何か・②渡す・③返る**：同じ1枚の図の強調が変わります。図の線・枠・道の名前は、実際に動いた公開デモのソースに基づく説明です。内部の値・途中の画像・各段の時間を測ったものではありません。
- **数字の四角（1〜6）**：説明のための6つのまとまりです。公式の区分でも、6体のAIでもありません。下の「6つのまとまり」で、原典（固定版 3515cd7）の該当行と、実際に動いた公開デモの参照を開けます。原典の引用は参照で、実行の証拠ではありません。
- **作者AIとthinkerは別物**：作者AI（Claude Opus 5.5・1体）はpromptとクライアントを書いただけです。thinker（BailingMoE-v2）はモデルの部品です。
- **結果**：実際のPNGを拡大し、背景を白・緑・市松で見比べられます。見え方だけが変わり、PNGのバイトは変わりません。新しい生成もしません。

## 結果について、正直に

- 見出し「こもれび読書会」・日時・注記「架空のイベント」は目で読めます。**会場「小箱図書室」の「図」は「圖」のような字形に見え、原稿との一致は確かめられていません（会場の字形は要確認）**。画像から文字コードは決められず、OCRや人の承認もしていません。
- **透明画素は0。半透明が残ります**（α 216〜255、半透明 90,578 画素）。依頼した完全に不透明な紙の背景にはなっていません。RGBAの形式は、透明な背景や編集レイヤーの証明ではありません。
- サーバーの「9.9s」はサーバーの申告です。14.941秒・20.532秒はキュー・GPUの割り当て・通信を含む手元の時計です。
- PNGは修正・再生成・選び直し・トリミング・色の補正をしていません。実際のイベントに転用する前や印刷の前には、人が文字・日付・会場と透過を確かめてください。

## 同じ経路を試すとき（再現）

`run_example.py` は、**この1枚のポスターの依頼を、今の公開デモのbuildに対してだけ**送る匿名クライアントです。どんな依頼にも使える汎用のクライアントではありません。標準ライブラリだけで動き、送る前にSpaceのbuild（`367085c…`）・状態・`/generate` の引数と戻り値の形を照合し、どれかが違えば送らずに止まります。

```bash
python run_example.py --request inputs/request.json --output <新しい空の公開用フォルダ> --private <新しい空の非公開フォルダ>
```

- 出力先は毎回、新しい空のフォルダを使います。この作例の `outputs/` を上書きしないでください。
- 通信・待ち行列・無料枠・buildの変更・認証の要求で失敗したら、POSTを送り直さずに止まります。再現できたように見せるために照合の条件を書き換えないでください。
- 時間切れのときは、残った event id で `--resume-event <event id>` を付けると、**すでに送った依頼の結果の流れを読み直すだけ**です（もう一度POSTはしません）。
- 実行すると無料のZeroGPUの枠を消費します。[公式の説明](https://huggingface.co/docs/hub/spaces-zerogpu)の現行の記載では、匿名の目安は1日2分、xlargeは2倍の消費です。空きや残りの枠は保証されません。トークンを使った認証や有料の経路は使いません。
- サーバーが読み込む重みが変わっている可能性があり、同じseedでも**同じ画像になる保証はありません**。

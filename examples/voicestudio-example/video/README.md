# VoiceStudio の流れ（無音・32秒）編集用ソース

作例ページと同じ図を、7つの場面で動かす無音のフィルムです。公開の手順書（SKILL.md）と依頼が、作者AIのクライアント、担当者が実行した原典CLI、手元の VoiceStudio API、別の認識モデルを順に通り、同じ波形が2つの推定区間と実際の JSON・TXT になります。参照文は送らず、最後に文字どおり比べます。

ナレーション・音声トラック・効果音はありません。入力の WAV は作例ページ（`../index.html`）の再生ボタンだけで聞きます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 編集画面。縦横の切り替え、時刻のスライダー、場面へ移動、再生・一時停止・最初から・最初へ・最後へ、確かめる31ファイルの一覧 |
| `video.js` | 時刻の契約（`motionConfig`・`motionReady`・`seek`）とプレビューの再生。`<head>` の同期スクリプトで、描画は `../concept.js` を読み込んで使う |
| `video.css` | 編集画面と、書き出し時（`html.is-render`）の余白なしの表示 |
| `storyboard.json` | 7場面それぞれの秒・伝えること・入る状態・出る状態・動き |
| `../concept.js` | 作例ページと共通の読み込み・検証・場面・描画（`loadData`・`sceneAt`・`drawConcept`・`layoutConcept`・`SCENES`） |

## 時刻の契約

- `window.motionConfig = {duration: 32, fps: 30, width: 720, height: 1280, posterTime: 31, audioEvents: []}`。初期化の前に `window.renderConfig` の `width`・`height`・`fps` があればそれを使い、`motionConfig` にも同じ値を入れます。幅が高さより大きければ横の配置で描きます。`?orient=wide` でも横（1280×720）で開けます。
- `window.motionReady` は、フォントの準備と31ファイルの大きさ・SHA-256・中身（facts の形、3件の ID と出力のバイト数、6つの部品の原典の行、WAV の形、包絡の連続）の確認が終わると解決し、どれかが失敗すると reject します。失敗したら canvas を消し、時刻の操作を止め、「もう一度確かめる」で読み込み直します（新しい `motionReady` になります）。古い読み込みの結果は世代の番号で捨てます。
- `window.seek(seconds)` は Promise を返し、0〜32秒の任意の時刻を、その時刻だけから描きます。呼ぶ順番・壁時計・前のコマ・乱数・CSS アニメーションには依存しません（`sceneAt` は閉じた式）。30〜32秒は形も文字も止まり、ポスターは31秒です。
- `window.__MOTION_RENDER__` が真なら、操作の欄を出さず、プレビューの再生（requestAnimationFrame）を動かしません。`#film` の canvas だけを要求された大きさのまま、余白とスクロールバーなしで左上に置きます。書き出しは常に明るい色で描きます。
- 音声の要素・スクリプト・効果音はありません。`audioEvents` は空です。

## 描くもの

- 波形は `concept/waveforms.json`（実際の入力 WAV の PCM16 を240の連続した区間に分けた min/max）です。ランダムな波形や作ったメルスペクトログラムは使いません。
- 区間の境目・秒数・JSON と TXT のバイト数・全文・照合の結果は `outputs/attempt-01/` の保存された返答から描きます。フィルムの流れは default を使い、最後の場面で3件の結果を並べます。
- 場面の秒数と動きは説明の演出で、実際の処理時間ではありません。デコード・リサンプル・VAD・特徴量・モデルの内部は描かず、測ってもいません。

## ローカルで開く

作例フォルダー全体（`index.html` と `concept/`・`inputs/`・`outputs/`・`vendor/` がある階層）を、ローカルの静的 Web サーバーで配信して `video/index.html` を開きます。`file://` では読み込みが止まります。例：

```sh
cd <作例フォルダー>
python -m http.server 8000 --bind 127.0.0.1
# http://127.0.0.1:8000/video/index.html
# http://127.0.0.1:8000/video/index.html?orient=wide
```

外部への通信・モデル・API キーは使いません。読むのは同じフォルダーのファイルだけです。

## 書き出し（制作担当の別工程）

Motion Reel のレンダラーなど、上の契約に従う書き出し器で、縦 720×1280 と横 1280×720 をそれぞれ30fps・32秒・音声なしで書き出します。MP4・ポスター・連続コマの確認と、その記録（`../visual-verification.json`）は制作担当が別に行います。この README を書いた時点では、ブラウザーでの表示・任意時刻・書き出し・MP4 の確認はまだ行っていません。人による見た目の承認とも別です。


## 制作担当の確認と再描画（作者の受領後）

制作担当は別工程で、320/375px全18組・6部品13引用・16表示条件・3破損復旧、3入力WAVの終端と6区間シーク、9保存要求と返却9ファイル全bytes、31素材編集と任意7.2秒、代表/連続コマ、縦横32秒無音MP4の終端、出荷ソース62PNG一致を確認しました。人の試聴・意味/時刻の精度・審美的承認・実機iOSは未確認です。

転記の誤りを、そのまま直せる。28秒・無音の解説動画

作例用の原稿を手元の音声合成で読み上げた音声1本を、固定版の Whisper（base・CPU）で制作時に1回だけ転記した実際の原出力から、原稿を参照して3区間の文を手で直し、時刻はそのまま SRT で保存するまでを、実画面の静止キャプチャと実際の記録で組み直した映像です。続けて録画したものではなく、音声を聞いて確かめた校正でもありません。

自動では再生しません。スライダーでは ← → で0.1秒、PageUp・PageDown で2秒ずつ、Home・End で先頭・末尾へ移ります。

実入力・出力と画面を読み込んでいます…

場面

  1. 0〜4秒 入力：作例用の原稿を読み上げた合成音声（21.01秒・16kHz・モノラル）と、WAV から求めた0.1秒ごとの RMS。
  2. 4〜8秒 実際の原出力：保存済みの5区間の一覧と、工房名が原稿と違う文字になった id 0。
  3. 8〜15.5秒 原稿を参照して手で直す：id 0 の原出力・読み上げた原稿・直した字幕。編集前と後の実画面。
  4. 15.5〜20秒 直したのは3区間。5区間の時刻は推定値のまま。聞いての確認は未実施。
  5. 20〜24秒 ブラウザーが保存した SRT の最初と最後の区間（実ファイルの抜粋）。
  6. 24〜28秒 スマホ幅の初期画面と、試す順番「音声を開く → 文を直す → SRTで保存」。

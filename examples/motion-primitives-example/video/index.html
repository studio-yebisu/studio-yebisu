探して、ひとつ開く。28秒の解説動画の元ページ

6件の架空の手順書を「書き出し」で2件に絞り、原典の Accordion で1件を開いて切り替え、動きを抑えても同じ本文が残り、その状態を JSON で保存するまでを、実画面のキャプチャと実際の記録から組み直した無音の映像です。続けて録画したものではありません。

0.0秒 / 28.0秒

画面か本文にフォーカスがあるとき：Space で再生／一時停止、Home・End で先頭・末尾、PageUp・PageDown で2秒ずつ移動。スライダーでは ← → で0.1秒ずつ動きます。

素材を読み込んでいます…

場面

  1. 0〜4秒 依頼と、6件の手順書。最初の実画面（スマホ幅）。
  2. 4〜8秒 「書き出し」で検索すると、6件が2件に。
  3. 8〜14秒 原典の Accordion で PDF の1件だけを開く（expandedValue = "export-pdf"）。
  4. 14〜18秒 画像の見出しを押すと、開く1件が切り替わる。
  5. 18〜23秒 通常・ページの設定・OS の設定（CDPで模擬）で、同じ2段落。0秒は設定値です。
  6. 23〜28秒 保存した JSON の抜粋と、試す順番「検索 → 開閉 → JSON保存」。

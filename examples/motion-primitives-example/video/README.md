# Motion Primitives — 32秒・無音の図解動画のソース

紹介ページ（`../index.html`）と同じ構造図を、時刻を指定して描く編集用のソースです。`index.html` を開くとブラウザーの中で映像を描き、好きな秒へ移動できます。音声・ナレーション・効果音はなく、音源や原稿も同梱していません。

伝えることは1つです。**原典の部品ソースがブラウザーの中で入れ子の部品になり、開く1件は App が持ち、押した button の id が App へ戻って、同じ本文の紙が開く・切り替わる・閉じる。動きを抑えても同じ文が残る。**

## これは何の作例か

- Motion Primitives（ibelick/motion-primitives、固定コミット `120f64f6ca60348e251f929e9c81f11ccbe45eda`、MIT License, Copyright (c) 2024 ibelick、ベータ）は、motion と Tailwind CSS で作られた React のアニメーション付きUI部品集です。Agent Skill の指示書・モデル・推論API・検索サービスではありません。
- 元の作例は npm パッケージを入れず、原典の Manual に沿って `components/core/accordion.tsx` と `lib/utils.ts` を写し、読み込み先と id・aria の受け渡しだけを加えて（`../vendor/motion-primitives/accordion-adapter.patch`）、実際の React 18.3.1 と motion 11.12.0 で動かしました。
- 手順書6件は架空のアプリ「しおり工房」のものです。本文にある PDF・画像の書き出しは実行していません。

## 開き方

`crypto.subtle` で SHA-256 を確かめるため、HTTPS か localhost で開きます（例：作例のフォルダーで `python -m http.server 8861 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8861/video/` を開く）。`file://` では読み込みを止めます。

開くたびに `../concept/manifest.json` の SHA-256（固定値）と、そこに並ぶ22件の大きさ・SHA-256・中身（原典7ファイルの固定版、6つの引用の行、15状態と12の入出力例、検索の規則と保存した結果、元の実JSON、実画面4枚の PNG 寸法）を確かめます。合わないときは図を描かず、理由と「もう一度読み込む」を出します。読み込めた件数と4枚の寸法は `#asset-status`・`#asset-dims` に出ます。

## 時間の契約

- `window.seek(t)`：時刻 t（0〜32秒）の完成した画面を、t だけから描きます。呼ぶ順番に関係なく同じ画になり、0 と 32 の境界も同じ扱いです。Promise を返します。
- `window.motionReady`：22件の照合、照合済みのバイトからの `pdf.png` の復号、`document.fonts.ready` の後に解決します。
- `window.motionConfig`：`{duration: 32, fps: 30, width, height, posterTime: 31, audioEvents: []}`。
- `window.renderConfig` の `width`・`height`・`fps` を初期化時に反映します。向きは縦横比で決まります。
- `window.__MOTION_RENDER__`（または `?render`）のときは編集用の操作を隠し、プレビューのタイマーを動かしません。
- 毎フレーム canvas を save/restore して全体を描き直します。前のフレームの積み重ね、`Math.random`、壁時計、動作中の CSS アニメーションを出力に使いません。

## 2つのネイティブな配置

- **縦長 720×1280**（最初に作った主の向き）：論理360×640。紹介ページと同じ縦の並びを、余白と本文の行数を増やした `tall` 配置で描きます。地図の下に色の凡例、最後に元の `pdf.png` の切り抜き。
- **横長 1280×720**：論理640×360。左に作者AIと制作担当の列と凡例、中央にブラウザーの入れ子、右に実操作記録・元の画面（desk.html）・元の実JSON。切り抜きは元の画面の箱の中に出ます。

どちらも同じ時刻表・同じ状態から描き、縦長を縮めて横に並べたものではありません。図の文字は論理11px（出力で22px）以上です。

## 場面

| 時刻 | 場面 | 何が動くか |
| :-- | :-- | :-- |
| 0〜4秒 | Reactの動く部品集から、1つ | accordion.tsx の設計図（Accordion › Provider › Item › Trigger／Content）が縮んで「原典部品」の箱になる |
| 4〜8秒 | 作者AIが書き、制作担当が確かめる | 原典部品＋依頼文＋架空6件 → 作者AI → 画面と部品 → 制作担当（型検査・ビルド・実操作）→ 青い紙がブラウザーの中の Accordion の箱へ広がる |
| 8〜14秒 | 写した部品の入れ子 | 外側から順に輪（App、Accordion、Provider、Item、本文）。入力しただけでは6件（記録2）、検索ボタンで2件（記録3） |
| 14〜20秒 | 押すと、idがAppへ戻る | PDF を押す（記録4）→ 画像へ切替（記録5）→ 同じ画像で閉じる（記録6）。毎回、朱の粒が上の道で App の状態へ、黒の粒が下りて紙が動く |
| 20〜26秒 | 動きを抑えても、同じ本文 | ページ設定で設定0秒、紙がすぐ開く（記録12）。OS 設定（CDP 模擬）でも0秒・同じ文（記録13） |
| 26〜29秒 | 元の実JSONと、実部品 | App から元の実JSON（2529B）へ緑の粒、実操作記録と元の画面に輪、元の実画面の切り抜き。28.5秒で動きが終わる |
| 29〜32秒 | 全体 | 完成した図を静止して保持（記録12と同じ状態） |

編集画面の7つの移動ボタンは 0・4・8・14・20・26・29 秒です。

## 記録と役割

- **描く状態**：元の制作で制作担当が実ブラウザーで記録した15状態（`../concept/original-run.json` と `../outputs/operations.json`、同じ内容）のうち、記録1〜6・12・13 を使います。状態と状態の間の動きは説明のための補間です。部品そのものの実行、連続した画面録画、開閉速度の計測ではありません。開閉は見やすいよう遅く描いています。0.18秒・easeOut と 0秒は元の App の設定値です。
- **元の作者AI**：固定した原典、依頼文、架空の手順書6件を読み、`src/app.tsx`・`src/accordion.tsx` の adapter・以前の28秒の動画ソースを書きました。シェルは実行していません。
- **制作担当**：型検査・esbuild のビルド・実ブラウザーでの15の操作と記録、12の入出力例、実JSONの確認を行いました。OS の動きを減らす設定は Chrome の CDP で模擬しました。
- **このソース**：visual-r1 の改修で、保存した記録から書いた図と動画のソースです。中でモデル・ビルド・元の確認を動かしません。実部品は `../desk.html` で今も動きます。
- **実画面**：`../video/assets/pdf.png` は元の確認で撮ったローカル Chromium の画面です。最後に補足の証拠として小さく切り抜くだけで、映像の主役ではありません。

## まだ確かめていないこと

このファイルを書いた段階では、ファイルの読み書きだけを使いました。ブラウザーでの表示、`window.seek` の任意順での一致、書き出し、コンタクトシートやフレームのレビュー、MP4 の再生、紹介ページの 375×812・320px での実測は**まだ行っていません**。これらは親の制作工程が行い、実際の結果をこの README と記録へ追記します。元の確認でも、実機の iOS/Safari、VoiceOver、ブラウザーの200%拡大、人による見た目の承認は行っていません。

## 書き出しについて

同梱の `../render.py` は、現在 `video/legacy.html`（以前の28秒）を入口にしています。保護されたファイルのためこの改修では変更していません。新しい32秒の映像は、親の工程が `video/index.html` を入口にして縦長（720×1280）と横長（1280×720）を別々に、音声なしで書き出します。出力先は空の専用フォルダーを使い、既存の書き出しを上書きしません。紹介ページの `<video>` は `../../media/motion-primitives-example.mp4` と `-wide.mp4` を指しています。ポスター画像は書き出し後に親の工程で付けられるよう、指定していません。

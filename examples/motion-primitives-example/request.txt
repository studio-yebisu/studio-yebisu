Motion Primitives（ibelick/motion-primitives 固定コミット 120f64f6ca60348e251f929e9c81f11ccbe45eda）の Accordion を使い、小さな検索ヘルプ画面に「検索結果を開いた場所が分かる小さな動き」を付けてください。検索や操作の邪魔をせず、動きを減らしても同じ文を読めることが条件です。

入力：作例用に書いた架空のアプリ「しおり工房」の手順書6件（input/articles.json）。「書き出し」を含むのは「PDFを書き出す」と「画像を書き出す」の2件だけにします。

部品：components/core/accordion.tsx と lib/utils.ts を写し、読み込み先の変更と、ボタン・パネルに id と aria 属性を渡す最小限の追加だけにする。npm パッケージとしては入れない。開く1件は Accordion の expandedValue と onValueChange でアプリ側の状態として持つ。React 18.3.1・motion 11.12.0 などの版を固定し、esbuild で1つのスクリプトにまとめる。

画面：スマホ幅を基準に、検索欄と結果を最初に見せる。入力欄は16px以上、ボタンとリンクは44px以上。「検索」を押したときだけ結果を絞り、開いていた結果は閉じる。0件のときは全件に戻す操作を出す。見出しのボタンは aria-expanded と aria-controls を持ち、パネルは見出しで名前の付いた region にする。↑↓・Home・End で見出しの間を移動できる。

動き：OSの「動きを減らす」設定か、ページの「動きを抑える」がオンなら開閉を0秒にし、文と操作は変えない。

記録：今の検索語・一致したid・開いたid・動きの設定・表示中の手順書をJSONで保存できるようにする。原典と改変点、ビルドとブラウザーで実際にした操作、未確認の点を残し、約28秒の無音で編集できる動画を作る。

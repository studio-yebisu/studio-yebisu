# 検索結果を、小さく開く

架空の6件の手順書を、ブラウザー内のReact画面で検索しました。AIや検索サーバーは呼んでいません。

1. 「書き出し」を検索すると、PDFと画像の2件。
2. PDFを開く→画像へ切替→同じ見出しで閉じる。原典のAccordion/AnimatePresence/motion.divを実行し、一度に開くのは1件。
3. 全角「ＰＤＦ」はPDF1件、「書き出し PNG」は画像1件、存在しない語は0件。リセットで6件へ。
4. 手動の「動きを抑える」と、CDPで模擬したOSのreduce設定では、どちらも開閉時間を0にして同じ2段落を表示。実機iOSの設定を確認した結果ではありません。
5. 表示をJSON保存し、検索語・一致ID・開いたID・設定・本文が実画面と元入力に一致。
6. QAサーバーで入力JSONだけHTTP503にするとエラーになり、偽の結果は表示せず、解除後に再試行すると6件に復帰。

実際の入力と出力は samples.json と outputs/operations.json。デコードや自動照合は人の見た目の承認を意味しません。

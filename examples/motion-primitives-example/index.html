Motion Primitives

Reactの動く部品集。Accordionを1つ写し、Appの状態で開閉する

実部品を動かす

これは何か

Motion Primitives は、motion（旧 Framer Motion）と Tailwind CSS で作られた、React のアニメーション付きUI部品集です。原典はベータとされています。Agent Skill の Markdown 指示書でも、モデルや推論API、検索サービスでもありません。この作例は motion-primitives という npm パッケージを入れず、原典の説明（Manual）どおり Accordion のソース（components/core/accordion.tsx と lib/utils.ts）を1つ写し、読み込み先の変更と、ボタン・パネルへ id と aria 属性を渡す最小限の adapter だけを加えて、実際の React 画面で motion/react を動かしました。

図の流れ

  1. 写して書く　固定版の部品ソース、依頼文、作例用に書いた架空の手順書6件を、元の制作で1つの作者AI（Claude Opus 5.5）が読み、React の画面（src/app.tsx）と最小 adapter 付きの部品（src/accordion.tsx）、旧28秒動画のソースを書きました。AIはシェルを実行していません。型検査・ビルド（esbuild）と、実ブラウザーでの操作と記録は、制作担当が別の工程で行いました。
  2. 入れ子　実行時は App が開く1件の状態を持ち、Accordion に expandedValue・onValueChange・transition を渡します。Accordion の中では MotionConfig が transition を配り、Provider が開いている値と toggleItem を子へ共有します。各 AccordionItem は手順書の id を value に持ち、AccordionTrigger は本物の button、AccordionContent は AnimatePresence と motion.div で高さと透明度を切り替えます。
  3. 押して戻る　button を押すと toggleItem が呼ばれ、同じ id なら null、別の id ならその id を onValueChange で App へ戻します。App の状態が変わると新しい expandedValue が下へ配られ、古い本文が閉じて新しい本文が開きます。開くのは常に1件です。

選べる5つの記録

  • 2件に絞る（記録3）　「書き出し」で検索し、export-pdf と export-images の2件。どれも閉じています。
  • PDFを開く（記録4）　「PDFを書き出す」を押し、export-pdf だけが開いて本文2段落が region として出ます。
  • 画像へ切替（記録5）　「画像を書き出す」を押すと PDF が閉じ、画像の本文が開きます。
  • 動きを抑える（記録12）　ページの「動きを抑える」をオン、OS設定はオフで PDF を開きました。同じ本文とタグです。
  • 0件（記録10）　「存在しないキーワード」で0件。Accordion は描かれず、全件に戻すボタンが出ます。

図は、制作担当が実ブラウザーで記録した15状態のうちの5つを描いています。図の動きは保存した2つの状態の間を説明のためにつないだもので、部品そのものの実行や連続した画面録画、開閉速度の計測ではありません。開閉は見やすいよう遅く描いています。本物の Accordion は「実部品を動かす」（desk.html）で今も操作できます。

App が持つもの：検索と動きの設定

  • 検索は作例の App の処理　部品の機能ではありません。NFKC で正規化して小文字にし、見出し・分類・要約・本文・タグをまとめて、空白で区切った語すべてを部分一致で探します（全角の「ＰＤＦ」も「PDF」と同じ）。結果が変わるのは検索ボタンを押したときだけで、入力しただけでは6件のままです（記録2）。検索すると、開いていた1件は App が閉じます。
  • 動きの設定も App 側　OSの「視差効果を減らす」などの設定（prefers-reduced-motion）か、ページの「動きを抑える」のどちらかがオンなら transition を 0秒、それ以外は 0.18秒・easeOut にします。これは設定値で、応答時間や描画速度を測ったものではありません。見出し・本文・タグと操作はそのまま残ります。元の確認でのOS設定は Chrome の CDP で模擬したもので、実機の iPhone での確認や、アクセシビリティ全般の保証ではありません。
  • そのほかの App の作り　App はさらに外側の MotionConfig に reducedMotion も渡します。0件のときは Accordion を描かず、全件に戻すボタンを出します。どれもこの作例の App の作りで、ライブラリの部品が自動で用意するものではありません。

部品を6つに分けて見る

6つはこの説明のための整理で、原典の決まった形式ではありません。押すと図の該当箇所に印が付きます。引用は固定コミットの原典と、同じバイトで同梱したファイルの同じ行です。

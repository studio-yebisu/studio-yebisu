# 解説映像：点数と根拠を、セットで読む

架空FAQ「凪の図書室」の固定回答20件を、固定版 Ragas の文字列指標3つで採点した保存結果と、閲覧ページの実画面の静止キャプチャを編集した、28秒・無音の解説映像の元ページです。`index.html` を開くと編集・確認用のプレビューになり、同じページを書き出し用のレンダラーでMP4にします。

- 1280×720・30fps・840フレーム・28秒。音はありません（`audioEvents` は空）。
- ポスターは13.5秒（Q07の場面で、全要素が着地した静止状態）。
- 実画面は静止キャプチャ6枚の切り抜きを編集したもので、連続した画面録画ではありません。
- ページでも映像でも AI や Ragas は動きません。

映像の作者は Claude Opus 5.5（`claude-opus-5-5`）です。作者はファイルを書いただけで、書き出し・ブラウザーでの表示・映像の確認は行っていません（下の「確認の状況」）。

照合のあと、入力と結果の形、10問・10資料のID、20件の回答とメモが入力と同じこと、60個の値が0〜1であること、完全一致と包含が文字列から同じ値になること、平均と件数、Q07・Q08・Q05の値とラベル、保存JSONがQ07の行・資料D07・3指標の定義・入力のSHA-256・原典のコミットと一致すること、実画面の大きさとSHA-256、切り抜きの範囲を確かめます。1つでも合わなければ、理由を出して `window.motionReady` を失敗させます。内蔵の代わりのデータや外部への通信はありません。

## 時間の契約

- `window.motionConfig = {duration: 28, fps: 30, width: 1280, height: 720, posterTime: 13.5, audioEvents: []}`。
- `window.renderConfig` の `width`・`height`・`fps` を初期化時に反映します。描画は1280×720の論理座標を等倍率で収め、別の縦横比では余白を紙の色で埋めます（別の縦横比での見え方は確かめていません）。
- `window.motionReady` は、フォントの読み込みと12ファイルの照合・確認が終わると成功します。
- `window.seek(seconds)` は、その時刻の完成した画面を毎回最初から描きます。変換・クリップ・透明度はフレームごとに戻し、`Date`・乱数・前フレームの積算・CSSアニメーションは使いません。動きは閉形式の時間関数です。
- 書き出し時（`window.__MOTION_RENDER__ === true`）は、キャンバスだけを表示し、プレビューの再生を作りません。

## プレビュー

`index.html` は停止から始まり、自動では再生しません（動きを減らす設定でも同じ）。「再生」を押したときだけ `requestAnimationFrame` で進み、ボタンの `aria-pressed` が変わります。時刻のスライダーは0〜28秒・0.1秒刻みで、Home・Endで先頭・末尾、PageUp・PageDownで2秒ずつ（Homeから7回で14秒）動きます。操作部品は44px以上、文字は16px以上です。

ファイルを直接開くとJSONの取得が止まるため、作例フォルダー（`site`）をローカルサーバーで配信し、`/video/index.html` を開いてください。

## 書き出しの再現

Node.js 20以上、Chrome、FFmpeg と ffprobe、Python が必要です。作例フォルダー（`site`）で：

```powershell
npm ci --ignore-scripts --no-audit --no-fund --prefix tools/motion-reel
python render.py --out ../ragas-render-first
```

- `render.py` は、ソースの外の一時フォルダーへ作例を複写し、`video/index.html` に `<base href="video/">` を入れてレンダラーに渡します。`video.js` は `import.meta.url` を基準に素材を解決するので、どちらでも同じファイルを指します。
- 出力先はソースの外の空のフォルダーにします。既存の書き出しは上書きされません。
- 出力は代表時刻の静止画・コンタクトシート・連続フレーム・ポスター・`video.mp4`（音なし）・`capture.json` です。

## 範囲

- 3指標は文字列の比較で、忠実さ・事実としての正しさ・意味の一致は判定しません。完全一致の件数や平均は正答率ではなく、採用や合否の基準値もありません。
- 変更前・変更後は、意図して誤り・言い換え・根拠にない追記を入れた固定回答の名前です。実際のRAGシステム・モデル・検索器を変えて動かした結果ではありません。10問の架空データで、代表的なベンチマークではありません。
- 照合メモは制作担当が入力に書いたもので、Ragasの出力でも LLM judge でも人による承認でもありません。Q08の追記は「資料からは真偽を断定できない」とメモに書かれており、映像でも誤りとは書きません。

## 確認の状況

- 作者（Claude Opus 5.5）は5ファイル（`index.html`・`video.css`・`video.js`・`storyboard.json`・`README.md`）を書いただけです。コードの実行、ブラウザーでの表示、書き出し、フレームや通し再生の確認は行っていません。
- 書き出し・コンタクトシート・再生の確認と、その結果の記録は制作側で行います。レンダラーのPNG一致は同じ環境での再現性で、別OS・別フォントで同じ画になる保証ではありません。
- MP4へのリンクは、制作側が書き出してから追加します。

点数と、根拠をセットで読む

3指標は参照文と回答の文字を比べるだけです。内容が根拠と合うかは、各問の根拠資料と「制作担当の照合メモ（入力）」で確かめます。平均や件数は正答率ではなく、どちらを採用するかも決めません。

    同じ結果を作り直す手順

    Python の仮想環境で固定版の Ragas を入れ、evaluate.py を実行すると outputs/evaluation.json を新しく書き出します。既にあるファイルは上書きしません。インストールには通信が必要で、採点中の通信は拒否して記録します。

    python -m venv .venv
$env:SETUPTOOLS_SCM_PRETEND_VERSION_FOR_RAGAS = "0.0.0+studio.298b68274234"
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
Remove-Item Env:SETUPTOOLS_SCM_PRETEND_VERSION_FOR_RAGAS
.\.venv\Scripts\python.exe evaluate.py --out outputs/evaluation-new.json

    0.0.0+studio.298b68274234 は、Git情報のないソースZIPから入れるための手元の版名で、Ragas の正式なリリース番号ではありません。原典はコミット 298b682 で特定します。

    • evaluate.py（採点スクリプト）
    • requirements.lock.txt（実行した依存の版）
    • requirements.txt（互換系列の指定）
    • README.md（使い方と範囲）
    • outputs/method.md（評価の方法）
    • brief.json（制作ブリーフ）

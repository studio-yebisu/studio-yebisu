このスキルは何か

Make Interfaces Feel Better は、UIの細部（文字、面と操作範囲、動き、アイコン、性能）を見直すための、AIが読む Markdown の指針です。1つの SKILL.md に19の原則があり、5つの参照ファイルが続きます。UIを動かすAPIでも、自動の検出器でも、モデルでも、5つの自動AIでもありません。

図の流れ

  1. 渡す　固定版の SKILL.md と5参照、依頼文（対象の画面、主な操作、今の作り方、変えないデータと出力の契約、quick で上限3群）、そして今の納品メモ画面のファイルを、元の制作で Claude Opus 5.5 が一度読みました。
  2. 見て直す　元のAIは主な操作と頻度の高い状態だけを対象に（quick）、場所と理由を組にしたレビューと、同じ画面の直したHTML・plain CSS・JSを書きました。図の3群は、関連する10行を制作担当が整理したものです。変えない判断も3つ残しています。
  3. 使う　直した画面も、修正前と同じ clips.json と export.mjs を使います。選んだカットから同じJSONファイルを作り、ブラウザーへ渡します。実際の操作とダウンロードの確認は、制作担当が別の工程で行いました。

3つの変化

  • 1 押せる範囲（HIGH）　修正前は16pxのチェックボックスだけが押せて、フォーカス表示も消していました。修正後は行全体をネイティブの label にし、重ならない44px以上（指針の基準）と見えるフォーカスにしました。元の確認では行82px以上を観察しています。図の長さは説明用で、実寸ではありません。
  • 2 数字と状態（MEDIUM）　件数と時間を tabular-nums と幅の予約で固定し、0件の理由と「すべて選ぶ」、読み込み失敗からの再読み込みを加えました。
  • 3 押下と手渡し（HIGH）　押したときの縮みを0.86から0.96へ、transition: all をやめて指定した補間へ。色だけだった完了を、アイコンと「ブラウザーへ渡しました」の文言で示します。これはブラウザーへ渡した事実までで、ディスクへの保存完了ではありません。

AIが書いた範囲　元の Opus 5.5 がレビューと直した画面を書きました（シェルやブラウザーは実行していません）。制作担当の範囲　架空の入力3件と修正前の画面と export.mjs を用意し、関連する10行を内容を省かずに3群へまとめ、頻繁な選択での完了アイコンの即時復帰などを補正し、Nodeの8条件と実ブラウザー・実ダウンロードを確かめました。このページ　同じ入力で元の export.mjs を実際に呼び、保存した出力と照合するだけです。モデルは呼ばず、元のレビューや確認をやり直していません。

中身を6つに分けて見る

6つは説明のための整理で、原典の共通の形式ではありません。押すと図の該当箇所が光ります。

返ってくるもの：本物のJSON

「このJSONを保存」は、このページが元の export.mjs の serializeExport を実際に呼んで作った文字列を、ブラウザーへダウンロードとして渡します。渡す前に、保存済みの出力ファイルと1バイトずつ一致することを確かめています。アップロード・動画変換・モデル呼び出し・設定の保存はありません。

この作例の範囲

      
    
        
  • 入力は作例用　修正前の画面は、八百万図AIツールボックス が操作範囲・フォーカス・状態の課題を含めて作った依頼用の画面です。第三者の製品や誰かのアプリではありません。3件のカットは架空のメタ情報で、映像素材ではありません。
    • 
        
  • quick の範囲　原典の quick は主な操作と頻度の高い状態だけ、HIGH/MEDIUM のみで上限5件。今回の依頼はさらに上限3群です。full の15件や全画面を調べたものではありません。
    • 
        
  • 保ったもの　スタイルの方式・配色・書体・文言・ページ構成、clips.json と export.mjs の入出力。別のスタイル方式や新しい依存は足していません。
    • 
        
  • 元の確認　Animationsパネルでの10%再生は使えず、遷移時間を10倍にした私的なコピーで代わりに観察しました。準備中・object URLの失敗・HTTP 503 は条件を作った制御試験で、通常の待ち時間や失敗率ではありません。このページはそれらを再実行しません。
    • 
        
  • まだ確かめていないこと　実機のiOS/Safari、VoiceOver、macOS、ブラウザーの200%拡大、人による承認、一般的な使いやすさや品質。元のレビューの Approve は限定範囲のエージェントによる確認で、人の承認・アクセシビリティの認証・効果の大きさの証拠ではありません。
    • 
        
  • このページがしていること　開くたびに、固定した34件の大きさとSHA-256、6つの引用の行、19原則と5参照、3群・3見本・7枚の実画面の記録を確かめ、元の export.mjs で3見本・メモなし・0件の拒否を計算して保存済みの出力と照合します。合わないときは図もJSONも出さずに止まります。HTTPS か localhost で開いてください。

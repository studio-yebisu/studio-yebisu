Make Interfaces Feel Better：この画面で直した3点

Make Interfaces Feel Better は、UIの細部（文字、操作範囲、動き、アイコン、性能）を見直すための、文章で書かれたデザインエンジニアリングの指針です。SKILL.md と5つの参照ファイルでできていて、画面や文章を実行時に生成するAPIではありません。この作例では、その指針を quick レビューとして既存の納品メモ画面に当て、HIGH と MEDIUM の3群だけを直しました。このページで動いているのは通常の HTML・CSS・JavaScript で、ページ上でAIは動きません。

1. 操作範囲とフォーカス（Minimum Hit Area）

修正前は16pxのチェックボックスだけが押せる範囲で、フォーカス表示も消していました。修正後は各行と「制作メモを含める」をネイティブの label で囲み、44px以上の重ならない範囲にしました。キーボードで移動すると緑の枠が出ます。

修正前：before/before.mjs・before/before.css → 修正後：app.mjs・style.css

2. 件数・時間の安定と、空の状態（Tabular Numbers）

件数と合計時間を等幅の数字（tabular-nums）にして幅を予約し、チェックの操作では動きを付けません。0件にすると、書き出せない理由を文字で示し、「すべて選ぶ」で元に戻せます。入力を読み込めなかったときは、仮の行を出さずに理由と再読み込みのボタンを出します。

修正前：before/before.mjs・before/index.html → 修正後：app.mjs・index.html

3. 書き出しボタンの状態（Scale on Press・Contextual Icon・Motion Restraint）

押したときの縮みは0.96で、補間するのは縮みと hover の色だけです。押すとブラウザー内で JSON を作り、ダウンロードとしてブラウザーへ渡して「ブラウザーへ渡しました」と表示します。保存先への書き込みが済んだかは、ブラウザーのダウンロード表示で確認してください。アイコンの切り替えは原典が指定する値（scale 0.25→1、opacity 0→1、blur 4px→0、300ms）です。動きを減らす設定では、補間せずに文言とアイコンだけを切り替えます。

修正前：before/before.css・before/before.mjs → 修正後：style.css・app.mjs

入力と出力

入力は clips.json の3件（ID・題名・秒数・メモ）です。出力は atelier-delivery.json で、選んだカットを入力順に並べ、プロジェクト名「週末のアトリエ」を付けます。メモをオフにすると、各カットから note を除きます。計算と書き出しは、修正前と同じ export.mjs を使い、変えていません。

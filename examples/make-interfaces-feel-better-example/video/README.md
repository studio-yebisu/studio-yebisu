# 図解動画のソース（Make Interfaces Feel Better）

32秒・30fps・960フレーム、無音の図解動画のソースです。縦長 720×1280 と横長 1280×720 を、それぞれに合わせた配置で描きます。紹介ページ（`../index.html`）と同じ構造図を、同じモジュール（`../concept.js?v=visual-r1`）で描きます。

**状態：** claude-opus-5-5 がソースを書いた段階です。執筆者はブラウザーでの描画、テスト、フレームの確認、MP4への書き出し、公開をしていません（この環境ではそれらを実行できませんでした）。それらは制作担当の後の工程で、この README はそれが通ったとは主張しません。後の確認結果は制作担当が追記します。

## 動画が伝えること

Make Interfaces Feel Better が何か（AIが読むUI細部の指針。1つの SKILL.md に19原則、5つの参照）、何をAIに渡し、何が返り、どう使うかを、ひとつのつながった図の動きで見せます。文章のスライドやJSON・ログ・レビュー表を主役にせず、同じ本・紙・画面・レンズ・帯が動き、合流し、変わります。

| 秒 | 場面 | 動き |
|---|---|---|
| 0–4 | 何か | SKILL.md の本と5つの見出し（文字・面と操作範囲・動き・アイコン・性能）が光り、図の骨組みが現れる |
| 4–8 | 渡す | 本のページと依頼文が重なって元のAIへ。今の画面の写しもAIへ入り、AIが一度だけ光る |
| 8–14 | 見て直す | レンズが同じ画面の3か所に印を付け、それぞれ修正前の見た目から修正後へ変わる。変えない3案に線が引かれる |
| 14–20 | 3つの変化 | 1 押せる範囲（16pxの箱 → 行全体＋フォーカス）、2 数字（等幅の升に固定、桁が升の中で入れ替わる）、3 押下（0.86 → 0.96、アイコンと「ブラウザーへ渡しました」）を2秒ずつ |
| 20–26 | 同じJSON | one・two・all の順に、件数と時間が同じ升で入れ替わり、変わらない帯（clips.json → export.mjs）から 252B・399B・560B のJSONが出る |
| 26–29 | 別工程 | 実検証は制作担当の別工程（Node8条件・実ダウンロード）。変えない判断の枝も示す |
| 29–32 | 全体 | 図全体と3見本の値が止まったまま。動きは28.9秒で終わり、ポスターは31秒 |

場面へ移動するボタンは 0・4・8・14・20・26・29 秒です。図の下の固定のラベルは「Markdownの指針・元のAIが書いた変更・図は説明用・実検証は別工程・無音」です。

## 実際のデータ

- 件数・時間・各カットの時間・JSONの大きさは、読み込み時に元の `../export.mjs` を `../clips.json` で実際に呼んだ結果です（`summarize` と `serializeExport`、見本 all/two/one、メモあり）。それぞれの文字列が `../outputs/{all,two,one}.json` と1バイトずつ一致し、メモなしが `../outputs/no-notes.json` と一致し、0件が RangeError で拒否されることを確かめてから描きます。新しい入力や出力は作っていません。
- 3つの変化は元の画面の変更（`before/before.css`・`style.css`・`app.mjs` の該当行を読んで確認）を図にしたものです。図の大きさは説明用で、実際のUIの寸法ではありません。44px は指針の基準で、元の確認では行82px以上を観察しています。
- 「ブラウザーへ渡しました」はブラウザーへファイルを渡した事実までで、ディスクへの保存完了ではありません。
- 本・紙・レンズ・印・帯の形は説明用の絵で、実行の証拠ではありません。AIがシェルやブラウザーを動かす絵、新しいレビュー、点数、承認の印、アップロード、待ち時間や故障の演出は描きません。

## 読み込みと止まり方

`../concept/manifest.json`（SHA-256 `a4075c5d1bda1e89cbae006fd7d65268d9e1784704df569cd719c5bb738c1426`）が挙げる34件を、大きさとSHA-256で確かめてから描きます。6つの引用が SKILL.md の記録した行にあること、19原則と5参照、3群と3見本、samples.json・original-run.json・validation.json・verification.json の要点、7枚の実画面の幅と高さ、元の画面の該当行、依頼文とレビューの見出しも中身で確かめます。これらは保存した記録を読む確認で、新しい実行ではありません。

合わない・読めないときは何も描かず、操作を止めて「もう一度読み込む」だけを残します。もう一度読み込むと34件を最初から確かめ直します。`crypto.subtle` が必要なので、HTTPS か localhost で開いてください。外部への通信・CDN・外部フォントは使いません。

## 書き出し側との約束

- `window.motionConfig = {duration: 32, fps: 30, width, height, posterTime: 31, audioEvents: []}`
- `window.renderConfig` の幅・高さ・fps を初期化時に使います。幅が高さより大きければ横長の配置です。`?orient=wide` でも横長になります。
- `window.motionReady` はフォント、34件の確認、export.mjs の計算と照合を待ちます。失敗すると reject します。
- `window.seek(t)` は時刻 t（0〜32に丸める）だけから完成した1枚を描きます。呼ぶ順番や壁時計、乱数、前のフレームに依存しません。毎フレーム canvas の save/restore で描き直します。
- 素材の場所は `../concept.js` 自身のモジュールURLから決まるので、`<base href="video/">` を持つルートの入口から開いても同じ素材を読みます。
- `window.__MOTION_RENDER__` が真なら確認用の再生を止め、`?render=1` か `__MOTION_RENDER__` で canvas だけを表示します。
- 音声はありません（ナレーション・TTS・音声ガイド・音の要素・スクリプト・素材・トラックなし）。元の入力にある「手元の音を残す」は架空のカットのメモで、音声ガイドではありません。

# 入力：既存の納品メモ画面を3点だけ磨く

対象は作例用の架空作品「週末のアトリエ」の納品メモ。実入力は clips.json の3件（ID・題名・秒数・メモ）です。映像素材そのものはありません。チェックしたカットと「制作メモを含める」の設定から、実際の JSON ファイルをブラウザー内で作り、ダウンロードします。ネット送信、動画変換、AI実行、設定の永続保存はしません。

before/ は依頼用に Studio Yebisu が作った既存画面です。美化した比較対象や第三者製品ではありません。HTML・plain CSS・ES moduleだけを使っています。export.mjs の実際の入力→出力契約を引き継ぎ、既存の文字・配色・書体・ページ構成は保ってください。

Make Interfaces Feel Better の固定版 SKILL.md と必要な5参照を読み、quickレビューとして、主な操作の HIGH/MEDIUM の問題を最大3群に絞って修正してください。操作範囲とフォーカス、変化する件数・時間の安定、書き出しの反応が主な検討対象です。全変更をレビュー表に含め、却下した候補も根拠付きで残します。5分類の実際に見た範囲を記載し、未実行の画面確認は Not verified とします。

操作・結果：全選択=3件・370秒・06:10。c01を外す=2件・275秒・04:35。c02だけ=1件・190秒・03:10。全部外す=0件で出力不可、理由を表示。メモOFF時は出力各clipからnoteを完全に除く。メモON時は原文のまま。順序は入力順。プロジェクト名も固定。スキルによる品質の向上率や第三者への優位は計測しません。

完成条件：修正前後とも実際に同じデータを書き出せる。afterでは320px幅で文字やボタンがはみ出さない。各チェックのクリック可能範囲は44px以上で隣同士が重ならない。キーボードだけで選択・メモ設定・出力・0件解除ができ、フォーカスを隠さない。動く件数と時間はtabular-nums。空・準備・出力済みの静的な文言がある。成功文言はブラウザーへファイルを渡した事実までにし、ディスクへの保存完了と混同しない。架空のアップロード、待ち時間、速度向上は付けない。高頻度のチェックは動かさず、書き出しアイコンを使うなら原典指定のCSS cross-fade値とreduced-motionを守る。説明や確認は画面下へ置き、初めに実操作を見せる。

実ブラウザー確認、10%速度での動きの観察、実ダウンロードの一致、動画、公開の成否は後の実行工程で記録する。スクリーンリーダー、人による承認、macOS、全環境の確認は実施済みとしない。

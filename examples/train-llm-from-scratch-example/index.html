この図で試せること

  1. 英文 自分で書いた英文96行を、学習83行と検証13行に分けます。
  2. BPE 学習側の文だけで、文を番号の並びに切る規則を作ります。
  3. 学習 同じ初期値から、片方だけ800回調整します。もう片方は0回のままです。
  4. 比べる 同じ書き出しの番号を両方に渡し、続きを並べます。

検証13行はすべて学習側にも同じ文があります。損失が下がっても、文型を覚えた練習の記録で、知識・汎化・文章の品質の評価ではありません。P08の質問にも答えず、物語の文が続きます。

続きを書いたのは、この作例で学習した小さなTransformerです（Claude ではありません）。このページの中で学習や生成は動かず、保存済みの記録を読んで描いています。

        手元で再現する
        
      
        python -m venv .venv
# Windows（PowerShell）
.venv\Scripts\Activate.ps1
# macOS・Linux
source .venv/bin/activate

# Windows / Linux：今回使ったCPU版を明示する
python -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cpu

python -m pip install -r requirements.txt
python run.py --artifact-dir ../training-artifacts
python -m http.server 8866
        
      
        配布済みの outputs/training-run.json があると run.py は止まり、上書きしません。新しい作業用フォルダへコピーしてから実行してください（README.md 参照）。依存の導入にはネット接続が要ります。

# 解説映像の編集元 — 小さなモデルを、ゼロから（Train LLM From Scratch 作例）

作例のために書いた英文96行で、固定版の原典の学習コードを手元のCPUで実行した記録を、28秒・無音の映像に編集する元ページです。`index.html` を開くと、照合したファイルから描いた映像を、再生位置を選んで確かめられます。

主なメッセージは「文型を覚える、その過程を動かす。」です。

この映像は、保存した実出力と実画面の静止画を編集したものです。学習や操作の録画ではありません。学習中の端末・進み具合・AIの思考は、記録にないので描いていません。ページでも映像でも、Python・学習・AI は動きません。

## 何の練習で、何ではないか

- 英文は名前・場所・物を入れ替える短い型の繰り返しです（96行、重複を除くと64行）。学習側83行・検証側13行に分かれ、検証側13行はすべて学習側にも同じ行があります。
- 映像が示すのは、同じ初期値から800回更新したモデルが学習文の型を覚えた様子です。知識・汎化・文章の品質の評価やベンチマークではありません。
- 検証損失（記録では6.1135→0.1900）は、上の重複のため汎化の指標にならないので映像に出しません。グラフは更新ごとの学習ミニバッチの損失（保存した800個）だけです。
- 800回のCLIの所要秒は、他のPCの速さや性能比較と誤解されるため映像に出しません。実行スクリプトの確認44件も、品質や人の承認ではないため出しません。
- SFT・RLHF・DPO・PPO・GRPO・量子化・GPU・外部データ・APIは使っていません。

## 使う素材（8ファイル。すべて照合してから使う）

`video.js` は、まず照合表 `assets/data-hashes.json` 自体の SHA-256 を、制作側の記録（公開配布には含まれない `runtime/frozen-reviewed-source.json` の `files_sha256`）の値 `91cf42aa5717fa4201943bc87d0b3ac5a1de4b7f494d2fff2c2e06253d87e5d6` と比べます。次に、照合表に書かれた8ファイルの生のバイト列を WebCrypto の SHA-256 で確かめます。画像は照合済みのバイト列から作ります。一つでも欠けたり、読めなかったり、合わなかったりすれば、理由を出して `window.motionReady` を拒否します。代わりの映像は描きません。

| ファイル | 映像での使い方 |
| --- | --- |
| `outputs/training-run.json` | 原典の版、入力の SHA-256、設定、行数・語彙・パラメータ数、0回と800回、800個の学習ミニバッチの損失、8件×学習前後の全文とトークンID |
| `outputs/independent-checks.json` | 16出力の作り直しの一致、同じseedの新しい初期値、重複を除いた64行、検証側13行の重複、各出力のトークン数 |
| `input/stories.txt` | 1〜3行目の最初の文の抜粋。行数・重複・検証側の重複を数え直し、P01・P08 の続きと学習文の関係を照合 |
| `input/prompts.json` | 学習前に固定した8つの書き出しと生成条件 |
| `input/run-config.json` | 学習前に固定した設定（CPU・4スレッド・800回など） |
| `video/assets/screen-manifest.json` | 実画面2枚の大きさと SHA-256 |
| `video/assets/workbench-phone.png` | スマホ幅（375×781）の閲覧ページ、P01 を選んだ状態。22〜28秒に切り抜きを置く |
| `video/assets/workbench-desktop.png` | 広い幅（1265×889）の閲覧ページ。照合・復号・大きさの確認だけで、今回の構図では描きません（720pに縮めると文字が読めないため） |

行数・語彙・トークンID・パラメータ数・更新回数・損失・抜粋は、すべて読み込んだファイルから取り出します。コードに書いた期待値（固定コミット、96行・64行・83行・13行・重複13行、上限512・実語彙417、135,552パラメータ、0回・800回、P01〜P08、48トークン、確認44件）は照合にだけ使い、合わなければ描きません。

## 場面（28秒・840フレーム・無音）

| 時刻 | 見出し | 伝えること | 素材 |
| --- | --- | --- | --- |
| 0〜4秒 | 小さなモデルを、ゼロから。 | 副題「文型を覚える、その過程を動かす。」英文の1〜3行目の最初の文、96行、自作の定型文、重複を除くと64行 | 英文 |
| 4〜8秒 | 文章を、数字に変える。 | P01「Mira walks to the」→ 実際のトークンID 327・313・269・301。語彙は上限512／実語彙417、学習側83行の文だけで作成 | 実行記録 |
| 8〜12秒 | 同じ初期値から、800更新。 | 保存済みの学習記録から、学習ミニバッチの損失800個（最初6.1106・最後0.0038）。135,552パラメータ、CPU・4スレッド、0回と800回は同じ初期値から | 実行記録・設定 |
| 12〜18秒 | 同じ書き出し。違う続き。 | P01 の0回更新（学習前）と800回更新の実出力の抜粋。学習前は続く48トークンがすべて「the」、学習後は学習文の1行と一字一句同じ | 実行記録・英文 |
| 18〜22秒 | 質問への答えは、覚えていない。 | 学習文にない質問 P08 の800回更新後の実出力の抜粋。質問に答えず、学習文の型が続く | 実行記録・英文 |
| 22〜28秒 | データから、生成までを確かめる。 | データ→BPE→学習→生成の4段。定型文を覚える練習で、知識・汎化の評価ではない。コードは Claude Opus 5.5、続きの文は学習した小さなモデル。24.9秒以降は案内「8例と実行記録を、サイトで読む。」で静止 | 実行記録・スマホの実画面 |

足元にはいつも「原典コードの実行記録を編集・無音」と「続きの文は、学習した小さなモデルの実出力」を表示します。場面の見出しと本文は重ねず、0.3秒で紙の色へ消えてから次が0.3秒で現れます。損失の線は一度に現れ、左から描き進める演出や回数の数え上げはしません。

ポスター（13.5秒）は、見出しと、0回更新・800回更新の2枚のカードがすべて着地して止まった状態です（全要素が13.35秒までに着地）。

## 実出力の抜粋

抜粋は、保存した全文の先頭からの文字列そのままです。表示する直前に `video.js` が全文から切り出し、手で書き写した文は使いません。入力の部分は薄く、続きは濃く描きます（閲覧ページと同じ）。末尾の「…」は抜粋の印で、出力の文字ではありません。8件×学習前後の全文はサイトで読めます。

| 場面 | 出力 | 切り出しの規則 | 表示 |
| --- | --- | --- | --- |
| 12〜18秒 | P01 学習前 | 入力＋続きの最初の4語（続きは同じ語の48回の繰り返しであることを照合） | `Mira walks to the the the the the …` |
| 12〜18秒 | P01 800回更新後 | 入力の後の2つ目の「.」まで（1行目が学習文の1行と同じことを照合） | `Mira walks to the garden. Mira reads a small book. …` |
| 18〜22秒 | P08 800回更新後 | 入力の後の2つ目の「.」まで（続きが学習文と同じ並びで、答えを含まないことを照合） | `What is the capital of Japan? is blue. A friend brings a red book. …` |

英文の抜粋は等幅44pxで、語の単位で折り返します。見出し72px・副題52px・抜粋44pxを下限のまま描き、枠に収まらなければ縮めずに理由を出して止まります。

## 実画面の切り抜き

実画面は縦横同じ倍率で置きます。画素を伸ばさず、消したり描き直したりせず、上に文字を重ねません。見出し・数・記録カード・グラフ・強調は、画像の外に編集で置いたものです。記録カードは保存した JSON の値を読みやすく描き直したもので、アプリ画面や端末の様子ではありません。

| 名前 | 画像 | 切り抜き（x, y, 幅, 高さ） | 置き場所・倍率 | 内容 |
| --- | --- | --- | --- | --- |
| phoneAfter | workbench-phone.png（375×781） | 10, 366, 342, 264 | x904 y314・0.96 | スマホ幅の閲覧ページ、P01 の「800回更新後」のカード |

`video.js` は、画像の実寸が記録の大きさと同じこと、切り抜きが画像の内側にあること、置き場所が本文の範囲に収まることを確かめます。切り抜きの座標は静止画を見て決めた値です。端の数画素の収まりは、書き出したフレームで確かめる必要があります。

## 時間の契約

- `window.motionConfig = {duration: 28, fps: 30, width: 1280, height: 720, posterTime: 13.5, audioEvents: []}`。840フレーム、**無音**です。
- `window.renderConfig` の幅・高さ・FPS を初期化時に反映します。1280×720 を基準に、渡された縦横比へ論理座標を広げ、上の帯と足元の帯は端に、本文は中央に置きます（1280×720 以外は未確認）。
- Canvas は `getContext('2d', {willReadFrequently: true})` で作ります。
- `window.motionReady` は、フォントの準備、照合表と8ファイルの照合、画像の復号、記録の照合、文字の収まりの確認が済むと解決します。失敗すると理由つきで拒否され、ページは `#status[data-state="error"]` と「もう一度読み込む」を出します。
- `window.seek(seconds)` は、0〜28秒に収めた時刻だけから完成した1フレームを描きます。毎回キャンバスの状態（変換・透明度・クリップ）を捨ててから描き、壁時計・乱数・前のフレームには依存しません。動きは閉形式の減速曲線です。
- 素材のパスは `new URL('../' + path, import.meta.url)` で `video.js` の1つ上を基準に解決します。書き出し時に `<base href="video/">` が入った写しでも同じファイルを指します。外部のフォント・CDN・通信は使いません。
- 編集用のプレビューは停止から始まります（動きを減らす設定でも同じ）。「再生」を押したときだけ requestAnimationFrame で進みます。書き出し時（`window.__MOTION_RENDER__`）は動かしません。CSS のアニメーションは使いません。
- 再生ボタン `#play` の `aria-pressed` は再生中かどうかを表します。再生位置 `#time` は0〜28秒・0.1秒刻みで、`#clock` に現在の秒を出します。Home・End は先頭・末尾、PageUp・PageDown は2秒ずつ動きます（Home から PageUp 7回で14秒）。操作部品は44px以上、文字は16pxです。

## 開いて確かめる

照合に WebCrypto と fetch を使うため、`file://` ではなくローカルサーバーで開きます。作例フォルダ（`video/` の1つ上）で次を実行し、`http://127.0.0.1:8866/video/` を開きます。

```powershell
python -m http.server 8866 --bind 127.0.0.1 --directory .
```

## 書き出しの再現

必要なもの：Node.js 20以上、インストール済みの Google Chrome、FFmpeg と ffprobe、Python 3。作例フォルダで次を実行します。依存はレンダラーの隣にだけ入れ、パッケージのスクリプトは実行しません。

```powershell
npm ci --ignore-scripts --no-audit --no-fund --prefix tools/motion-reel
python render.py --out <作例フォルダの外の空のフォルダ> --work-root <作例フォルダの外の作業用フォルダ>
```

`render.py` は作例フォルダを `--work-root` の下の一時フォルダへ写し、`video/index.html` に `<base href="video/">` を入れた写しを入口にして `tools/motion-reel/render.mjs` を呼びます。出力先と作業用フォルダは作例フォルダの外だけを受け付け、既存の書き出しは上書きしません。`--stills-only` で静止画とコンタクトシートだけを作れます。`--strip-at` で連続フレームの位置を変えられます。

レンダラーは同じ時刻を別の順序と新しいページで描き、PNG の一致を確かめます。これは同じ環境内での再現性を示すものです。書体は環境のものを使うため（Windows では Yu Gothic UI・Yu Mincho・Cascadia Mono か Consolas、macOS では Hiragino と SF Mono）、OS が違えば文字の幅や見た目が変わります。

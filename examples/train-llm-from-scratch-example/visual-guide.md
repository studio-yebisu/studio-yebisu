# 同じ書き出し、違う続き。

自作の英文96行からBPEを作り、小さなTransformerを0回と800回更新した実記録を、一つの大きな概念図で読みます。英文の束・文字を番号にする部品・学習の調整ループ・2つのモデル・実際の続きがつながります。同じ書き出しの紙と番号のかけらが、2つのモデルへ分かれ、保存済みの続きの紙へ伸びます。

P01「Mira walks to the」は、0回のモデルではtheが続き、800回のモデルではgarden. Mira reads a small book.という物語の続きになります。P08の首都を尋ねる質問には、物語の言い回しが続いて質問には答えません。画面で示す短い文章は実出力の抜粋です。全文・全トークンID・省略せず記録した文字や区切り記号は下から開け、選んだ1件を両モデルの結果ごとJSONで保存できます。

96行は64種類の定型文で、学習83行・検証13行に分かれ、検証13行のすべてが学習側と重複します。BPEは学習側だけで作り、指定した語彙の上限512に対して実際は417です。図の重複のつながりは、この検証側が独立していないことを示します。損失の低下は、知識・文章品質・知らない文への汎化を評価したものではありません。学習の調整や内部の部品の図は概念の説明で、記録にない確率・重みの推移・バッチの実測を補ったものではありません。

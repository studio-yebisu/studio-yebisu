          作り方と範囲

          Python 3.12 の仮想環境に固定版の browser-use を入れ、手元の 127.0.0.1 で作例フォルダを配って run_browser.py を実行すると、6状態を操作して outputs/browser-run.json と画像6枚を新しく書き出します。既にあるファイルは上書きしません。

          使った API は Browser・Page・Element の直接操作です（上流の文書では legacy direct control）。Agent.run、LLM による操作の判断、ChatBrowserUse、Browser Use Cloud、既存の Chrome プロファイルは使っていないので、Browser Use の自律エージェントとしての能力はこの記録では確かめていません。

          • README.md（使い方と範囲）
          • run_browser.py（操作して記録するスクリプト）
          • outputs/method.md（操作と照合の方法）
          • requirements.txt（固定コミットの browser-use）
          • brief.json（制作ブリーフ）
          • fixture.html（操作した検索画面）

# 原記録の読み方（制作担当による追記）

原実装4ファイルはOpus5.5の執筆原本を保全した上で実行しました。implementation.mdは執筆時点のメモです。次の説明の言い違いは、原実行やそのファイルを変更せず、この追記と新しい構造図で区別します。

- 元VAEのマスクは上半分を残し、下半分を黒くします。原メモ/runnerのupper-half-maskedという語と診断PNGの保存名は逆の説明です。実際のPNGは下半分が黒で、原典VAEも下半分をゼロにしています。推論の修正や新しい推論ではありません。
- res_frame_queueには、貼り戻す前の予測顔と2つの生音声チャンクが入ります。その後のprocess_framesが、待機用の元画像か貼り戻しを選び、透かしを描いて出力へ渡します。原メモ中のpasteback→queueという語順は逆です。
- type1は入力キューが空のときに作られたゼロ音声です。音源の中の無音をVADで判定したものではありません。Whisperエンコーダは待機音でも動きます。全部type1のバッチではU-Netを省き、個々の待機フレームでは元画像を使います。
- 比較用の期待音声を読むために原典の変換関数を呼び、その後put_audio_fileが同じ変換を呼びます。元WAVを再合成したものではありません。
- 27選択原典にはランナーが照合する23必須パスがあります。アプリ全部ではなく、別のモデル重み/依存/FFmpegが必要です。実制作は177ファイルの全checkoutを使い、同梱部分で推論し直してはいません。
- 手動の枠とマスクを使ったこの出力の一部では、下顔のぼけと枠の境界が見えます。実出力をそのまま見せ、修整/選別/再推論で隠していません。見た目や口の同期の精度、人による承認を保証しません。音声は聴取していません。
- 入力は以前のChatterboxの同じWAVです。元合成ではPerthを適用しましたが、この変換/圧縮後の透かし検出や頑健性は確認していません。

outputs/results.jsonは原ランナーによる測定の包装です。2つのjob JSONはそのオブジェクトを制作担当がUTF8/LFで包装したもので、原典の返却JSONや新しいモデル出力ではありません。原run-logは非公開保管し配布しません。

# AIに渡す、専門家の指示書集

Agency Agentsの役割ファイルは、AIに担当と仕事の進め方を伝えるMarkdownの文書です。図ではUX設計と画面実装の2役を切り替え、担当・仕事・約束・進め方・成果物・確認観点を開けます。この6項目は選んだ2ファイルの共通構造を説明用に整理したもので、全役割の共通機械スキーマではありません。

役割の指示書と、今回の依頼・素材を一緒にAIへ渡します。元の制作ではUX Architectが6つの架空企画から引き継ぎ書とCSS土台を作り、制作担当がそれを次のFrontend Developer適用へ渡しました。同じOpus5.5の別実行を順につないだ成果です。図の操作でAIを実行するものではありません。

「できあがった作例を触る」からguide.htmlへ進むと、元の6企画を比べ、重ならない予定をJSONで保存できます。元の入力・引き継ぎ書・CSS土台・実装メモ・保存済み出力は保持しました。元UX案の自動入替は実装では不採用で、重なる追加を止めて既存選択を残します。イベントは架空で、予約・支払いにはなりません。

32秒・30fpsの無音動画は、この指示書・依頼・AI・成果の構造を図解します。編集ソースはvideo/index.html、11固定素材はconcept/manifest.json。原典の成功指標は目標で、検証済みの数値ではありません。確認範囲はverification.jsonを参照してください。実機iOS/VoiceOverや人による審美的承認は未確認です。

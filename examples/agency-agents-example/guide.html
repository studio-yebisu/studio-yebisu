架空イベント・予約ではない

6企画が回る予定になるまでの図と操作

架空イベントの入力の6企画（S01〜S06）を、UX設計の引継ぎ書と土台CSSを経て、Frontend実装が時間の図にしたものです。午前と午後の帯で、横の位置と幅が開始と終了の時刻です。斜線は時間が重なる部分です。各帯の下の「予定」の列が回る予定で、図の下の予定メモにまとまり、JSONで保存できます。帯を押すと、その企画に注目します。入れる・外すは図の下のボタンで行います。

固定した7つのファイルを読み込み、バイト数と SHA-256 を確かめています…

元のファイルを確かめられなかったため、図と操作を止めています。

古い内容や内蔵の代わりのデータは表示しません。ファイルを直接開いた場合は読み込めないことがあります。HTTP で配信して開いてください。

    絞り込みの条件

    企画名・内容・部屋・対象年齢・メモから探します。空白で区切ると、すべての語を含む企画に絞ります。

    条件に合う企画はありません。

      この作例のつくり方

      Agency Agents の2つの役割ファイルを、同じ Claude Opus 5.5 が別々の実行で順に当てて作りました。先に UX Architect が入力から引継ぎ書と CSS の土台を書き、次に Frontend Developer がそれを読んで、企画を比べて選ぶ画面を実装しました。README の「Option 3: Use as Reference」（読んで写し、調整して使う）の使い方で、エージェントのインストール、独立したエージェント同士の協調、自動の振り分けはありません。この図は保存済みの成果をつないで見せるもので、ページを開いてもAIは動きません。

      このページと解説動画は、元の2段階のあとに Claude Opus 5.5 が別の実行で作り直した表示です。元の入力・引継ぎ書・土台CSS・実装・保存記録は書き換えず、起動時にバイト数と SHA-256 を確かめて読み込んでいます。元の実装の画面は comparison.html で開けます。

      2つの役割（元の引継ぎ書から）

      採用しなかった案と、直した条件

      A09「入れ替える」は採用していません

      引継ぎ書は、重なる企画のボタンで今の予定を外して入れ替える案でした。実装では、重なる企画を押しても予定は変えず、どの企画のどの時間と重なるかを知らせます。こちらにしたいときは、先に今の企画を自分で外します。押しただけで選んだ企画が外れる操作は置いていません。

      受け入れ条件は引継ぎ書の段階で書かれた将来の確認項目で、合格の記録ではありません。

      重なりの判定式（引継ぎ書のまま）

      終了と開始が同時刻なら重なりません（例：S05 の終了 14:00 と S06 の開始 14:00）。部屋が違っても、時間が重なれば重なりです。移動の時間は考えていないため、実際に参加できることは保証しません。

      元の画面で実際に操作した記録（履歴）

      元の実装（comparison.html）を実ブラウザーで操作したときの記録 samples.json と outputs/browser-record.json からの抜き出しです。この図のページを確かめた記録ではありません。

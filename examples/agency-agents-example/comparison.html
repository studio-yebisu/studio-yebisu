      この作例の作り方

      このページは、Agency Agents の2つの役割ファイルを、同じ Claude Opus 5.5 が別々の実行で順に当てて作りました。先に UX Architect が引き継ぎ書と CSS の土台を書き、次に Frontend Developer がそれを読んでこのページを実装しています。独立したエージェント同士の協調や自動の受け渡しではなく、ページを開いてもAIは動きません。

      引き継ぎ書を読み込んでいます…

      引き継ぎ書を読み込めませんでした。

      企画ガイドの操作はこの欄と関係なく使えます。

      Frontend Developer 段階で変えたこと

      重なる企画の「入れ替える」は採用していません

      引き継ぎ書は、重なる企画のボタンを「入れ替える」にする案でした。実装では、重なる企画を押しても回る予定は変えず、どの企画と重なるかを知らせます。入れたいときは、先に今の企画を自分で外します。押しただけで選んだ企画が外れることを避けるためです。

      重なりの判定式は引き継ぎ書のまま

      終了と開始が同時刻なら重なりません。予約不要の企画も、開始から終了までの枠全体で判定します。

      そのほかの変更

      • 絞り込みに「費用（無料／費用あり）」を足し、キーワードは対象年齢も探します。
      • 「回る予定へ」のリンクは画面の下に追従させず、一覧の前後に置きました。追従する帯で企画カードが隠れないようにするためです。
      • この欄のために、企画データに加えて引き継ぎ書と依頼文も同じフォルダーから読みます。外部への通信はありません。
      • テーマの保存名は、この作例専用の名前にしました。

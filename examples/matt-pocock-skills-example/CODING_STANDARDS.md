# この作例のコーディング基準

- 依存パッケージは追加しない。Node.js標準の `node:test` と `node:assert/strict` だけを使う。
- 公開するのは `searchEntries` だけ。補助関数はexportせず、テストからも呼ばない。
- `searchEntries` は新しい配列を返し、渡された作例集と各掲載項目を変更しない。
- テストは `searchEntries` を通して返る識別子の配列だけを確かめる。内部のモック、呼び出し回数、補助関数の形は確かめない。
- 期待値は合成データを読んで決めた識別子の固定リストで書く。実装と同じ処理で期待値を計算しない。
- テスト名は `GLOSSARY.md` の言葉を使い、何が返るかを日本語で書く。
- 1段につき新しいテストは1件。次の段の振る舞いを先回りして実装しない。
- `entries.json` は合成データの正本として扱い、テストの都合で書き換えない。

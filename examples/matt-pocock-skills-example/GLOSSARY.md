# 作例検索

Studio Yebisuの記事用に作った架空の作例集を、検索語と分野で探すための文脈。実在のサイト検索とは別物。

## Language

**掲載項目**:
作例集に載っている1件の作例。掲載順を持つ。
_Avoid_: 記事、カード、レコード、エントリー

**表題**:
掲載項目に付いた1つの名前。
_Avoid_: タイトル、見出し、名前

**タグ**:
掲載項目に付いた短い手がかりの言葉。1件に複数ある。
_Avoid_: キーワード、ラベル

**分野**:
掲載項目が属するただ1つの区分。
_Avoid_: カテゴリ、ジャンル、種類

**全分野**:
分野で絞らないという選択。
_Avoid_: すべて、未選択、なし

**検索語**:
利用者が入力した文字列の全体。
_Avoid_: クエリ、キーワード

**語**:
検索語を空白で区切った一つひとつ。
_Avoid_: 単語、トークン、キーワード

**表記ゆれ**:
この作例で同じとみなす、Unicode互換文字や英数字の大文字と小文字による書き分け。ひらがなとカタカナの相互変換は含まない。
_Avoid_: 誤字、同義語、揺らぎ

# Ryoshuをローカルで試す — v1.3.0

この紹介ページは保存済みの架空データを表示し、OCR・AIは実行しません。旧映像と4例はv0.4、最新版の実画面はv1.3です。

1. [動作要件](https://github.com/studio-yebisu/ryoshu/blob/e79394d7349efc15aadb2dc02f6fe381596b407d/docs/REQUIREMENTS.md)と[モデルの条件](https://github.com/studio-yebisu/ryoshu/blob/e79394d7349efc15aadb2dc02f6fe381596b407d/THIRD_PARTY.md)を確認し、Ollama Windows版を導入します。
2. [v1.3.0の配布ZIP](https://github.com/studio-yebisu/ryoshu/releases/tag/v1.3.0)を別フォルダーへ展開し、`Ryoshu.cmd`を実行。初回だけPython・依存・モデルを取得し、復元用パスワードを設定します。
3. PDF・画像をまとめて選択またはドロップし、「読み取りを開始」。原本・文字数字・科目を並べて確認します。画像はクリックで拡大できます。
4. 科目だけ直すときは「科目を変更」→「カテゴリー」→「勘定科目」→「変更を保存」。金額・日付・用途も直すときは「確認・修正する」を開きます。
5. 原本と確認し、汎用・freee・MFクラウド・弥生向けCSVへ。確認済みの科目を変更すると未確認へ戻るため、CSV前に再確認してください。

初期データで領収書に選べる科目は69、カテゴリーは13。全マスターは74科目で、残る5科目は支払元・事業主等に使います。カテゴリーは補助科目ではなく、CSVには選んだ科目名を出します。[科目一覧](https://github.com/studio-yebisu/ryoshu/blob/e79394d7349efc15aadb2dc02f6fe381596b407d/docs/ACCOUNTS.md)

原本・金額・科目・用途は必ずご自身で確認し、税務上の最終判断は税理士に確認してください。科目候補・カテゴリーは経費算入の可否を確定するものではありません。

## 更新・バックアップ

v1.3は科目カテゴリーを保存するためDBをスキーマ3へ更新します。更新前に暗号化バックアップを保存してください。更新前の暗号化スナップショットを保存し、既存明細・仕訳・独自科目を保持します。更新したDBは旧アプリで開けません。旧版へ戻す場合は、更新前のバックアップを別の保存先へ復元してください。 [導入・更新の手順](https://github.com/studio-yebisu/ryoshu/blob/e79394d7349efc15aadb2dc02f6fe381596b407d/docs/INSTALL.md)

準備後の処理はPC内で行い、外部AIのアカウントやAPIキーは使いません。DB・保存済み原本・プレビュー・バックアップは暗号化。書き出したCSV・原本は平文です。

## 今回の検証

新規100件：金額・円額未確定97/97（返金3件除外）、日付99/100、暫定科目44/48、科目/保留条件86/100。非負の円額95件と円額未確定2件を評価。返金3件は除外。 暫定科目は、提案を期待する48件が対象です。

暫定科目はv1.2の47/48から44/48、科目/保留条件は89/100から86/100になりました。新たな不一致のV032・V067・V093は、両版とも候補が外注工賃です。旧版では外注費をその別名として照合しましたが、今回は別々の正式科目に分離したため、不一致を保持しています。他の一致判定の状態は同じです。V050の賃借料→リース料は、どちらの版も許容候補と一致しました。元の期待値は変更せず、説明による加点もしていません。

税額の別評価63件：印字税額51/52、空欄11/11。数値を期待した空欄1件、誤った数値0件。評価対象外の返金3件に残った税額候補は登録停止のままで、成功件数へ加えていません。 税額評価は返金3件と外貨2件を実行前から除外しています。 V013は553円が印字されていますが、税額ラベルを特定できず空欄でした。 事前期待値・対象外・個別差異は検証記録を確認してください。

改善にも使った同じ架空100件の回帰検証であり、未知の実物領収書の正答率ではありません。AIの摘要を含め、出力は原本と照合してください。 Python256、JavaScript5、通常画面28・保護画面10・UX8・科目操作8項目、CSV4形式。実会計サービスへの取込は未実施です。実HTTP18項目と依存・native監査は過去の記録で、今回の検査には数えません。

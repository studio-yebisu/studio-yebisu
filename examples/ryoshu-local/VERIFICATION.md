# 今回の改訂と確認範囲

アプリv0.4は、取り込み→OCR・AI候補→未確認の帳簿作成→あとから確認・修正→会計ソフト向けCSVの順序です。確認前でも帳簿を表示し、未確認を含む汎用CSVを出せます。既定で途中の1件ずつの確認を挟みません。設定で確認を先にする流れへ切り替えられます。

新しい順序、一括確認、入力済み項目の保持、更新競合、設定保存を71テストと保存済み架空4例の画面操作で検査しました。新しいOCR・AI推論はしていません。[アプリの機能検査](workflow-verification.json)

映像の描画・タイムラインは最初の制作と今回の改訂ともOpus5.5が執筆。制作担当はCanvas設定、結果の見出し、縦配置の余白、未確定の金額を含む指標名等を調整し、ページ・書き出し・確認・公開を担当しました。

主版は16:9・1920×1080、32秒・30fps・960フレーム・無音。縦版は720×1280で別配置です。両版の任意時刻再描画、別ページの再現、メタデータと全編デコードを検査。32秒の実MP4再生と代表場面、PC1280px・スマートフォン375pxの表示・保存済み4例の操作を確認しました。利用者本人の視聴承認を取得済みとはしていません。

動画とページに元の100件の結果を表示しています。

| 指標 | 一致数 / 評価数 |
| --- | --- |
| 金額・円額未確定の扱い | 97 / 97 |
| 日付 | 99 / 100 |
| 店名 | 86 / 100 |
| 暫定科目 | 47 / 48 |

金額は返金3件を分母から除外。暫定科目は候補を評価する48件が対象です。同じ100件で改善した架空の回帰検査で、未知の実物領収書での正答率ではありません。元の検証は全件未確定です。今回の操作検査で確認した4例は、別の架空データ用DBです。

初回の依存・モデル取得にはネット接続が必要です。準備後のOCR・AI判断・帳簿保存はローカルで動作します。会計ソフトの実アカウントへのCSV取込は未検証です。[詳細](verification.json)

## v1.0.0の追加記録

ファイル・フォルダー・ドロップでの一括取り込み、PDFのページ分割、進捗・停止・再試行、あとからの一括確認、4形式のCSV、検証付きバックアップ復元に対応します。130件のPython検査・28項目の実ブラウザー操作が成功しました。画面検査のOCR・AI値は保存済み結果の再現です。

別に原本100件のOCR・AIを新規実行し、家賃の誤提案を修正して再実行しました。金額・円額未確定97/97（返金3件除外）、日付99/100、店名86/100、暫定科目47/48。全100件のソース、最終科目データでの条件差分照合と3件の新規読取は別々に記録します。元の架空100件は修正にも使った回帰データです。映像と4件の保存済み例はv0.4時点の記録を保持します。

原本・金額・科目・用途は必ず本人が確認し、税務上の最終判断は税理士に確認してください。確認済みは本人の操作で、税理士の承認・法的適合の証明ではありません。アプリの専門家による法務審査は未実施です。

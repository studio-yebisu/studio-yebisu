本文を取り出す読書室

Webページには、記事の本文のほかに、ナビや広告、関連記事や購読の案内が並んでいます。Defuddleは記事の本文とタイトル・著者を見つけて、Markdownにします。架空の3つの記事で、取り出す前と後を見比べてください。

1記事を選ぶ

取り出す記事

上下・左右の矢印で記事を選べます。選んだ記事でEnterを押しても取り出せます。記事を切り替えると、前の結果は消えます。

2本文を取り出す

このページに同梱した Defuddle 0.19.5（固定コミット 556d74e からビルドした full 版）を、このブラウザーの中で実行します。ネットからの取得、AIへの通信、外部サービスへの切り替えはありません。

new Defuddle(
  new DOMParser().parseFromString(html, 'text/html'),
  { url: sample.url, markdown: true, useAsync: false, removeImages: true }
).parse()

記事の一覧を読み込んでいます。

      この作例について
      
        
        
          
      • 3つの記事は、この作例のために書いた架空のページです。実在の催し・アプリ・調査ではありません。読み込むのはこの3つのHTMLだけで、任意のURLを入力する機能はありません。
        • 
          
      • Markdownにすると、元のページの色・配置・文字の大きさは残りません。残るのは見出し・段落・リストなどの文章の構造です。
        • 
          
      • この3つでうまく取り出せても、インターネット上のどのページでも同じように取り出せるとは限りません。
        • 
          
      • extraction-results.json は、制作時にNode.jsとjsdomで同じ3件を取り出して保存した実出力です。このページでいま取り出した結果とは別のファイルです。
        • 
          
      • samples.json（入力のHTMLと照らし合わせる語句）・解説動画のソース・再現の手順

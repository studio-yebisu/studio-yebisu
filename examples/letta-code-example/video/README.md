# 解説動画の編集ソース — Letta Code 記憶の点検（32秒・ナレーションつき）

記憶のメモ・stage の変更・Letta の点検・Git の保存を1つの大きな図にして、32秒で動かす映像のソースです。縦 720×1280（本編）と横 1280×720 を、同じ時刻表から別々の配置で描きます。

```text
ルート → 案内 → 2つの詳細      変更（stage）→ 点検（門）→ 保存（Git の点）
```

| 時刻 | 場面 | 記録 |
| --- | --- | --- |
| 0–5.3秒 | メモを変えたら、点検 | L01 の形（結果は描かない） |
| 5.3–9.6秒 | 案内がないと、止まる | L02 |
| 9.6–15.1秒 | 案内を戻した、別の試行 | L03（別の新しいリポジトリの記録） |
| 15.1–22.8秒 | 止まっても、変更は残る | L02 に戻る |
| 22.8–29秒 | 点検と、正しさは別 | L03 |
| 29–32秒 | 理由を見て、必要な所を直す | L03（同じ図を3秒保つ） |

場面・物・時刻・音・素材・言えることの範囲は [storyboard.json](storyboard.json) にあります。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 編集画面（プレビュー・場面の一覧・素材の照合結果） |
| `video.js` | canvas に時刻 t の1枚を描くコードと、素材の照合 |
| `video.css` | 編集画面の見た目。書き出しのときは canvas だけを出す |
| `storyboard.json` | 場面・ナレーション・配置・続き方・素材・範囲の設計 |
| `assets/` | 固定した8素材と `manifest.json`（制作側が用意。このフォルダーの外の工程で作ったもので、編集しない） |

## プレビュー

`fetch` と Web Crypto で素材を照合するため、`file://` では開けません。作例のフォルダー（`index.html` のある場所）でローカルの HTTP サーバーを起動して開きます。

```text
python -m http.server 8000
```

- 縦：`http://localhost:8000/video/`
- 横：`http://localhost:8000/video/?layout=wide`

操作：

- **再生／一時停止**：押したときだけ、照合済みの `narration.wav` を1本だけ鳴らし、映像はその再生位置に合わせて描きます。自動再生はしません。音を再生できないブラウザーでは、そのことを表示して映像だけを進めます。
- **先頭へ**：再生と音を止め、0秒の画を描きます。
- **消音**：音だけを消します（映像の時計は同じ）。
- **時刻のつまみ**：音を止め、その時刻の画を描きます（`window.seek` と同じ）。
- **場面の一覧**：押すとその場面の代表の時刻で止まります。
- 最後まで再生すると止まり、32秒の画のままになります。もう一度押すと先頭から再生します。

ナレーションの文は、画の下に表示します（図の代わりにはしません）。

## 照合と失敗したとき

描く前に、次をすべて確かめます。1つでも合わなければ `window.motionReady` を拒否し、canvas を隠し、再生などの操作を止め、理由と「もう一度読み込む」を出します。代わりの記録や仮の画は持っていません。「もう一度読み込む」は manifest と8素材を最初から取り直します。

1. `assets/manifest.json` の SHA-256 が `video.js` に固定した値（`abbf4355…4653`）と一致する。
2. manifest の8件の名前・SHA-256・バイト数が `video.js` の固定値と一致し、8素材すべての実際の SHA-256 とバイト数が一致する。
3. `memory-runs.json`：形式、Letta Code の固定版（`316e4c0`・0.34.14・Apache-2.0）、原典8ファイルが `vendor-lock.json` と一致、入力とロックの SHA-256、初期方針、L01〜L08 の8件（重複なし）、各件の commit の成否・HEAD・stage の整合、件数 8／2／6、確認208件がすべて合格。
4. `memory-changes.json`・`expected.json`：8件の入力が記録と同じで、実行前の期待（成否・件数・L02/L03 の組）と一致する。
5. `independent-checks.json`：合格、この記録の SHA-256、8つの Git リポジトリの照合、原典 hook の SHA-256、L02/L03 の違いが `bookclub/MEMORY.md` だけ。
6. `reproduction-checks.json`：合格、記録の全バイトの再現、成否 2／6。
7. `narration-cues.json`：5文の文・seed・時刻・ファイル・SHA-256・バイト数と6場面の時刻・見出し・記録が `video.js` の固定値と完全に一致する。
8. `narration.wav`：PCM16・モノラル・48000Hz・ちょうど32秒で、5つの区間それぞれに音がある（RMS）。
9. 図の場面が依って立つ事実：L01 は案内ありで1件の変更、L02 は案内を消して止まり stage に2件残った、L03 は L02 との違いが案内だけで保存され stage が空。

ページの短いハッシュと件数（基準の点、L03 の新しい点、台の件数）は、照合を通った記録から読みます。

## 書き出し（縦・横）

書き出しは作例のフォルダーの `render.py` が、同梱の `tools/motion-reel/render.mjs` を使って行います。Node.js 20 以上・Chrome・FFmpeg と ffprobe が要ります。初回だけ `tools/motion-reel/` で依存を入れます。

```text
cd tools/motion-reel
npm install --ignore-scripts
```

出力先は毎回、**このソースの外の、空のフォルダー**にします。`render.py` はソースの中や、空でないフォルダーへの出力を拒否し、既存の書き出しを上書きしません。

```text
python render.py --out <ソースの外の空のフォルダー> --width 720 --height 1280
python render.py --out <ソースの外の別の空のフォルダー> --width 1280 --height 720
```

- `render.py` は作例のフォルダーを一時的な場所へ写してから描くので、ソースは変わりません。
- レンダラーは `window.renderConfig` の幅・高さ・FPS を渡し、`window.__MOTION_RENDER__` を真にします。映像はそのサイズの配置で描き、プレビューの音とタイマーは止まります。
- 音は同じ `video/assets/narration.wav` を `--audio` で渡し、レンダラーがラウドネスを揃えて AAC にします。音楽や効果音は足しません。
- `--stills-only` で静止画だけを書き出せます。

縦は `media/letta-code-example.mp4`、横は `media/letta-code-example-wide.mp4` として掲載されます（掲載は制作側の工程）。

## ナレーション

Aratako/Irodori-TTS-v4.1-Small（リビジョン `2b28324dc263ed5e6638b3cf3dd94c82ead07b4b`・MIT License とモデルカードの利用上の制限）で、制作側が5つの文を実際に合成したものです。声は caption から作ったオリジナルの合成の声で、実在の人の録音や声のまねは使っていません。5つの文を重ならないように sample 単位でそのまま並べ、無音で32秒にそろえた `narration.wav` だけを使います。モデルの重みは同梱していません。

聞いた印象・自然さ・読みの正しさの確認、人による承認、実機の iPhone・Safari での確認は記録にありません。

## この映像が示す範囲

- 図の状態は、制作時に固定版 Letta Code の原典の検査を実際の Git の pre-commit で動かして保存した記録（L01・L02・L03）から決めています。映像の中で原典・Git・エージェント・AI は動きません。
- 案内のカードが枠へ戻る動きは、別の新しいリポジトリで試した L03 の記録を見せる絵です。その場の修正やエージェントの操作ではありません。
- 点検は記憶の形の検査です。通っても、中身の正しさ・事実の正確さ・人の承認・セキュリティの保証ではありません。
- L04（上限を超えたメモ）・L05・L06・L07・L08（設定の保護）は映像に入れていません。作例ページと `../comparison.html` で確かめられます。

## 書き出し後の確認

32秒・30fps・960フレームの縦版720×1280と横版1280×720を、実生成した日本語Irodori-TTSナレーション5区間と同じ時刻で書き出しました。代表・連続・スマホ幅・終端の画、別順序と新ページの同時刻PNG一致、全デコード、ブラウザーでのMP4再生終了と編集ソースの実音源再生・シークを確認しました。音声の聴取、人による承認、実機iOS/Safari/VoiceOverは未確認です。

音源は5区間のTTSを編集せず無音の間を空けて配置した32秒PCMです。各cueの原PCMとの一致を確認し、MP4ではMotion Reelが音量調整とAAC圧縮を行っています。原典API/Gitの入力と結果は改修前のものを保全しています。

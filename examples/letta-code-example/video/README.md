# 動く概念図・無音の編集ソース

32秒・30fps・960フレーム。縦720×1280と横1280×720に対応し、大きな概念図と短いラベルで説明します。音声ガイドはなく、MP4にも音声トラックはありません。

作例のフォルダーをHTTPで配信し、video/index.htmlを開きます。再生・一時停止・先頭へ・時刻のスライダーで確認できます。7素材とmanifest.jsonのSHA-256が一致してから表示し、失敗時は停止して「もう一度読み込む」で再試行します。window.seek(seconds)は任意時刻の完成した画を描きます。

作例フォルダーからの書き出し例（FFmpeg、Nodeとtools/motion-reelの依存を用意）：

```text
python render.py --out ../render-portrait --width 720 --height 1280
python render.py --out ../render-wide --width 1280 --height 720
```

出力はソースの外の空フォルダーを指定します。音源や--audioは渡しません。今回公開する動画は、従来の完成MP4からビデオpacketを変えずに音声トラックだけを除いたものです。図と動きのOpus制作範囲は保持し、音声ガイドの除去と無音の再生UIは制作側の変更です。原典の実入力・出力・固定版はそのままです。図は機能の実行記録を説明するもので、ライブ動作の録画ではありません。

      図の状態（案内の有無とつながり、stage の件数、点検の門が止めるか通すか、Git の点の数と短いハッシュ）は、制作時に固定版 Letta Code 0.34.14 の原典の検査と実際の Git の commit で実行して保存した記録（L01・L02・L03）から決めています。本・メモ・門・台の絵は関係を見せるための図で、画面の録画やその場の実行ではありません。案内のカードが枠に戻る動きは、別の新しいリポジトリで試した L03 の記録を見せる絵で、ライブの修正やエージェントの操作ではありません。

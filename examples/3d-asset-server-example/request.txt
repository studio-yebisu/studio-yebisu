Webの小さなシーンに置くCC0の木箱を、固定版 3D Asset Server の原典コードで探し、利用条件と容量を取得の前に確かめてから、実物のファイル一式を取得して3Dで確かめる作例を作ってください。原典の関数と Poly Haven が実際に返した値・例外・取得したファイルをそのまま保存し、スマホで読める日本語のページで、候補・利用条件・容量・予算で止まった例・取得した実物を確かめられるようにしてください。

入力（ここを差し替える。実行の前に固定し、結果を見てから変えない）
・目的：Webの小さなシーンに置く、CC0の木箱を1つ
・配信元：polyhaven と fab の2つだけを有効にする
・User-Agent：自分の作例を識別できる名前（この作例では Studio-Yebisu-3D-example/1.0 (+https://studio-yebisu.github.io/yaoyorozu-ai-toolbox/)）
・予算：1回の取得で 4194304 バイト（4MiB）まで
・操作：A01 検索（wooden crate・model・無料・3件）、A02 詳細と利用条件、A03 1k の glTF の選択と容量、A04 8k を予算付きで取得しようとする、A05 配信元の無いID、A06 未登録の配信元、A07 Fab だけを直接取得できるものに絞った検索、A08 1k の glTF 一式の取得
・期待：選ぶ素材のID・ライセンス・作者・1k のファイル数と合計バイト数・止まる操作の例外の名前を、実行の前に別のファイルへ書く

進め方
1. 原典のソース・原典の build:server が出力した dist/ の JS・three・ロック・入力の SHA-256 を照合する。原典の package-lock.json どおり npm ci で依存を入れ、原典の build:server で dist/ を作る。照合の後でだけ、dist/ の AssetService・createHttpClient・polyhaven・fab・selectFiles・totalBytes・expandFiles・downloadFiles を読み込む。配信元や関数を書き直したり、代わりのものに差し替えたりしない
2. ASSET_SERVER_USER_AGENT に識別できる User-Agent を入れてから原典の http を読み込み、createHttpClient の fetchImpl には Node の fetch を、レスポンスを複製して記録するだけの包みで渡す。内容や結果は変えない。通信の全文は公開しないフォルダーにだけ残す
3. A01 は AssetService.search に入力をそのまま渡し、候補・ライセンス・作者・配信元ごとの状態（ok・link・skipped）と tookMs を残す。A02 は getAsset で利用条件・形式・ファイルを見る。Web の three.js には glTF を選ぶ
4. A03 は selectFiles と totalBytes・expandFiles で、取得の前に glTF・bin・画像の全ファイルと合計を出す。A04 は 8k を maxBytes 4MiB で downloadFiles に渡し、通信の前に止まること・取得の通信が0件で保存フォルダーが作られないことを確かめ、原典の例外をそのまま残す
5. A05・A06 は原典の InvalidAssetIdError・UnknownProviderError をそのまま残す。A07 は Fab が skipped（エラーではない）になり、Fab へ通信しないことを確かめる
6. A08 は A03 と同じ選択を downloadFiles で非公開のフォルダーへ取得する。相対パスを保ち、ファイルを作り直したり圧縮し直したりしない。各ファイルのバイト数・SHA-256・MD5 を、Poly Haven の files API の size・md5 と通信の記録に照らす。glTF 2.0 として読み、buffer と画像の参照がすべて同じフォルダーの実ファイルを指すこと、アクセサーが buffer の中に収まること、メッシュと三角形の数を実ファイルから数える
7. 結果を得た後でだけ期待のファイルと照らし合わせる。すべての確認が通ったときだけ、記録の JSON と取得した実ファイル、info・files API の応答を outputs/ に1回だけ書く。既にある記録は上書きしない。絶対パス・時刻・認証情報・カタログ全体の応答は公開しない。失敗したら非公開の証拠だけを残して止める

ページでできること
・最初に A08 の取得した木箱を、取得したファイルそのものから three.js の GLTFLoader で3D表示する。読み込む前に全ファイルのバイト数と SHA-256 を記録と照合し、代わりの形やサムネイルは出さない。左右に回す・向きを戻す・線で見るのボタンで確かめられ、自動では回さない
・作者・配布元・ライセンス（James Ray Cock / Poly Haven / CC0）と、「1k・glTF + bin + 3枚の画像・約2.17MiB」のような中身と容量を、記録の値から表示する
・8件を選び、A01 の3件の候補と配信元ごとの状態、A04 の予算超過の実際の例外と超過したバイト数、A07 の skipped がエラーではないことを読む。A04 から A03・A08 へ移れる
・各操作の入力と記録の JSON は折りたたみで全文を開ける。取得したファイルのバイト数・SHA-256・MD5 も開ける
・記録・入力・ロックを取得し、固定版・SHA-256・8件の入力・確認の合否を照合してから表示する。合わなければ理由と「もう一度読み込む」だけを出す
・選んだ1件の記録を JSON で保存し、A08 ではモデル一式の ZIP も保存でき、この依頼文をコピーできる
・320px幅のスマホから1280px幅のパソコンまで横スクロールなし。操作部品は44px以上、入力欄の文字は16px以上。外部のフォント・CDN・計測・AI の呼び出しは使わず、Poly Haven のサイトの画像やロゴも読み込まない

書かないこと
・2つの配信元で試した結果を、原典が対応する全配信元を試したように書かない
・既にある素材の検索と取得を、3Dモデルの生成として書かない。モデルを作った人と、コードや文章を書いた AI を混同しない
・保存した記録を、ページを開いたときの最新の検索結果として書かない。tookMs や順位は再実行で変わる
・公開サーバー 3d.shep.bot・HTTP API・MCP の通信路・Web 画面・アカウント・API キー・有料素材・Blender やゲームエンジンへの組み込みを試したように書かない
・ファイルの一致と glTF の構造の確認を、見た目の品質や本番での性能の確認として書かない

最後に、作ったファイル、実際に実行したコマンドとその結果、まだ確かめていない点を分けて書いてください。

      確かめた範囲と、確かめていないこと
      
      
        
        
      • 配信元は2つだけ。原典が持つ多数の配信元のうち、この作例で有効にしたのは Poly Haven（API で検索・取得）と Fab（リンクだけ）です。ほかの配信元は試していません。
        • 
        
      • Fab へは通信していません。原典の Fab はサイト内検索への URL を作るだけで、候補もファイルも返しません（A01 の link、A07 の skipped）。
        • 
        
      • 新しい3Dモデルは作っていません。このツールは既にある素材を探して取得するもので、表示している木箱は James Ray Cock さんが制作し Poly Haven が CC0 で配布しているものです。
        • 
        
      • 公開サーバー 3d.shep.bot、HTTP API・MCP の通信路、Web 画面、アカウント・API キー、有料素材、Blender やゲームエンジンへの組み込みは使っていません。動かしたのは原典のライブラリの関数と、事前の CLI 検索だけです。
        • 
        
      • 検索の順位・件数・tookMs・メタデータは、Poly Haven の側で変わることがあります。再実行で同じ値が出る約束ではありません。固定しているのは原典・入力・この記録と取得ファイルのハッシュです。
        • 
        
      • 確かめたのはファイルの一致と glTF の参照・構造です。見た目の品質、ゲームや本番サイトでの性能、人による承認は確かめていません。

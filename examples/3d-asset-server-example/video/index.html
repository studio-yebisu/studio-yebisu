3D Asset Server 作例・図解動画の元ページ

既存の3D素材を探し、一式で受け取る図解32秒・無音（縦 720×1280・30fps）

作例ページと同じ25件の素材を照合してから、同じ概念図を時刻ごとに描きます。手順書の本と依頼、AI（Opus）が書いた run.mjs、制作担当によるNodeでの実行、原典の AssetService、Poly Haven と Fab、候補の木箱、予算のゲート、保存フォルダー、実物の表示までが、同じ形のままつながります。値はすべて元の実行で保存した記録と実ファイルから読み、検索・取得・AIの実行はしていません。音もありません。

場面

  1. 0〜4秒既存の3D素材を探し、一式で受け取る：手順書の本が開き、検索・確認・取得の見出し札と規則の5つの印。隣に、検索・取得の道具（原典の AssetService と2つの配信元）の形。3Dを作る絵ではありません。
  2. 4〜8秒渡す：依頼の札と本の写しが AI（Opus）へ合流し、AIが書いた run.mjs が制作担当へ渡ります。Nodeで実行したのは制作担当で、AIではありません。
  3. 8〜14秒配信元へ振り分ける：Poly Haven から候補3件、Fab からは検索URLだけ（通信なし）。選んだ木箱に CC0 と glTF 1k の札。候補と状態は A01 の記録から。
  4. 14〜20秒取得の前に容量を比べる：同じカードが5つのファイルに開き、A08 の 1k（2,277,087 B）は予算の内側、A04 の 8k（118,636,175 B）は脇道で止まります。別々の記録で、自動の再試行や切り替えではありません。
  5. 20〜26秒受け取る：1k の5ファイルが相対パスのままフォルダーへ合流し、実物の木箱の静止画（制作担当が実3D表示を撮ったもの）と出典。Fab の欄に A07 の skipped が短く出ます。
  6. 26〜29秒保存した実物を使う：フォルダーに ZIP、実物の表示に実3Dの札。映像の中で端末の保存はしていません。
  7. 29〜32秒全体の経路を同じ濃さで静止（入りは28.3〜28.9秒、ポスターは31秒）。

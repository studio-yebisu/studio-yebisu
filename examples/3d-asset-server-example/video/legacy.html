      この映像が示す範囲

      固定版 arielshad/3d-asset-server（コミット f605df3425011bae55ade114c9e7b276f5b1297b・0.1.0・Apache-2.0）の、原典の build:server が出力した改変なしの AssetService.search・getAsset・selectFiles・totalBytes・expandFiles・downloadFiles を、実際の Poly Haven API に使った8件の操作の記録です。通信は Poly Haven の API 3件とファイル配信 5件の計8件だけで、Fab はリンクだけを返す配信元のため通信していません。

      原典のスキルの手順どおり、短い語で探し、利用条件と形式を見て、取得する全ファイルの合計を取得の前に確かめてから取得しました。8k の一式（118,636,175 バイト・約113.14MiB）は予算 4,194,304 バイト（4MiB）を超え、原典の downloadFiles が取得の通信を出す前に止めました。原典の例外の文は 1024 進の値を MB と表記しています（113.1 MB）。1k の一式（2,277,087 バイト・約2.17MiB）の5ファイルは、大きさと MD5 が Poly Haven の files API の値と一致しました。

      独立した Python の確認212件は、原典のファイル・Poly Haven の値・取得した glTF のバイナリ（メッシュ3・三角形6,576・頂点4,686）を確かめたものです。通信なしの再生29件は、別の Node のプロセスで、保存した実際の応答を使って原典の関数を動かし直し、5ファイルがバイト一致したことを確かめたもので、Poly Haven へもう一度問い合わせた結果でも、検索の時間が同じになる約束でもありません。

      映像の木箱は、閲覧ページで three 0.180.0 の GLTFLoader が照合済みの5ファイルを描いた実画面の切り抜きです。2枚の向きは、スマホが最初の向き、パソコンが「右へ回す」ボタンを2回押した向きで、自動回転や生成した映像ではありません。閲覧ページはこの作例の独自の表示部で、原典のアプリ全体の画面ではありません。

      試していないもの：原典が持つほかの配信元、新しい3Dモデルの生成、公開サーバー 3d.shep.bot・HTTP API・MCP の通信路・原典の Web 画面、アカウント・API キー・有料素材、Blender やゲームエンジンへの組み込み、見た目の品質や本番での性能、実機の iPhone Safari・VoiceOver、人による承認。

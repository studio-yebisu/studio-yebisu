何が入っていて、どう渡し、何が返るか

      

        

          
どんな道具か

          
既にある3D素材を探し、利用条件と容量を確かめてから、取得できるファイルを持ってくる道具です。原典はライブラリ・CLI・REST・MCPとして使えるコードと、AIが読むMarkdownの手順書（SKILL.md・AGENTS.md）でできています。3Dモデルや画像を作るものではありません。

        

        

          
中にあるもの

          
手順書には、検索 → ファイルと容量の確認 → 取得 の3手順と、IDの書き方・用途で選ぶ形式・ライセンスとクレジット・直接取得できないときはURLを案内・大きい容量は先に確認、の5つの規則。コードには、配信元へ振り分ける AssetService と、selectFiles・totalBytes・expandFiles・downloadFiles があります。

        

        

          
今回：Nodeの原典関数

          
依頼と手順書を読んだ元のAI（Opus）が run.mjs を書き、制作担当がそれを別の工程でNodeで1回実行して、原典のライブラリ関数を呼びました。AIが自分でCLIやサーバーを動かしたのではありません。有効にした配信元は Poly Haven と Fab の2つだけです（原典は23の配信元に対応しますが、ほかは試していません）。

        

        

          
返るもの

          
候補と利用条件、取得の前に分かる合計バイト数。予算を超えれば取得の前に例外で止まり、通れば相対パスを保ったファイル一式が届きます。今回の1kは gltf + bin + 画像3、合計 2,277,087 B でした。

        

      

      

        他の入口：MCP・REST（今回は未実行）
        
原典の AGENTS.md には、公開サーバーの MCP と REST API を使う手順も書かれています。この作例では公開サーバー・REST・MCP・Web画面のどれも使っていません。図の点線の札は、手引きにある入口を示すだけで、実行の記録ではありません。

            問い（照合後に表示）

            • 資料は、制作担当がこの作例のために書いた架空のメモ3件・15行です。実在の顧客や店舗の調査ではありません。
            • どの発言も架空の参加者の自己申告です。操作の観察・分析ログ・アンケート・売上・効果の測定は含みません。
            • 「1/3人」などの人数は、この3人の中の数です。利用者全体の割合や市場の大きさは分かりません。
            • 確からしさ（中が3件・低が2件）と優先順は整理者の定性的な判断で、点数の式は使っていません。順は暫定です。
            • 提案R01〜R05は試作と追加調査の案で、どれも実装・テストしていません。効果は分かりません。
            • 整理は制作時に Claude Opus 5.5 が固定版の SKILL.md を読んで1回行い、保存しました。人によるレビューや複数人でのコード付けの照合は受けていません。
            • プラグインの導入、スラッシュコマンド、MCPコネクターは使っていません。メモは手元のファイルとして渡しました。
            • この図は保存済みの整理を描き直したものです。図の配置・短いラベルは見せ方で、新しい分析ではありません。

# 解説動画の元ページ — まとめた理由を、原文までたどれる。

28秒・30fps・1280×720（840フレーム）の**無音**の解説動画を描く、編集できるHTMLです。架空のヒアリングメモ3件（15行）に固定版の Synthesize Research を制作時に1回適用した**保存済みの整理**を、発見から原文の行までたどり、選んだ発見を Markdown で保存するところまでを、実画面の静止キャプチャと実際のファイルで組み直しています。続けて録画した映像ではありません。音声トラック・音楽はありません（`audioEvents: []`）。

- このページでも映像でも、AIは動きません。新しい整理を行う機能はなく、描く文字は読み込んだファイルから取り出します。
- メモは制作担当が書いた架空のもので、すべて架空の参加者の自己申告です。実在の顧客調査・操作の観察・分析ログ・効果の測定は含みません。人数は「この3人のうち何人か」です。
- 提案は、これからの試作と追加調査の計画です。作った予約画面・採用・測った効果はありません。
- 人による承認は受けていません。

## ファイル

| パス | 内容 |
|---|---|
| `index.html` | 元ページ（プレビューと書き出しの入口） |
| `video.js` | 描画・読み込み・照合・プレビューの操作 |
| `video.css` | 元ページの見た目。CSSのアニメーションは使わない |
| `storyboard.json` | 場面の設計（時刻・入りと出・伝えること・素材・範囲） |
| `assets/` | 実画面6枚・`screen-manifest.json`・`data-hashes.json`（制作側で固定。この映像の作業では変更していない） |

## 映像が読むファイル

`window.motionReady` は、まず `assets/data-hashes.json` を読み、そのSHA-256が制作記録（`runtime/frozen-reviewed-source.json`）の値 `f0cfc61e…5b90` と同じかを確かめます。次に、そこに並ぶ11ファイルを1件ずつ読み、SHA-256を照合します。パスは作例フォルダーからの相対で、`new URL('../' + path, import.meta.url)` で解決するため、書き出し時に `<base href="video/">` が入っても同じ場所を指します。

| ファイル | 使い方 |
|---|---|
| `input/interviews.json` | 問い、参加者の区分、原文の行（P01-L02・P02-L04・P03-L02・F03の3行） |
| `outputs/synthesis.json` | 発見5件の題・人数・確からしさ、F05・F03の根拠と反する発言、F03の要約の最後の文 |
| `outputs/browser-selected.md` | 保存した F05 の Markdown（保存時の名前 `synthesis-F05.md`）の行をそのまま抜粋 |
| `outputs/browser-complete.json` | 値が `synthesis.json` と同じことを確かめる（画面には出さない） |
| `video/assets/screen-manifest.json` | 実画面の大きさ・SHA-256・撮影時に選んでいた発見・DOMの範囲（近似） |
| `video/assets/*.png`（6枚） | 実画面。照合したバイト列から一時URLで画像にし、読み込めたらURLを片づける |

読み込み時には、ほかに次を確かめます。どれかが合わないと準備は失敗し、理由を画面と状態の欄に出します。代わりの内容は描きません。

- 参加者3人・各5行・計15行、観察15件・発見5件。15件の引用が同じ行IDの原文と完全に一致する。
- 各発見の人数が、根拠の観察の別々の参加者の数と一致する。反する発言の行は支持の行に入らない。提案の発見IDが実在する。
- F05 の支持は P03-L02 の1人、反する発言は P02-L04。P01-L02 は要約で触れられ、どちらにも数えない。
- F03 の3つの抜粋が、それぞれの本文に完全に含まれる。「控え」「当日の変更」は本文にあり、P03-L05 は種類が「未定」。
- Markdown に F05 の見出し、`1/3人（P03）`、P03-L02 と P02-L04 の引用の行、次の一歩、固定原典のURL、架空である旨がある。
- 実画面の大きさが記録と同じ。切り抜きが画像の内側にあり、記録したDOMの範囲（発見の一覧・支持と反する発言の欄・P02-L04の行）を含む。

照合済みの数は状態の欄に出しますが、映像の中では品質の点数や売りとしては扱いません。

## 場面と切り抜き

切り抜きは画像の画素座標で、等倍率で置きます（伸縮・文字の合成はしません）。DOMの範囲は全体撮影のあとに記録した近似値で、スクロールバーの有無で横が最大15pxほどずれうるため、余白を広めに取っています。枠の位置も近似です。

| 時刻 | 段階 | 伝えること | 切り抜き（x, y, w, h → 倍率） |
|---|---|---|---|
| 0〜4.5秒 | メモ | 問いと、空き日の探し方の原文3行 | `phone-initial.png` 0, 0, 375, 420 → 0.98 |
| 4.5〜7.5秒 | 発見 | 発見は5件。どれも暫定 | `desktop-first.png` 78, 612, 374, 420 → 1.08 |
| 7.5〜14秒 | 発見 | 月表示を望むのは1人。反する発言は支持に数えない（ポスター13.5秒） | `desktop-calendar.png` 465, 1076, 720, 560 → 0.86。枠：支持 474, 1086, 702, 266／反する発言 474, 1358, 702, 268 |
| 14〜18秒 | 原文 | 引用から、原文の同じ行へ | `desktop-origin.png` 72, 2890, 1136, 250 → 0.98。枠：P02-L04 99, 2980, 1082, 82 |
| 18〜23秒 | 原文 | 用途の違い（控え・当日の変更・未定）も残す | `desktop-notifications.png` 465, 1104, 720, 532 → 0.76（支持する発言の見出しと上の2件） |
| 23〜28秒 | 保存 | 保存した synthesis-F05.md と、スマホ幅の F05 | `phone-calendar.png` 0, 0, 375, 812 → 0.58 |

実画面に写っているフォーカスの輪郭（キーボード操作のもの）は、実際の画面の一部なのでそのまま残しています。全体撮影の desktop 画面の下部には P02 のメモが開いた状態で写っていますが、別の操作の状態として数えてはいません。撮影していないクリックや保存完了の表示は作っていません。

上の段階表示「メモ → 発見 → 原文 → 保存」と、足元の「架空メモ3件・保存済みの整理／無音・実画面を編集」は全時刻で表示します。

## 時間の契約

- `window.motionConfig = {duration: 28, fps: 30, width: 1280, height: 720, posterTime: 13.5, audioEvents: []}`。`window.renderConfig` の幅・高さ・FPSを最初に反映します。
- `window.seek(seconds)` は、その秒だけから完成した1フレームを描きます（毎回 canvas を初期化し、変換・クリップ・透明度を戻す）。壁時計・乱数・タイマー・前のフレームの積算は使いません。入りと出は時刻の純粋な関数です。
- 描画は論理座標1280×720で組み、別の縦横比では等倍率で収めて余りを紙の色で埋めます。別の縦横比のレイアウトは作っておらず、確認もしていません。
- 書き出し時（`window.__MOTION_RENDER__`）は canvas だけを表示し、プレビューの操作やタイマーは動かしません。

## プレビュー（元ページ）

- 開いた直後は停止しています。自動再生はしません（`prefers-reduced-motion` にかかわらず、「再生」を押したときだけ `requestAnimationFrame` で進み、28秒で止まります）。ボタンの文言と `aria-pressed` は実際の再生・停止に合わせて変わります。
- スライダーは0〜28秒・0.1秒刻み。← → で0.1秒、PageUp・PageDown で2秒ずつ（ブラウザー標準の移動量ではなく、この元ページで2秒に決めています）、Home・End で先頭・末尾。Home から PageUp 7回で14秒です。ボタンとスライダーは高さ44px以上、文字は16pxです。
- 照合が終わるまでは操作できません。失敗したときは理由と「再読み込み」を出します。
- ローカルのファイルだけを読み、外部への通信はしません。`file://` ではなくHTTPで開いてください。作例フォルダーで `python -m http.server 8863 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8863/video/` を開きます。

## 書き出しの手順

作例フォルダー（`site/`）で、Node.js 20以上・Chrome・FFmpeg/ffprobe・Python を用意して次を実行します。出力先は作例フォルダーの外の、空のフォルダーにしてください（既存の出力は上書きしません）。

```
npm ci --ignore-scripts --no-audit --no-fund --prefix tools/motion-reel
python render.py --out ../knowledge-work-render-first
```

`render.py` は作例を一時フォルダーへ写し、`video/index.html` を `<base href="video/">` 付きの入口にして、同梱の `tools/motion-reel/render.mjs` で代表フレーム・コンタクトシート・ポスター・MP4（音声なし）を書き出します。

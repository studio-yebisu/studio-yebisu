# PDF Creator 作例：32秒・無音の動く図（編集ソース）

PDF Creator（AIが読むMarkdownの手順書＋Pythonの変換スクリプト＋CSSテーマ）の中身と、AI・道具へ渡したもの、受け取ったもの、次の使い方を、1つの大きな図で示す映像の編集ソースです。図の部品は消えずに残り、同じ原稿の印が矢印に沿って移動・合流・折り返しをします。

- 書き出しの想定：縦 720×1280 と横 1280×720、30fps、32秒（960フレーム）、ポスター31秒
- **無音**：ナレーション・読み上げ・効果音・音声トラックはありません（`audioEvents: []`）
- 図は保存済みの原制作から描きます。PDFの生成・元のモデル・lintは再実行しません
- 題材は架空のイベントです。開催・申込窓口・外部送信はありません

## ファイル

- `index.html`：映像の画面とプレビュー操作（`#play`・`#reset`・`#replay`・`#end`・`#time`・`#clock`・7つの `data-jump`・`data-orient` の縦横切り替え・`#retry`）
- `video.js`：`window.motionConfig`・`window.seek(秒)`・`window.motionReady`、プレビューの再生
- `video.css`：編集画面の配置。書き出し時（`html.render`）は図だけをビューポートいっぱいに出す
- `storyboard.json`：場面の意図・入る状態・出る状態・出典・未確認の項目
- 図と読み込みの本体は1つ上の `../concept.js`（作例ページと共有）。部品の位置と矢印の経路は `LAYOUTS`、場面の開始秒と見出しは `SCENES`

## 時間の契約

- `window.motionConfig = {duration: 32, fps: 30, width: 720, height: 1280, posterTime: 31, audioEvents: []}`。`window.renderConfig` の width・height・fps を初期化時に反映し、縦横の切り替えでも width・height を更新します。横長なら `wide`、縦長なら `tall` の配置を、その大きさのまま描きます（縦の縮小ではありません）
- `window.seek(秒)` は毎回キャンバスを消してから、その時刻の完成した1枚を描きます。値はその時刻と照合済みのデータだけで決まり、呼び出し順・fps・壁時計・前の描画に依存しません。7.2秒のような任意の時刻も描けます
- `seek` の中ではタイマー・CSSアニメーション・乱数・前フレームの積算を使いません。プレビューの再生は `seek` の外の `requestAnimationFrame` で、`window.__MOTION_RENDER__` が真なら動かさず、操作部も隠します
- 書き出し用のブラウザーが「動きを減らす」設定でも、`seek` の結果は変わりません

## 準備（`window.motionReady`）

次がそろうと解決し、どれかが欠けると失敗（reject）します。失敗したらキャンバスを消し、操作を止め、`#asset-status[data-state=error]` に日本語の理由を出します。`#retry` は23ファイルをすべて読み直します。

1. `concept/manifest.json` のSHA-256が固定値 `ce604633…f99` と一致し、23件の形が正しい
2. 23ファイルそれぞれの長さとSHA-256が記録と一致（WebCrypto）
3. 2つの版のID・寸法・ページ数・PDFのバイト数とSHA-256が、structure・outputs/manifest・samples・validation・元の生成記録で一致。PDFは `%PDF-` で始まり `%%EOF` で終わる
4. 原稿のSHA-256が全記録で共通、backend は chrome、元のモデル受領記録2件（implement・video、claude-opus-5-5）
5. ページ画像3枚の寸法（PNGの見出し）とデコード結果が記録どおり
6. 6部品の引用が原典ファイルの記録した行にある。原稿に固定の架空の注意・流れ6件・持ち物3件（任意1件）・定員12名・日付があり、表がない
7. フォントの準備（`document.fonts.ready`）と、`storyboard.json` の書式・場面が `SCENES` と一致

`file://` では読み込めません。作例フォルダー（この `video/` の1つ上）をHTTPで配信し、`http://127.0.0.1:8000/video/index.html` を開きます（WebCryptoのため HTTPS か localhost が必要です）。

```text
python -m http.server 8000 --bind 127.0.0.1
```

外部のCDN・フォント・モデル・音声認識・音声は使いません。文字はシステムフォントで描くため、別のOSやフォントでは見え方が変わることがあります。

# 入力：同じ日本語原稿を、配布用と細いページ用へ

正本は inputs/event.json。Studio Yebisuが作った架空の紙作品ワークショップ案内です。日付・時刻・料金・定員・持ち物・工程・架空である注意を変えず、日本語のMarkdownへ整えます。表ではなく短い段落・箇条書き・番号付き手順で、参加者が日時と持ち物をすぐ確認できる配布資料にしてください。リンク・申込・送信機能はありません。

PDF Creatorの固定版SKILLと2テーマ、変換コードを読み、原典のmarkdown_to_pdf APIを実際に使います。親が実行するbuild_pdfs.pyは原典をimportし、themes/warm-terra.cssとmobile.cssに今回の和文上書きを足し、HTML langだけjaに直します。元スクリプトは変更せず、WindowsのChrome検出と一時ユーザープロファイルを明示する互換処理を記録します。Pandocはpypandoc_binary1.17経由の実pandocを使い、Chromeを明示します。PythonUTF8を設定します。

A4版(paper)：原典warm-terraテーマの210×297mm、余白12/12/16/12mmを基本に、和文フォントNoto Sans JPを優先。細いページ版(phone)：原典mobileの148×210mm、余白10mm、本文15px/行高1.9を基本にする。同じevent.mdを使い、内容を省略しない。これは可変のWeb画面ではなく、固定ページPDF2種類。ページ数は生成後に記録する（1ページとは決めつけない）。日本語の禁則はCSSのline-break:strict等を意図して使い、実ページで確認する。原典のlintは中国語向けの一部パターンのみで完全な和文保証ではない。表はこの原稿に含めず、表境界の検査は対象外と明記する。

Noto Sans JPはこのPCにインストール済み（SIL OFL1.1）。フォント本体は同梱しない。公開ページはsystem font。PDFの埋込フォント・日本語文字抽出・全ページの画像で欠け、はみ出し、見出しの孤立、改ページ、括弧/句読点の配置を確認する。macOSPreview/Adobe/実機印刷/全禁則網羅/人による承認は未確認。作例で日本語対応全体の優位性を証明しない。

実行順：Opusが原稿・和文CSS・説明/静的デモを制作→親が原典APIでPDF2種を生成し、実PNGとmanifestを書き出して確認→Opusがその実物で短い編集動画を制作→MP4/公開。画面上でPDFを生成するアプリにはせず、実際に生成されたPDFと各ページ画像を閲覧・ダウンロードできる静的見本。生成できない未確認の機能を作例として演出しない。

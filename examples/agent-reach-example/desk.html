        再現するには
        
    
          
    このページはHTTPで配信して開いてください。ソースバンドルのルート（examples/ と media/ がある階層）で python -m http.server 8000 を実行し、http://localhost:8000/examples/agent-reach-example/ を開きます。file:// で開くと保存データを読み込めず、エラーを表示します。
    
          
    取得をやり直す補助コマンド python examples/agent-reach-example/collect.py --private-out PATH は、この環境で実際に実行し、原典6ファイルの一致と公開投稿のID・非空本文を確認しました。固定版Agent Reachの依存が入ったPython環境、gh、twitter-cli 0.8.5と既存の認証設定が必要で、これらは同梱していません。出力先は公開フォルダの外にし、生の投稿やCookieをコミットしないでください。
    
          
    同梱の原典 vendor/agent-reach/ は固定コミットの54ファイルを書き換えていません。X の読み取りでは、呼び出し側がtwitter-cliのブラウザーCookie自動読み取りだけを無効にしてから本物のコマンドを起動しました。認証の検証と返ってきた出力は変えていません。

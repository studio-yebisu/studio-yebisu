この作例について

図は「元の音声＋声色の見本 → OpenVoice → 変換後」の関係を表した説明図です。再生するのは、固定版の OpenVoice V2 の声色変換で制作時に実際に変換し、保存した WAV です。ページを開いても OpenVoice は動かず、新しい変換やアップロードはできません。

変えるのは声色（tone color）です。なまりや感情まで写し取ることを示す作例ではありません。

元の音声と見本は、Irodori-TTSの合成音声（Irodori-TTSの元の案内声・落ち着いた声・明るい声）です。人の声や原典のデモ音声は使っていません。文を音声にしたのはIrodori-TTS で、OpenVoice の読み上げ・MeloTTS・別の言語への変換・VAD・Gradio・クラウドは使っていません。

変換後の WAV には、原典の既定の透かし（WavMark）が入っています。保存した3本の WAV から、入れた目印「SYEBISU!」を読み出せました。動画の AAC 音声に残るかは確かめていません。

記録の確認は、ファイル・形式・長さ・ハッシュ・数値の確認です。補助に使った自動書き起こしは元の音声でも誤認識があり、変換後のほうが誤りの多いものもありました。書き起こしは聞こえ方の証明ではありません。発音・自然さ・声の近さの点数はつけておらず、聞き比べた印象や人による承認は記録にありません。

再生と保存の前に、各 WAV のバイト数と SHA-256 を記録と照らし、合ったものだけを使います。波形は記録にある0.1秒ごとの実測 RMS を、それぞれの音声の最大値を基準に描いたものです。

分担：声色の変換は OpenVoice の原典のコード、元の音声と見本は Irodori-TTS、図の構成案は 八百万図AIツールボックス の制作側、このページと解説動画は Claude Opus 5.5 が作りました。

このページで動いているもの

      
制作側が手元の CPU で python run.py を1回実行し、固定版 OpenVoice の ToneColorConverter が書き出した3本の WAV と、その記録 outputs/voice-runs.json を読んで再生します。ページを開いても OpenVoice は動かず、音声のアップロードや新しい変換はできません。再生の前に、各 WAV のバイト列を記録の SHA-256 と照合し、合ったものだけを再生と保存に使います。

      
    
        
  1. 原稿を書く　架空の「紙の博物館」の案内2文と、参照用の1文を書いて固定
    2. 
        
  2. 合成音声にする　Irodori-TTSで、案内は Irodori-TTSの元の案内声、参照は Irodori-TTSの落ち着いた声 と Irodori-TTSの明るい声 が読む（4本）
    3. 
        
  3. 声色をとる　4本それぞれに原典の extract_se をかけ、256次元の声色の埋め込みを作る
    4. 
        
  4. 変換する　原典の convert で、案内の声色を参照の声色へ（3件・tau 0.3・CPU 4スレッド・seed 20261017）
    5. 
        
  5. 聞いて選ぶ　変換後・元の声・参照の声を聞き比べ、気に入った WAV を保存
    6. 
      

    


    

      
確かめた範囲と、確かめていないこと

      
    
        
  • 声色の変換だけです。OpenVoice のテキスト読み上げ・MeloTTS・6言語の読み上げ・別の言語への変換は使っていません。文を音声にしたのは Irodori-TTSです。
    • 
        
  • 人の声は使っていません。元の声も参照の声も、インストール済みの Irodori-TTSの合成音声です。原典のデモ音声も使っていません。実在の人の声を写す作例ではありません。
    • 
        
  • 透かしは原典の既定設定です。合成音声の目印「SYEBISU!」を付けています。圧縮や編集後の残存は確認していません。
    • 
        
  • 参照音声の区切り（VAD・Whisper による se_extractor）、OpenVoiceのGPU推論、Gradio、ホストされたサービス、ブラウザー内の推論は使っていません。
    • 
        
  • 記録にある確認は、ファイル・形式・長さ・SHA-256・埋め込みの数値の確認です。声がどれだけ近いか・自然かの点数はつけていません。聞いた印象と人による承認は、この記録には含まれません。
    • 
        
  • 時間は1回の実行で測った値で、速さの約束ではありません。
    •

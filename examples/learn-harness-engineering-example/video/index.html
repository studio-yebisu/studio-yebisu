固定版 Harness Creator が作った5ファイル、架空の書店メモ8件、CLI の保存出力（Q03 と Q06）、制作担当が実行した ./init.sh の検証、2つの時点の状態ファイルから描く28秒・無音の解説映像の編集元です。

保存済みのファイルと実画面を確かめています…

この映像が示すこと・示さないこと

  • 固定版 walkinglabs/learn-harness-engineering（38ddcd2、MIT）の Harness Creator を、書き下ろしの小さな CLI 練習1件に当てはめた記録です。講座の Project 01・02 の比較実験、Electron アプリ、模擬Q&A ではありません。
  • 検索は NFKC・小文字・空白区切りの全語AND とタグの完全一致です。結果は保存した CLI の出力で、AI の回答や意味の判断ではありません。
  • feat-001 は、1回目のセッションの後は作業中・未検証でした。制作担当が ./init.sh を実行して8問と意図的な不正入力11件の確認が通った後、新しいセッションが保存記録を読んで done にしました。feat-002 は未着手です。
  • Q06 の0件は「入力に一致するメモなし」という正しい結果です。不正入力11件は、わざと作った入力を CLI が断るかの確認で、作業の失敗ではありません。
  • 映像は保存した記録と実画面の静止画を編集したもので、操作の連続録画ではありません。記録カードは編集で描き直したもので、実画面の画素は変えていません。
  • ハーネスなしとの比較はしておらず、効果・速さ・信頼性の向上は測っていません。構造の点検の点数は映像に出していません。
  • メモと書店は架空です。このページでも映像でも、Node・CLI・AI は動きません。

照合してから使うファイル

照合表 assets/data-hashes.json を制作記録の SHA-256 で確かめ、そこに書かれたファイルの生のバイト列を照合してから描きます。合わなければ理由を出して止まり、代わりの映像は描きません。

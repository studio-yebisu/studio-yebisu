手元で実行し直す

このページから実行はできません。実行ファイル・モデル・索引キャッシュは配布していません。公式リリースを自分で取得し、確かめてから使います。インストールや全体設定の変更はしません。

  1. 公式 v0.12.0 の Windows 版 zip と checksums.txt を、作例フォルダの外の新しいフォルダに取得し、SHA-256 とビルド証明を確かめて展開する（v0.12.0 のリリース、確かめ方は原典の SECURITY.md）

  2. ほかの Codebase Memory MCP のセッションやコマンドが動いていないことを確かめる。止めるためにほかのセッションを終了させない

  3. 展開したフォルダで作例の workflow.py を実行する

    $cbmProof = Join-Path $env:USERPROFILE (".cbm-proof-" + [guid]::NewGuid().ToString("N"))
New-Item -ItemType Directory -Path (Join-Path $cbmProof "rendezvous") -Force | Out-Null
$env:CBM_RUNTIME_DIR = Join-Path $cbmProof "rendezvous"
python <作例フォルダ>\workflow.py --binary .\codebase-memory-mcp.exe --work (Join-Path $cbmProof "work") --cache (Join-Path $cbmProof "cache")

  4. 作例フォルダで python -m http.server 8000 を起動し、http://127.0.0.1:8000/ を開く。file:// では記録を読めません

CLI で作った索引は監視されません（原典 README の Auto-Index）。ファイルを変えたら index_repository を手でやり直します。

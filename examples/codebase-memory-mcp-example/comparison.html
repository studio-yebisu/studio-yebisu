手元で実行し直す

このページから実行はできません。実行ファイル・モデル・索引キャッシュは配布していないので、公式リリースを自分で取得して確かめてから使います。インストールや全体設定の変更はしません。

  1. 公式 v0.12.0 の Windows 版 zip と checksums.txt を、作例フォルダの外の新しいフォルダに取得し、SHA-256 とビルド証明を確かめて展開する

    v0.12.0 のリリース · 確かめ方は README と原典の SECURITY.md の Verification

  2. ほかの Codebase Memory MCP のセッションやコマンドが動いていないことを確かめる（キャッシュの場所が違うと、動いている間は拒否されます。止めるためにほかのセッションを終了させないでください）

  3. 展開したフォルダで、作例の workflow.py を実行する

    $cbmProof = Join-Path $env:USERPROFILE (".cbm-proof-" + [guid]::NewGuid().ToString("N"))
New-Item -ItemType Directory -Path (Join-Path $cbmProof "rendezvous") -Force | Out-Null
$env:CBM_RUNTIME_DIR = Join-Path $cbmProof "rendezvous"
python <作例フォルダ>\workflow.py --binary .\codebase-memory-mcp.exe --work (Join-Path $cbmProof "work") --cache (Join-Path $cbmProof "cache")

    --work は新しい空のディレクトリ、--cache はこの作例専用の場所にします。どちらも作例フォルダの外です。

  4. 作例フォルダでこのページを開く

    python -m http.server 8000

    ブラウザで http://127.0.0.1:8000/ を開きます。file:// で直接開くとJSONを読み込めません。

詳しい手順と注意は README にあります。

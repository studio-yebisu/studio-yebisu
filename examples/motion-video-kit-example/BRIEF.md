# BRIEF：Studio Yebisu サイト紹介（20秒・無音）

作成：Opus 5.5（claude-opus-5-5）。原典 Motion Video Kit の `business-motion-film`（固定コミット e4b1c00、同梱 `vendor/motion-video-kit/`）の SKILL.md と references（motion-grammar・launch-film-notes・quality-bar・gauntlet・critic-prompts）、Motion Reel の SKILL.md を読んで書いた。この文書は現在の本編に合わせた版。場面と時刻は `storyboard.md`／`storyboard.json`。

## 1. 何を伝えるか

- **事業**：Studio Yebisu。AIスキルとツールを用途の分野ごとに日本語で紹介するサイト。一部の紹介には、実際に制作した作例の記事（入力と結果、依頼文、出典、確認した範囲、短い動画）がある。
- **この映像の仕事**：無音で20秒見た人が「AIスキルを用途から選び、作例を見て、依頼文で試せるサイトだ」「次は『作例を見る』」と言えるようにする。
- **残す一文**：用途から選び、作例を見て試す。

## 2. 見る人

AIで制作する手がかりを探している人。スキルの名前は知らないが、用途ははっきりしている。紹介文だけでは、どの入力でどんな結果になるかが分からない。

## 3. 一つの行動（CTA）

- 文言：**作例を見る**（唯一のCTA）。行き先は既存のサイト `studio-yebisu.github.io/studio-yebisu/`（文字として表示するだけ。描画時に接続しない）。
- ボタンの文字は96px。320px幅の画面に縮めても約16pxで読める。17.10秒から20.00秒まで、CTAのすべての文字が読める状態を保つ（条件は2.4秒以上）。

## 4. 映像で言ってよいこと

| 表現 | 根拠 |

| モーションの説明「文字と図形を動かして、仕組みを伝える。」 | サイトの分野の説明 |

| 作例記事の「実入力と結果」「入力」「結果」「AIへの頼み方」「依頼文の例」「依頼文をコピー」「できないことと注意」「出典とライセンス」、パンくず「トップ／モーション」 | サイトの記事ページの見出しとボタン |

## 5. 言わないこと・描かないこと

- 全項目に作例がある、全項目を確かめた、とは示さない。「検証済み」は画面に出さない。
- 保存・アカウント、制作代行の申し込み、価格、実績、件数、速度や品質の保証を出さない。
- 架空の顧客評価・架空のログ・増える数字を出さない。
- AIがその場で生成しているように見せない。カーソル、検索候補、通知、「コピーしました」などの押したあとの状態は描かない。
- 原典にある第三者28本の参考映像は見ていない。動きの仕組みは同梱の文章分析だけから選んだ。

## 9. 原典をどう当てはめたか

- **一つの主役**（motion-grammar の規則2）：モーションのカードを囲む**ティールの輪郭**1本。表紙のカード → 接写 → 一覧 → 「制作した作例あり」の印 → 記事 → 入力の枠 → 入力の帯と結果をまとめた外側 → 「依頼文をコピー」→「作例を見る」のボタン、と受け渡す。着地先は自分の選択の線を描かない。入力の引用は、記事の枠から大写し・帯まで同じ文字のまま運ぶ。
- **3つの機構**（機構の表と launch-film-notes の文章）：選ぶと広がる（Wonder 18/19、AsideHQ 05 の記述）、結果が組み上がる（Replit Slides 11）、残る道筋（Replit 13）。補助に、同じ記事が上へ送られて次の節が来る動き。
- **原因 → 結果**（規則6）：選ぶ → 一覧が開く、印 → 記事が開く、入力 → 結果、印 → ボタン。
- **構図**：表紙／カードの接写／一覧の俯瞰／記事の模式図／引用の大写し／枠の中の枠／節のカード／CTA の8構図。30秒で12〜15構図という目安を20秒に当てはめた。
- **受け渡しの約束**：輪郭が横切る文字は先に消し、辺が通り過ぎてから戻す。日本語は拭き取りで切らず、行ごとに不透明度と上昇で出す。輪郭が動き出す時点で、行き先の面と構図がすでに在る。
- **間**：読める着地 → 速い退場 → 減速する到着。読む区間はゆっくりした寄り（1.5〜3%）と、輪郭の周を回る短い線分で動かし続ける。
- **音の工程の除外**：audio.md・loudness.sh・効果音・音楽の後ろ合わせは行わない。

## 10. 完成の基準（quality-bar.md を20秒・無音に当てはめる）

- frozen-time：差分が閾値を下回る合計が約0.7秒以内を制作時の目安とした。最終 v3 の実MP4は約5.5秒、最長非CTA区間は約1.7秒で、原典の数値目安は未達。引用・完成した結果・依頼文・CTAを読む保持を残し、実測値と別担当AIの視覚評価を別に記録する（review-summary.json）。数値基準に適合したとは扱わない。
- 落ち着いた文字はWCAG AA。frame0 が完成した構図。クロスフェードの途中も文字が重ならない。
- 同じ時刻を別の順序で描いて同じ画になること（同じ実行環境内）。
- 無音で、サイトの内容と「作例を見る」が分かる。CTAはスマートフォンの大きさでも2秒以上読める。

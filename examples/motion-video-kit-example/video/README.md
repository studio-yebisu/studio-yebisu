# Motion Video Kit の仕組み：32秒・無音の解説映像（編集ソース）

Motion Video Kit（echris6/motion-video-kit、固定コミット `e4b1c0004080fe6a0deb883631bad5eba1e5f339`）の構造と、原制作でそれを1件の実入力へ当てはめた流れを、一枚の動く図だけで説明する映像のソースです。音声・ナレーション・効果音・音源ファイルはありません。

原制作の20秒の作品（`../film.mp4`、サイト紹介）とは別物です。宣伝映像の新作でも、Gauntletの新しい判断でもありません。

## 時間の契約（Motion Reel）

- `window.motionConfig = { duration: 32, fps: 30, width: 720, height: 1280, posterTime: 31, audioEvents: [] }`
- `window.renderConfig` の `width`・`height`・`fps` を初期化時に使う。縦長なら `tall`、横長なら `wide` の配置で描き直す（720×1280 と 1280×720 の両方を想定）。
- `window.seek(seconds)` は 0–32 秒へ丸めた時刻の完成した画面を描き、Promise を返す。描画は時刻と検証済みの記録だけで決まり、呼び出し順・FPS・壁時計・前フレームに依らない。乱数・タイマー・CSSアニメーションは使わない。
- `window.motionReady` は書体の準備、25件の記録のバイト数と SHA-256（`concept/manifest.json` 自体は固定値 `c06042ba…a150`）、相互の関係、実フレーム PNG 5枚の復号と 1920×1080 を確かめてから解決する。一つでも違えば図を消して reject する。`#retry` で25件を読み直す。
- `window.__MOTION_RENDER__` が真なら操作を隠し、プレビューの再生（requestAnimationFrame）と時計の表示を止める。
- 読み込むのは同じサイト内の25件だけ。外部の書体・CDN・モデルへは接続しない。

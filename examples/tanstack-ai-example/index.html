架空の商品カタログ3件を読む get_products だけ。入力 {query: string, maxPrice?: number}・出力 {products: Product[]} の型をzodで定義し、サーバー側で実行しました。
実行の流れ
質問文を送る → モデルが道具を型つきで呼ぶ → 実際にサーバーツールが実行され商品を返す → モデルが日本語で短く答える。サンプル1は「青いマグカップ」（1,800円）1件、サンプル2は予算2,500円以内のマグ2点でした。
再現手順

再現用コードは run.mjs です。実行には既存のClaude Codeログインが必要で、新しい課金や認証は始めません。

npm ci          # package-lock.json どおりに依存を揃える
node run.mjs    # 2問を実行し out/<日時>/ に記録を書く

実行の記録は out/ へ書き込まれ、公開物には含まれません。公開データに認証情報やセッションの生ログは入っていません。

この作例の道具の縛りについて

この作例は、自分が定義した読み取り専用の get_products だけを許可し、ファイルやシェルの道具は使えない構成にしています。ただし local-process のサンドボックスはセキュリティ上の隔離ではありません。本番で使う場合は、信頼できる道具だけを選び、サーバー側の権限と実行環境を別途設計してください。権限の回避を指示するオプションは使っていません。

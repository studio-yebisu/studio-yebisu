# 図解動画のソース（LangGraph）

32秒・30fps・960フレーム、無音の図解動画のソースです。縦長 720×1280 と横長 1280×720 を、それぞれに合わせた配置で描きます。紹介ページ（`../index.html`）と同じ構造図を、同じモジュール（`../concept.js?v=visual-r1`）で描きます。

**状態：** claude-opus-5-5 がソースを書いた段階です。執筆者はまだブラウザーで描画しておらず、テスト・フレームの確認・MP4への書き出し・公開もしていません。それらは制作担当の後の工程で、この README はそれが通ったとは主張しません。

## 動画が伝えること

LangGraph が何か（共有stateと関数をつなぐPythonのライブラリ）、中に何があるか、架空の申請がどう state として渡り、規則のPython関数・分岐・停止・テスト値による再開を経て、どんな保存記録が返ってくるかを、ひとつのつながった図の動きで見せます。文章のスライドや画面の寄せ集めではなく、同じカードが動き、項目を増やし、門で止まります。

| 秒 | 場面 | 動き |
|---|---|---|
| 0–4 | 部品 | 5つの関数、空の RequestState のカード、分岐、compile／invoke、メモリのトレイ、review の門、Command のカードが順に光る（6部品は説明用の整理） |
| 4–8 | 書く・動かす | 原典API＋依頼文 → 元の制作AI → workflow.py。制作担当が Python で compile → invoke。カードに申請Aの品目が入る |
| 8–14 | 止まる | validate → estimate（camera 6,000×1・tripod 1,000×2・合計 8,000円・予算フラグ false）→ review で門が閉じ、停止。メモリの A に記録 |
| 14–20 | 再開 | テスト値 true の Command が同じ thread A へ。review の先頭から戻り、approved → finalize → 保存記録 → 元の実データ |
| 20–26 | BとC | B は返却日が空で needs_input → END（見積・停止・再開なし）。C は 36,000円・予算フラグ true でも同じく停止し、テスト値 false で rejected |
| 26–29 | 保存 | C の最終 state が保存記録 rejected.json になり、元の実データへ |
| 29–32 | 全体 | 図全体と3件の最終値（A approved 8,000円・B needs_input end_date 不足・C rejected 36,000円）が止まったまま。動きは28.9秒で終わり、ポスターは31秒 |

場面へ移動するボタンは 0・4・8・14・20・26・29 秒です。図の中の固定のラベルは「規則処理・保存記録の図解・回答はテスト値・同じプロセスのメモリ」です。

## 実際のデータ

- カードと帯の値は、元の実行が保存した `../concept/jobs/{approved,missing,rejected}.json`（`../outputs/runs.json` の jobs と同じ内容）のチェックポイントから読みます。新しいグラフ実行・Python実行・推論はしていません。
- 返却日のない申請（B）には、合計・停止・再開を描きません。Command のカードは「停止なし」と表示します。
- 再開は review の先頭へ戻る線で描きます。finalize から始まる絵や、人が承認する画面は描きません。
- 紙・門・トレイ・画面の形は説明用の絵で、実行の証拠ではありません。

## 読み込みと止まり方

`../concept/manifest.json`（SHA-256 `3147f2fff01f9ae8e548ebd4af6084648f357232d49b0bdb2530916feaedf4ed`）が挙げる21件を、大きさとSHA-256で確かめてから描きます。6つの引用の行、固定コミットと4パッケージの版、3件の記録と入力・runs.json・samples.json の一致、元の実行記録の件数とハッシュ、workflow.py の5ノード・条件分岐・compile・invoke・interrupt・Command の行も中身で確かめます。これらは保存した記録を読む確認で、新しい実行ではありません。

合わない・読めないときは何も描かず、操作を止めて「もう一度読み込む」だけを残します。`crypto.subtle` が必要なので、HTTPS か localhost で開いてください。

## 書き出し側との約束

- `window.motionConfig = {duration: 32, fps: 30, width, height, posterTime: 31, audioEvents: []}`
- `window.renderConfig` の幅・高さ・fps を初期化時に使います。幅が高さより大きければ横長の配置です。`?orient=wide` でも横長になります。
- `window.motionReady` はフォントと21件の確認を待ちます。
- `window.seek(t)` は時刻 t（0〜32に丸める）だけから1枚を描きます。呼ぶ順番や壁時計、乱数、前のフレームに依存しません。
- `window.__MOTION_RENDER__` が真なら確認用の再生を止め、`?render=1` か `__MOTION_RENDER__` で canvas だけを表示します。
- 音声はありません（ナレーション・TTS・音声ガイド・音の要素・スクリプト・素材・トラックなし）。

## 確認用の画面

`index.html` を開くと、再生・最初へ・最初から再生・最後へ、0〜32秒の位置、7つの場面ボタン、縦長／横長の切り替えがあります。これらは確認用で、書き出す映像には入りません。以前の28秒の解説動画のソースは `legacy.html`・`legacy.js`・`legacy.css`（`legacy-storyboard.json`・`legacy-README.md`）に元のまま残っています。

## この作例の事実

- LangGraph は Python のライブラリで、SKILL.md・AIモデル・自動承認エージェント・ホスト型APIではありません。実行時の5ノードは決まった規則のPython関数で、グラフはLLMを呼んでいません。
- 元の Opus 5.5 が workflow.py と元の画面を書き、制作担当が別の工程で、外への接続を止めた1つのPythonプロセスで3件を実行しました（トレース・LangSmith・Cloudなし）。
- 分岐は入力の不足・誤りだけで決まります。完全な申請は金額にかかわらず review で止まります。予算フラグ（30,000円以上）は目印で、自動の差し戻しではありません。
- 回答はスクリプトが渡したテスト値で、人の承認ではありません。予約・在庫確保・通知・決済はしていません。
- InMemorySaver は同じPythonプロセスのメモリだけです。永続化や再起動後の再開は試していません。チェックポイント 6/4/6 件は記録の数で、速さや品質の点数ではありません。

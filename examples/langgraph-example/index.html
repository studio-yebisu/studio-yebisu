手元で実行し直す

このページから実行はできません。結果を作り直すときは、Python 3.10 以上で、この作例のフォルダから次を順に実行します。APIキーやアカウントは不要です。

  1. 仮想環境を作って有効にする

    python -m venv .venv

    有効化：Windows（PowerShell）は .venv\Scripts\Activate.ps1、macOS・Linux は source .venv/bin/activate

  2. 固定版の4パッケージと依存を入れる

    python -m pip install -r requirements.lock.txt ./vendor/langgraph/libs/checkpoint ./vendor/langgraph/libs/prebuilt ./vendor/langgraph/libs/sdk-py ./vendor/langgraph/libs/langgraph

  3. グラフを実行して結果を書き出す

    python workflow.py

  4. このページを開く

    python -m http.server 8000

    ブラウザで http://127.0.0.1:8000/ を開きます。file:// で直接開くとJSONを読み込めません。

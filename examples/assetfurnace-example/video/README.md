# 無音の説明映像（編集ソース）

AssetFurnace 作例の32秒の説明映像です。作例ページと同じ `../concept.js` の `loadData`・`sceneAt`・`drawConcept`・`createModelView` で、同じ構造図と同じ実GLBを、時刻ごとに描きます。

- 32秒・30fps・ポスター31秒。縦720×1280が主で、横1280×720は配置を作り直して描きます（拡大縮小した流用ではありません）。
- **無音です。** `audioEvents` は空で、`<audio>`・音楽・効果音・ナレーション・音声ガイド・再生用の音のコードはありません。
- 図の動きは説明用の演出で、原典CLIの処理時間ではありません。
- 動く画像の小片は、確かめたGLBに埋め込まれた実際の画像の縮小表示です。小片の大きさは画素数の比（1024を1として512は1/2、256は1/4）の説明で、実寸ではありません。1024上限の候補PNGは原典が保存しないので、中身の無い点線の枠で示します。
- 3Dは、確かめた4つの実GLB（入力と3つの出力）を three.js 0.180.0 の GLTFLoader で読み、画面外の WebGL 描画1つ（640×360・倍率1・`preserveDrawingBuffer: true`・同じカメラと照明）で描いて、そのコマの出力GLBの箱と下の帯に貼ります。向きは時刻だけの式で決まり、メッシュを足したり作り直したりはしません。

## 開き方

`site/`（このフォルダの1つ上）をルートにしてローカルサーバーで開きます。`file://` では読み込みとSHA-256の確認ができません（ES module・import map・`crypto.subtle` のため）。

```text
cd <site>
python -m http.server 8000 --bind 127.0.0.1
# http://127.0.0.1:8000/video/index.html
```

開くと、`../concept/manifest.json` を `cache: no-store` で読み、SHA-256 が固定値 `6caba83d259fc7f8aa61c37ec918bd3d6b7fc3c2378650b0bd61aa76fa39d6dc` と一致するかを確かめ、一覧の39ファイルすべての大きさとSHA-256、facts（`assetfurnace-actual-facts@1`）、原典の引用6か所の行、ジョブ3件、実測の記録、4つのGLBの中身（画像3枚のバイト列・形式・寸法、画像以外の12viewのSHA-256、画像以外のJSON、三角形の数）、three.js で読んだメッシュ・三角形・テクスチャの寸法、`storyboard.json` と場面の一致を確かめます。1つでも合わなければ映像を描かず、理由と「もう一度確かめる」を出します。WebGL が使えない環境でも、代わりの絵は出さずに止まります。

three.js は `index.html` の import map で `../vendor/three/build/three.module.js` を指し、ハッシュの確認が終わってから読み込みます。外部のCDN・フォント・APIは使いません。

## 操作

- 縦／横：向きだけを変えます。時刻や再生状態は変えません。
- 再生・一時停止・最初から再生・先頭・末尾、0〜32秒（0.1秒刻み）のスライダー、7つの場面への移動。
- 「確かめた素材」に39ファイルの大きさとSHA-256、「ソースと出典」に編集ソースと原典・素材へのリンク、作例ページへの戻りリンクがあります。

## 書き出しの契約（Motion Reel）

| 項目 | 内容 |
| --- | --- |
| `window.motionConfig` | `{duration: 32, fps: 30, width: 720, height: 1280, posterTime: 31, audioEvents: []}`。`window.renderConfig` の `width`・`height`・`fps` があれば、どのモジュールより前の最初のスクリプトで反映します |
| `window.motionReady` | 39ファイル・facts・引用・4つのGLB・絵コンテをすべて確かめ、画面外のWebGL描画で4つのGLBをそれぞれ1回描き、フォントの準備ができてから解決します。どれかが失敗すれば reject します。代わりの「準備できた」扱いはしません |
| `window.seek(seconds)` | Promise を返し、その時刻の完成した1枚を描きます。状態は時刻だけで決まり、呼ぶ順番・壁時計・前のコマに依存しません（任意の7.2秒や順不同でも同じ画）。3Dも毎回同じ式の向きで描き直します |
| `window.__MOTION_RENDER__` | 真なら再生ループを動かさず、操作パネルを隠し、`#film` だけを余白・スクロールバー無しで指定の大きさに描きます |
| 静止 | 30〜32秒は形・位置・文字・3Dの向きがすべて30秒の状態のままです |

書き出しの例（制作担当が別工程で行います。出力先は毎回、新しい空のフォルダーにします）：

```text
node <motion-reel>/scripts/render.mjs --project <site>/video --out <empty-dir>/portrait --video
node <motion-reel>/scripts/render.mjs --project <site>/video --out <empty-dir>/wide --width 1280 --height 720 --video
```

音の指定（`--audio`・`--synth`）は付けません。この映像は `video/` の外にある `../concept.js`・`../concept/`・`../outputs/`・`../inputs/`・`../vendor/` を読むので、書き出しでも `site/` 全体を同じオリジンから http で配信した状態で `video/index.html` を開く必要があります。`video/` だけを切り離したり `file://` で開いたりすると、確認に失敗して `motionReady` が reject します。書き出しに使うブラウザーで WebGL が使えることも必要です。

## 場面

`storyboard.json` に7場面の時刻・伝えること・入る状態・出る状態・動きがあります。場面の時刻と文言は `../concept.js` の `SCENES` が描画の元で、`storyboard.json` と一致しないと映像は読み込みを止めます。変えるときは両方を同じように直してください。

| # | 時刻 | 伝えること |
| --- | --- | --- |
| 1 | 0–4秒 | AssetFurnaceは手元の3Dアプリ。今回は圧縮CLIだけを使う |
| 2 | 4–7.5秒 | 原典のREADME・CLIと架空の依頼から、作者AIがジョブを書く |
| 3 | 7.5–11秒 | 制作担当がBlenderで5ファイルを1つのGLBに包み、原典CLIを3回実行 |
| 4 | 11–14.5秒 | 同じ入力GLBが、そのまま写す形と、画像3枚に分かれる |
| 5 | 14.5–21.5秒 | 上限で縮めた候補が元より小さい時だけ、画像を置き換える（1024→512→256の順に3回） |
| 6 | 21.5–26秒 | 同じ形と選ばれた画像が、実際の出力GLBに戻る（256上限の実GLB） |
| 7 | 26–32秒 | 実ファイルを同じ向きで比べ、保存して次の確認へ（30秒から静止） |

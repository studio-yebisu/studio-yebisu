# 動く概念図・無音の編集ソース（Claude-Mem 作例）

32秒・30fps・960フレーム。縦720×1280と横1280×720のそれぞれに配置を作り、同じ時刻表で描きます。問いのルーペ → ひとつの保存先（SQLite）にある2つの案件の本棚 → 3つの引き出し「題名 → 前後 → 本文」→ 返った記録が置かれる場所、をひとつの図としてつなげ、同じ本（記録）が棚を出て、題名の札になり、隣の記録と並び、1冊だけ開く様子を見せます。音声・ナレーション・読み上げはなく、MP4にも音声トラックを入れません。

| ファイル | 内容 |
| --- | --- |
| `index.html`・`video.css`・`video.js` | 編集ソース（キャンバスに描く。外部のフォント・CDN・画像は使わない） |
| `storyboard.json` | 場面ごとの伝えること・入る状態・動き・出る状態・読む値・範囲、続けて使う部品、縦横の配置 |
| `assets/manifest.json` | 7素材のファイル名・SHA-256・バイト数・元の場所 |
| `assets/` | 元の実行記録・独立した照合・入力2件・原典のロックの写しと、図の値 `diagram-data.json`・時刻表 `timeline.json` |

## 見る

静的な HTTP サーバーが必要です（`file://` で直接開くと素材を照合できず、理由を表示して止まります）。作例のフォルダー（`index.html` のある場所）で次を実行し、`http://localhost:8000/video/` を開きます。横は `http://localhost:8000/video/index.html?layout=wide` です。

```text
python -m http.server
```

- 開いた時点では一時停止しています。「再生」「一時停止」「先頭へ」と時刻のスライダーで確かめます。最後まで行くと「もう一度再生」になります。スライダーを動かすと一時停止して、その時刻の画を描きます。
- 「場面へ移動」で6場面それぞれの読みやすい時刻へ移ります。
- 「素材と出典」で7素材の照合結果（一致・不一致・照合前）を見られます。
- 音声の要素・ミュート・音量の操作はありません。

## 照合と失敗時

`video.js` は `assets/manifest.json` の SHA-256 を固定値 `a83234ef8ad6f98d84e43f00954b2f069091ce6c166167de644b9d356531a944` と比べ、並ぶ7素材のバイト数と SHA-256 をすべて確かめます。続いて次を確かめます。

- 元の実行記録（`efd1001c…b931c`）の形式・原典（thedotmack/claude-mem `fef3402e674bebbf72a23aeb735e91c92cd34afd`・13.39.0・Apache-2.0・Copyright 2026 Alex Newman）・194ファイルのロックとその SHA-256・入力2件の SHA-256・C01〜C08 の8場面と全確認の合格・通信の試み0件・新しいプロセス1回。
- 独立した照合（`independent-checks.json`）の合格と5件の ID・題名・案件。
- `diagram-data.json` の5件・ID・要約・各段階の索引と本文と例外が、記録の該当する呼び出しと同じ値であること。
- `timeline.json` が32秒・30fps・960フレーム・無音・6場面（固定の時刻と記録番号）であること。
- 図に出す短い見出しと本文の抜粋が、実際の題名・返った本文の一部であること。

図に出す題名・ID・順番・件数・案件・拒否のコードは、この記録から読みます。どれかが合わなければ、キャンバスを隠して操作を止め、短い理由と「もう一度読み込む」を表示します。内蔵の代わりのデータは使いません。

## 時間の契約

- `window.motionConfig = { duration: 32, fps, width, height, posterTime: 19, audioEvents: [] }`。`window.renderConfig` の幅・高さ・FPS を初期化時に反映し、縦か横かで配置を選びます（それ以外の大きさは、合う向きの配置を縦横同じ比率で拡大・縮小します）。
- `window.seek(t)` は時刻 t だけから完成した画を描きます。呼ぶ順番・壁時計・前のフレーム・乱数には依存しません。
- `window.motionReady` は、フォントの読み込みと7素材・記録の照合が終わると解決し、失敗すると拒否されます。
- `window.__MOTION_RENDER__` が真なら、編集画面の部品を隠し、プレビューの再生を止め、同じキャンバスだけを書き出し用の大きさで表示します。

## 書き出し

作例のフォルダーで、同梱の `render.py` を使います。Node.js 20 以上・Chrome・FFmpeg と ffprobe、`tools/motion-reel/` のレンダラーの依存（その隣で `npm install --ignore-scripts`）が必要です。出力はソースの外の、空のフォルダーを指定します（既存の書き出しは上書きしません）。音源や `--audio` は渡しません。

```text
python render.py --out ../render-portrait --width 720 --height 1280
python render.py --out ../render-wide --width 1280 --height 720
```

`render.py` はソースを一時フォルダーへ写し、そこで `video/index.html` を描きます。静止画だけなら `--stills-only` を付けます。

## 範囲

- 図は、制作時に固定版 Claude-Mem の上流ライブラリ（DatabaseManager・saveMemory・SearchManager・ProgressiveMemorySearch・progressiveSearchToolResult）を改変せずに Bun 1.4.3 で動かして保存した結果の説明です。ライブの実行や新しい推論ではありません。
- 保存は saveMemory による明示的な保存で、会話の自動記録や LLM による要約ではありません。検索はローカルの SQLite FTS5 のキーワード一致で、日本語のメモを英字の「iOS」「playsinline」で探したものです。意味検索や日本語の検索品質の評価ではありません。
- mem-search スキルの手順は上流のワーカー関数に直接当てはめたもので、MCP の通信やプラグイン・フックの導入ではありません。
- C03 で N01 を選んだのは実行スクリプトの呼び出し側です。自動モードは決まった順位付けで、LLM を呼びません。C04 の N02 は題名だけの前後で、本文は開いていません。
- 案件の指定は検索範囲を分けるもので、認証ではありません。続きの合図は発行したプロセスの中だけで15分有効で、新しいプロセスには引き継がれません。映像に合図の文字列は出しません。

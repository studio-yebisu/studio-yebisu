        範囲・原典・ライセンス
        
このページは、制作側が bun --no-install run.ts で実行して保存した outputs/memory-run.json を読んで図にする、作例用の閲覧ページです。Claude-Mem の公式アプリではありません。ブラウザーの中で Claude-Mem・Bun・Claude は動かず、新しい検索や推論もしません。表示の前に、記録そのものと入力2ファイル・ロックの SHA-256、固定版と版、8つの場面、確認の合否を照合し、合わなければ図を出しません。

        
    
          
  • 実行したもの：固定版の上流ライブラリ（DatabaseManager・saveMemory・SearchManager・ProgressiveMemorySearch・progressiveSearchToolResult）を改変せずに Bun 1.4.3 で動かし、手で保存した架空の5件をローカルの SQLite FTS5 で探しました。8場面・99の自動確認、別の Python sqlite3 による読取の照合、同じ保存先を新しい Bun プロセスで開き直す確認を含みます。
    • 
          
  • mem-search スキルの「題名 → 前後 → 本文」の手順は、上流のワーカー関数に直接当てはめています。MCP サーバーとの接続や、プラグイン・フックの導入ではありません。
    • 
          
  • 試していないこと：会話の自動記録や LLM による要約・圧縮、文脈の自動注入、Chroma の意味検索、クラウド同期、ホスト型の記憶、MCP の通信。
    • 
          
  • 検索はキーワードの一致です。日本語のメモを英字の「iOS」「playsinline」で探したもので、意味の近さや日本語の検索品質を測ったものではありません。
    • 
          
  • C03 で N01 を選んだのは、実行スクリプトに書いた呼び出し側の選択です。AI が自動で選んだのではありません。自動モード（C06・C07）は決まった順位付けで選び、LLM は呼びません。
    • 
          
  • C04 の前後に並ぶ N02 は題名だけの文脈で、本文は開いていません。
    • 
          
  • project の指定は検索範囲を分けるもので、認証やアクセス制御ではありません。C08 は記録にある5つの呼び出しを確かめたもので、あらゆる誤用を試したわけではありません。
    • 
          
  • 続きの合図（ms_ で始まる文字列）は、発行したプロセスの中だけで15分有効です。新しいプロセスには引き継がれず、記録に残る合図は終わった実行のもので、いまは使えません。開き直したあとは、問いからやり直します。
    • 
          
  • 図の見出しは実際の題名を縮めたもの（短い見出し）です：N01「下余白」・N02「動画」・N03「JSON」・N04「図」・N05「PDF」。本文の抜粋は、返った本文の一部をそのまま引いています。案件名「さくらサイト」「つばき資料」は架空の本文にある名前です。
    •

# 必要な記憶だけ、図で開く

架空の2案件の決定を5件保存した実記録を、一つの大きな概念図で見ます。「題名」から必要なメモを選び、「前後」を確かめてから、選んだ1件の「本文」だけを開きます。同じメモが図の中で移動し、開く様子を32秒の無音動画でも説明します。

案件の切り替えでは、同じiOSという語でも別のメモが返った実結果を比較できます。開き直す場面では、新しいBunプロセスが同じ保存先を開いて新たに検索し、同じIDのメモを取り出しています。メモは残りますが、前のプロセスの続きの合図は使えません。

原典の194ファイル、実行コード、5つの架空の入力、8場面の実出力、独立したSQLite照合は変更せずに引き継いでいます。図は保存済みの実結果を読むための独自画面で、ブラウザー内でClaude-Memやモデルを実行するものではありません。本文は保存したメモであり、生成された回答ではありません。検索はSQLite FTS5のキーワード一致です。

図と映像の新しいコードはClaude Opus5.5が執筆し、制作側が検証・書き出し・配布・掲載を担当しました。動画と編集ソースに音声ガイドはありません。自動検査やエージェントによる画面確認は、人による審美的承認や実機iOSでの確認とは区別します。

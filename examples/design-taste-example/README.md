# Design Taste の作例：余白図書室（架空）十一月の催し

架空の「余白図書室」の2026年11月の催し6件を、対象と語句で絞り込み、各行の参加方法を開いて読める一覧です。Design Taste（madebymustafa/design-taste、固定コミット c4a6bff0871eb4b15371b0e7d2751628b0ed4608）のうち、design-taste・japanese-minimal・taste-accessibility・taste-typography・taste-ux-copy の5つの SKILL.md を読み、実際の依頼（input.md）と、実装の前に書いたデザイン計画（design-plan.md）に沿って Opus 5.5 が作りました。

余白図書室と催しは作例用の架空のデータです。実際の参加・申込はできません。

## 絞り込みの決まり

`filterEvents(events, { audience = "all", query = "" } = {})` は入力を変更せず、新しい配列を返します。

- 対象：`all` 以外は `audience` と完全一致。
- 検索：検索語と、題名・説明・会場の各項目の両方に NFKC・前後の空白除去・小文字化をかけ、項目ごとに文字どおりの部分一致で調べます。空白で区切った語ごとの AND にはしません。日付・時刻・対象は検索しません。
- 対象と検索は AND。順序は入力（日付順）のまま。
- 曜日は ISO の日付を暦の日付として `Date.UTC` で計算し、端末のタイムゾーンに依存しません。

URLの合図 `#all`・`#children`・`#reading` は、読み込み時と、例のリンクを押したとき・戻る/進むで合図が変わったときに、検索欄と対象の欄へ実際に値を入れて計算し直します。そのあと利用者が欄を変えると、件数の表示は「例」ではなく「現在の条件」と書きます。「読書」は会場「読書の間」にも一致して4件になるため、1件の例には「短編」を使っています。

## 計画から変えた点

- 並び順：計画では読み込み時に日付と時刻で並べ直すとしていましたが、依頼に従い、入力の順序（日付順）をそのまま保ち、並べ直しはしていません。
- 縦書き：計画の §2 では左の3列に縦書きと絞り込みを置くとしていましたが、同じ §2 の「見出し横」に合わせ、見出しの左に置きました。広い画面の左3列は絞り込みだけです。
- 件数の表示：「6件中2件」に加えて、いまの条件（例の名前、または現在の条件）も書きます。
- 0件の理由：検索語があるときは、検索の対象が名前・説明・会場だけで、日付や時刻を含まないことも書きます。
- 架空の注記の末尾に、作り方と依頼文がある場所（一覧の下）へのリンクを足しました。
- 読み込みの失敗、JavaScript が無効なとき、モジュールを読み込めないときの表示を足しました。成功したように見せる表示はありません。
- 広い画面で高さが十分あるときだけ、絞り込みの欄をスクロールしても画面に残します。
- 日付と開始・終了の時刻は、それぞれ別の `time` 要素にしました。

## 実行と書き出し

一覧は静的HTTPサーバーから `index.html` を開きます。Node.jsで `node verify.mjs` を実行すると、同じ入力から検証と結果JSONを作り直せます。

動画は `video/index.html` の編集ソースから、実際の `assets/` のPNGを使って描きます。`captures.json` は元の実画面の状態とハッシュです。連続操作の録画ではありません。音声はありません。

Motion Reel（固定版56198544e69201b1c202e0c00fb90b568a729824）の `scripts/render.mjs` と依存、Node.js20以上、Chrome、FFmpeg/ffprobeを用意し、次を実行します。`--out` は新しい出力先を指定します。原本は変更せず、一時コピーで描画します。

```text
python render.py --renderer <MotionReel>/scripts/render.mjs --out <新しい出力先>
```

ZIPは `examples/design-taste-example/` と `media/` の相対配置を保持します。展開先をHTTP配信すると一覧と動画を確認できます。共通カタログの画面はオンライン版を使います。原典の選択した7ファイルとMIT表記も含みます。統括用の非公開資料やモデル会話ログは含みません。

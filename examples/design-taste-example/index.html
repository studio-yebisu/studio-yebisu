    何が入っていて、どう渡し、何が返るか
    
      
    
        
    
          
    どんな指針か
    
          
    Design Taste は、AIが画面のコードを書く前に読む、英語のMarkdownのデザイン指針（SKILL.md）です。モデル、Webサービス、画面を生成するAPI、スタイルシートの仕組み、5つの自動のAIのどれでもありません。読んだAIが、指示を依頼の条件に合わせて使います。
    
        
    
        
    
          
    中にあるもの
    
          
    固定版には24のスキルがあり、この作例は5つだけを選びました。共通の指針（design-taste）、表現を1つ（japanese-minimal）、補助の指針（taste-typography・taste-accessibility・taste-ux-copy）。この3つの群は図の説明のための分け方で、原典が決めた形式ではありません。
    
        
    
        
    
          
    どう渡すか
    
          
    架空の余白図書室の依頼（誰に・何を・催し6件と、読みやすさの条件）と5冊を、同じAIに読ませました。AIはまず方針一行と計画を書き、別の執筆でその計画を使ってHTML/CSS/JSを書きました。Nodeでの検査と実際のブラウザーでの確認は、制作担当が別の工程で行いました。元のAIがCLIやブラウザーを動かしたのではありません。
    
        
    
        
    
          
    返るもの
    
          
    実際に動く催しの一覧（ネイティブの検索欄・select・details）。訪れた人の操作は、ブラウザーの中で JavaScript が計算するだけです。AIの呼び出し、予約、送信、アカウント、内容の保存はありません。
    
        
    
      
    
      
    計画で調整したこと
    
      
    原典の指示を機械的に当てはめたのではなく、依頼の読みやすさの条件に合わせて計画で変えた点です。計画の記録で、道具が自動で変換したものではありません。
    
      
    
      
    絞り込みの決まり（このページで同じ関数を呼んだ結果）
    
      
    対象は分類の完全一致。検索語は NFKC・前後の空白除去・小文字化のあと、題名・説明・会場のどれかに文字どおり含まれるかを見ます。二つの条件は AND で、順序は入力のままです。元の21条件の検査をやり直したものではありません。
    
      
      
    
      

    
      
      
      図の6つの部分
      
      
      説明のための分け方で、原典が決めた形式ではありません。選ぶと図に赤い枠が付き、引用した行を示します。

      記録と範囲
      
      
      
        元の制作と、このページがすること
        
        
          
      • 5冊を読んで書いたことの記録は、元の制作で保存した Opus 5.5 の3つの執筆です：計画（design-plan.md）、一覧の実装（いまの desk.html・app.mjs・events.mjs・style.css）、以前の26秒の映像（video/legacy.html）。この新しい図と32秒の映像は、その記録に付け替えていません。
        • 
          
      • Nodeでの21条件（validation.json）と実際のブラウザーでの確認（verification.json・captures.json）は、制作担当が別の工程で行いました。どれもここでやり直していません。
        • 
          
      • 人による事前の計画の承認、スキルなしで作った場合との比較、使いやすさの改善の測定はありません。同じ依頼を別の表現の本に渡す比較もしていません。
        • 
          
      • このページは素材23件を照合し、照合した events.mjs の filterEvents をこのブラウザーで呼ぶだけです。AI・Node・ビルドは動かしません。
        • 
          
      • 図と映像の新しいコードと文章は claude-opus-5-5 が書いたもので、書いた時点ではブラウザーでの表示も描画の確認もしていません。図の中の動きは流れの説明で、元の制作の時間や内部の記録ではありません。
        • 
        
      
      
      
      
      
        試した範囲と、していないこと
        
        
          
      • 余白図書室と6件の催しは架空の合成データです。実際の参加・申込はできません。「小さな詩の朗読会」は催しの名前で、音声は作っていません。
        • 
          
      • 元の確認のルート文字サイズ200%の検査は、ブラウザー全体のズームや、実機の iOS・VoiceOver・NVDA での検査ではありません。スクリーンリーダーでの確認、アクセシビリティ全体の適合の判定、人による承認はしていません。
        • 
          
      • この図のページの配色の切り替え（ダーク）は、このページだけです。実際の一覧（desk.html）は明るい配色だけです。
        • 
          
      • 固定版の24のスキルのうち、5つだけを使いました。ほかの表現の本は読ませていません。

場面

  1. 0〜4秒画面を作る前に、方針をそろえる：並んだ5冊が開き、共通・表現を1つ・補助3冊の3つの群に分かれます。AIが読む文章で、画面を生成するAPIではありません。
  2. 4〜8秒渡す：依頼の札の「誰に」「何を」「催し6件」に順に下線。5冊と依頼の写しが同じ1つのAIへ合流します（5つのAIではありません）。
  3. 8〜14秒組み立てる：AIがまず「方針一行」の紙を書きます。開いた表現の本の色・明朝・縦の線が紙に移り、薄い灰→濃い灰、10–11px→14px は計画の上の調整として示します。同じ紙が同じAIへ戻ります。
  4. 14〜20秒組み立てる：次の執筆で、計画からコードの紙へ（AIが執筆）。制作担当が Node と実画面で確認する別の工程を通り、「記録」の札が付きます（品質の印や点数ではありません）。
  5. 20〜26秒使う：同じ紙が6件の罫線の行に開き、照合した events.mjs の filterEvents の結果で、対象「子ども」は e01・e04、検索「短編」は e02 を選びます。IDは保存した結果と同じです。
  6. 26〜29秒使う：結果の欄に、保存した実結果（JSON）と実際の一覧（実UI）の札。映像の中で端末への保存はしていません。
  7. 29〜32秒本 → 方針 → コード → 使う の全体が同じ濃さで静止（動きは28.9秒で終わり、ポスターは31秒）。

# 26秒の解説（無音）：余白図書室（架空）十一月の催し

Design Taste の作例を、保存した実際のブラウザー画面で説明する、26秒・1280×720・30fps・無音の編集動画のソースです。操作をそのまま録画したものではありません。保存した4枚の画面を切り出し、拡大し、並べ、薄くして、場面ごとに説明の文字を添えています。

伝えること：AIが読むデザインの指示書（Design Taste）で方向を1つに決めてから、実際の入力で使える一覧を作る。

## 場面

| 時刻 | 場面 | 使う保存画面 |
|---|---|---|
| 0–4秒 | 入力：Design Taste とは何か、合成の6件 | なし（events.json の6件を文字で表示） |
| 4–9秒 | デザインの方向：japanese-minimal の1つだけ | all.png（全体 → 見出し → 日付と罫線の行） |
| 9–15秒 | 対象で絞る：「子ども」で6件から2件 | children.png（対象欄と件数、e01・e04） |
| 15–21秒 | 参加方法を開く：入力の本文がそのまま出る | participation.png、mobile.png |
| 21–26秒 | 依頼文で試す：【】を書き換えてAIに渡す | なし（request.txt の短い抜粋） |

場面ごとの切り出し位置と目的は `storyboard.json` にあります。

## 素材と出どころ

- 保存画面：`../assets/all.png`・`children.png`・`participation.png`・`mobile.png`。この作例のページを実際に実行して保存したものです。撮った条件と大きさは `../captures.json` にあります。生成した画像や、画面に似せて描いた操作部品は使っていません。
- 入力：`../events.json`（架空の図書室の合成6件）。最初の場面の6行は、このファイルの値をそのまま文字にしたものです。
- 出力：対象「子ども」で e01・e04 の2件になることは、同じ絞り込みの関数を実行した `../results.json` と一致します。
- 依頼文：最後の場面の抜粋は `../request.txt` から取り、文言を変えずに一部を「…」で省いています。ページの中でAIを動かすことはなく、コピーの操作も動画では見せていません。
- 画面の中の文字（題名、件数、「当日、会場へお越しください。これは架空の案内で、実際の参加はできません。」など）は保存画面のものです。大きな見出し、説明の文、窓の下の注記、常に出す「保存した実画面で解説・無音」「架空の図書室」は、動画のために書いた説明の文字です。

余白図書室と催しは架空です。実際の参加・申込はできません。スキルを使わない場合との比較や、品質の数値は示していません。

## 開き方

作例のフォルダをローカルのWebサーバーで配信して `video/index.html` を開きます。保存画面は `../assets/` から読みます。下の操作で、再生・一時停止、再生位置の移動、場面への移動ができます。操作は720pの画面の外にあり、書き出しでは取り除きます。外部のフォント・画像・通信は使いません。

## 書き出しの約束

- `window.seek(秒)` が、その時刻の画面を前の呼び出しに関係なく描きます。
- `window.motionConfig`：`{duration: 26, fps: 30, width: 1280, height: 720, posterTime: 13, audioEvents: []}`。`window.renderConfig` の幅・高さ・fps を初期化のときに読み、720pの画面を縮尺だけで収めます。
- `window.motionReady`：4枚の保存画面の復号と大きさの照合、`document.fonts.ready` を待ちます。欠けていれば失敗します。
- `window.__MOTION_RENDER__` が真のときは、操作を取り除き、タイマーと `requestAnimationFrame` を使いません。CSSのアニメーションと transition はありません。
- 最後の枠（25.9667秒）で最後の案内まですべて表示されます。

## 確認の状態

このフォルダは実MP4に使った編集ソースです。Motion Reelで26秒・780フレームを書き出し、代表フレーム・連続フレーム・任意時刻一致・全デコード・ブラウザーの終端再生を確認しました。確認範囲は ../verification.json、コンタクトシートは review/contact.png。人による承認とは別です。入力表の日付と題名の間隔だけ、実描画に合わせて制作担当が調整しました。

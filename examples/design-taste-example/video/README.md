# 図解32秒・無音の元ページ（Design Taste 作例）

`index.html`・`video.css`・`video.js` が、32秒・30fps・無音の図解動画の編集できるソースです。縦 720×1280（主）と横 1280×720 を、同じ時刻表で別々に組み直して描きます。場面の設計は `storyboard.json` にあります。以前の26秒の映像ソースは `legacy.html`（`film.js`・`style.css`）と `legacy-storyboard.json`・`legacy-README.md` に、そのまま残しています。

## 何を描くか

Design Taste（madebymustafa/design-taste、固定コミット `c4a6bff0871eb4b15371b0e7d2751628b0ed4608`、MIT・Copyright (c) 2026 Mustafa）は、AIが画面のコードを書く前に読むMarkdownのデザイン指針です。モデル、Webサービス、画面を生成するAPI、スタイルシートの仕組み、5つの自動のAIのどれでもありません。固定版の24のスキルのうち、この作例は5つを使いました。

映像は作例ページ（`../index.html`）と同じ概念図を、同じ形のまま動かします。

- 渡す：共通の本（design-taste）、開いた表現の本（japanese-minimal）、細い補助の本3冊（文字・操作・文言）と、依頼の札「誰に / 何を / 催し6件」が、同じ1つのAIへ合流します。3つの群は図の説明のための分け方で、原典の形式ではありません。
- 組み立てる：AIがまず「方針一行」の紙を書きます（紙・墨・印の赤、明朝とゴシック、罫線、縦の線1本）。薄い灰 #8A8378 の文字 → #625C53、10–11px のラベル → 14px は、計画の上の調整として示します（道具の自動の変換でも、実行した前後の画面の比較でもありません）。同じ紙が同じAIへ戻り、次の執筆でコードの紙になります。コードの紙は「制作担当が確認」（Node 21条件・実画面）を通り、「記録」の札が付きます。品質の印や点数ではありません。
- 使う：同じ紙が6件の罫線の行に開きます。照合した `events.mjs` の `filterEvents` が返した結果で、対象「子ども」は e01・e04、検索「短編」は e02 を選び、同じ色の札のまま結果の欄へ移って、参加方法（申込不要／窓口で申込（架空））が開きます。最後に JSON（保存した実結果）と実UI（実際の一覧）の札。映像の中で端末への保存はしていません。

## 使う素材

`motionReady` は、フォントの準備と、`../concept/manifest.json`（SHA-256 固定）の23件の照合を待ちます。照合では、大きさとSHA-256、structure.json の件数・群・絞り込みの決まり・調整、6つの引用がその行にあること、5冊の name・README・LICENSE、6件の催し、results・samples・3つの記録（改行LF）の値とIDの一致、validation.json の21条件の記録、実画面の静止画4枚のPNGの大きさを確かめます。さらに、照合した `events.mjs` のバイトをそのままモジュールとして読み、凍らせた6件の写しで `filterEvents` を3つの条件と6つの決まりの例について呼び、保存した結果と同じIDと順序であることを確かめます。どれかが違えば描画を止め、操作をすべて無効にし、「もう一度読み込む」だけを出します。

静止画4枚は照合するだけで、映像には描きません。フレームごとの取得や通信はありません。AI・Node・原典は、ここでは動かしません。

## 時間の契約（Motion Reel）

- `window.motionConfig = {duration: 32, fps, width, height, posterTime: 31, audioEvents: []}`。
- `window.renderConfig` の `width`・`height`（偶数）と `fps` があれば、配置の前に反映します。大きさが決まっているときは向きの切り替えボタンだけを止めます。配置を変えるのは `button[data-orient]` だけです。
- `window.seek(秒)` は、その時刻の完成した画面を毎回最初から描きます。0〜32秒に収め、呼ぶ順番、壁時計、乱数、前のフレームに依存しません。描画は `save`・`restore` で閉じています。
- `window.__MOTION_RENDER__` が真、または `?render` のときはプレビューの再生を止め、canvas だけを画面いっぱいに出します。
- 最後の動きは28.9秒で終わり、29〜32秒は静止します（点滅も組み直しもありません）。ポスターは31秒。
- 音声のトラック・ナレーション・読み上げ・案内の台本・音の合成・音声要素は一切ありません。

## 場面

| 秒 | 見出し | 内容 |
| --- | --- | --- |
| 0〜4 | 画面を作る前に、方針をそろえる | 並んだ5冊が3つの群に分かれ、表現の本が開く |
| 4〜8 | 5冊と依頼を、同じ1つのAIへ | 誰に・何を・催し6件に下線。本と依頼の写しが1つのAIへ合流 |
| 8〜14 | AIがまず「方針一行」と計画を書く | 方針一行の紙。灰→濃い灰、10–11px→14px（計画の調整）。同じ紙がAIへ戻る |
| 14〜20 | 計画を使う次の執筆で、HTML/CSS/JSへ | コードの紙。制作担当が Node と実画面で確認し「記録」の札 |
| 20〜26 | 同じ6件の行から、実際の関数が選ぶ | 6件の行に開き、子ども→e01・e04、短編→e02。参加方法が開く |
| 26〜29 | 使える一覧と、保存した実結果 | JSON と実UI の札（端末への保存はしない） |
| 29〜32 | 本 → 方針 → コード → 使う | 全体で静止 |

## 開き方と書き出し

`fetch`・`crypto.subtle`・`blob:` のモジュールを使うため、作例のフォルダ（`index.html` のある階層）をローカルのHTTPサーバーで配信して `video/index.html` を開きます。自動では再生しません。

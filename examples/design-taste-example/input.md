# 実際の制作依頼：小さな図書館の催し一覧

架空の「余白図書室」の2026年11月の催しを、日時と参加方法がすぐ読める、日本語の小さな一覧にしてください。固定版Design Tasteのコアを読み、利用者は近所の親子・おとな・年齢を問わない来館者、用途は「催しを探す → 日時を読む → 参加方法を開く」です。静かだが、操作を探さなくて済むことを優先します。

入力データは input-events.json の合成6件です。名前・日時・分類・会場・本文・参加方法を変えません。実在の図書館の催しや予約を装わず、ページの冒頭と参加方法で架空だと明示してください。送信・予約・ログイン・保存は不要。外部画像、Webフォント、分析ツール、APIを使わず、OSの明朝とゴシック、HTML/CSS/JavaScriptだけで作ってください。

Design Tasteからjapanese-minimalを1つだけ選び、紙色#F4F1EAと墨#33302B、印の赤#B3392Aで、罫線の一覧、余白、明朝とゴシック、縦書き1か所を使います。原典の薄い灰#8A8378は本文だとコントラストが不足しうるため、文字は濃い灰へ調整し、装飾の罫線だけに薄い灰を使えます。小さい10–11pxラベルより日本語の読みやすさを優先し、最低14pxを基本にしてください。taste-accessibility・taste-typography・taste-ux-copyも読み、原典のどの指示を適用・調整したか記録します。

機能は対象の選択（すべて／子ども／おとな／どなたでも）、名前や説明からの検索、条件解除、各行の参加方法の開閉です。対象は分類の完全一致で、全6件→子ども2件、検索「短編」はe02の1件、存在しない語は0件になります。検索はNFKC・前後空白除去・小文字化を両側へかけます。二つの条件はAND。検索範囲は題名・説明・会場だけ。日付順を維持します。空の結果は理由と解除操作を出し、キーボードだけでも全て使えるようにしてください。検索文字列をHTMLとして実行しません。絞り込みはブラウザーのその場の計算で、保存しません。320pxで日時・対象・参加方法が欠けず、読み順が自然なことが完成条件です。

作例の主役はこの催し一覧です。解説・作り方・依頼文は同じページの下へ置き、最初の画面を運用ログやQAメニューにしないでください。本文は実際に動く一覧と、素材・確認範囲を分けて説明します。自動検査は人の承認やアクセシビリティ全適合ではありません。

あとで、実際の一覧の画面から26秒・1280×720・30fpsの無音解説を作ります。入力→デザイン方針→対象で絞る→参加方法を開く→依頼文で試す、という流れにし、実際に確認して保存した出力と画面を使います。動画は操作録画と混同させず、保存した画面で解説する編集動画と明記してください。

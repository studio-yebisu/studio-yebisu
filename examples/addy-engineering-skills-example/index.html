                期限のきまり（tasks.mjs のまま）

                • selectTasks(tasks, {status, cutoff}) が絞り込みを持ちます。画面の配線は判定を持ちません。
                • 期限は YYYY-MM-DD の暦日の文字列で、指定日を含む（<=）。状態の絞り込みと同時に効きます（かつ）。
                • 期限のないTODOは、期限を指定したときだけ外れます。並びは入力の順のままです。
                • 実在しない日付（例：2026-02-30）は RangeError('INVALID_CUTOFF') で拒みます。
                • 自動の「今日」、並べ替え、通知、保存、サーバー、ブラウザー内のAIはありません。
                元のモデル実行と、制作担当の作業
                • 元のモデル実行の受領記録は6件です：仕様、RED1、GREEN1、RED2、GREEN2、画面。仕様は最初の別の実行で書きました。計画だけの受領記録はありません。
                • Node の実行（変更前と4回）、36条件、条件の反転は、元の制作担当が行いました。点検は、著者とは別の Codex の親が1回行いました。
                • outputs/*.json は、results.json の3件を制作担当がUTF-8・LFで分けて保存し直したものです。新しいAIやNodeの結果ではありません。
                • この図と映像は claude-opus-5-5 が新しく書いたもので、元の6回の執筆や、制作担当の梱包・確認とは別です。
                試した範囲と、していないこと
                • Agent Skills は、AIが読む工程別のMarkdown手順集です。モデルやAPI、自動の流れ作業ではなく、7つのAIが自動で動く仕組みでもありません。

                • 前提11個は制作担当が事前に決めました。人への聞き取り、仕様・計画・段階ごとの人の承認は行っていません。

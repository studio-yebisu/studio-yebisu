# 動く概念図・無音の編集ソース（Mem0 作例）

32秒・30fps・960フレーム。縦720×1280と横1280×720のそれぞれに配置を作り、同じ時刻表で描きます。架空の2人 → 好みのタイル → ひとつの保存先（あや・けんの2区画）→ 問いと絞り込みの道筋 → 実際に返ったタイル、をひとつの図としてつなげ、同じタイルが入る・出る・その場で変わる様子を見せます。音声・ナレーション・字幕の読み上げはなく、MP4にも音声トラックを入れません。

| ファイル | 内容 |
| --- | --- |
| `index.html`・`video.css`・`video.js` | 編集ソース（キャンバスに描く。外部のフォント・CDN・画像は使わない） |
| `storyboard.json` | 場面ごとの伝えること・入る状態・動き・出る状態・読む値・範囲 |
| `assets/manifest.json` | 7素材のファイル名・SHA-256・バイト数・元の場所 |
| `assets/` | 元の実行記録・入力3件・原典のロック・samples.json の写しと、時刻表 `timeline.json` |

## 見る

静的な HTTP サーバーが必要です（`file://` で直接開くと素材を照合できず、理由を表示して止まります）。作例のフォルダー（`index.html` のある場所）で次を実行し、`http://localhost:8000/video/` を開きます。横は `http://localhost:8000/video/index.html?layout=wide` です。

```text
python -m http.server
```

- 「再生」「一時停止」「先頭へ」と時刻のスライダーで確かめます。再生は押したときだけ始まり、最後まで行くと「もう一度再生」になります。スライダーを動かすと一時停止して、その時刻の画を描きます。
- 「場面へ移動」で各場面の読みやすい時刻へ移ります。
- 「素材と出典」で7素材の照合結果（一致・不一致・照合前）を見られます。

## 照合と失敗時

`video.js` は `assets/manifest.json` の SHA-256 を固定値 `10c7aed7d3f649f2522823957529e8f7a45c3e2b36777a2a3d1cf352d1c9fdca` と比べ、並ぶ7素材のバイト数と SHA-256 をすべて確かめます。続いて、元の実行記録の形式・Mem0 の固定版（コミット・SDK 2.2.1・156ファイルのロック）・埋め込みモデルの固定版（384次元・CPU）・infer=False・通信の試み0件・LLM 呼び出し0回・別プロセスの記録・入力3件の SHA-256・M01〜M08 の8件、samples.json の8件が記録と同じ値であること、時刻表（32秒・30fps・960フレーム・無音・6場面）を確かめます。図に出すタイルの見出し・順位・ID・件数・20→30・履歴は、この記録から読みます。

どれかが合わなければ、キャンバスを隠して操作を止め、理由と「もう一度読み込む」を表示します。内蔵の代わりのデータは使いません。

## 時間の契約

- `window.motionConfig = { duration: 32, fps, width, height, posterTime: 16, audioEvents: [] }`。`window.renderConfig` の幅・高さ・FPS を初期化時に反映し、縦か横かで配置を選びます。
- `window.seek(t)` は時刻 t だけから完成した画を描きます。呼ぶ順番・壁時計・前のフレーム・乱数には依存しません。
- `window.motionReady` は、フォントの読み込みと7素材・記録の照合が終わると解決し、失敗すると拒否されます。
- `window.__MOTION_RENDER__` が真なら、編集画面の部品を隠し、プレビューの再生を止め、同じキャンバスだけを書き出し用の大きさで表示します。

## 書き出し

作例のフォルダーで、同梱の `render.py` を使います。Node.js 20 以上・Chrome・FFmpeg と ffprobe、`tools/motion-reel/` のレンダラーの依存（その隣で `npm install --ignore-scripts`）が必要です。出力はソースの外の、空のフォルダーを指定します（既存の書き出しは上書きしません）。音源や `--audio` は渡しません。

```text
python render.py --out ../render-portrait --width 720 --height 1280
python render.py --out ../render-wide --width 1280 --height 720
```

`render.py` はソースを一時フォルダーへ写し、そこで `video/index.html` を描きます。静止画だけなら `--stills-only` を付けます。

## 範囲

- 図は、制作時に原典の Memory API と埋め込みモデルが返した保存済みの結果の説明です。ライブの実行や会話の録画ではありません。
- タイルの短い言葉は保存した本文を縮めた見出しです。けんの K02 の本文「ナレーション付き・60秒程度」は架空の好みの値で、「語り60秒」と表示しています。この映像にナレーションはありません。
- 順位だけを示し、Mem0 スコアを確率として扱いません。user_id による分離は検索範囲の指定で、認証ではありません。削除は一覧・取得・検索から外す操作で、履歴は残ります。物理的な消去は確かめていません。
- 開き直しは、記録にある新しい Python プロセスでの読み直しを描いたものです。ブラウザーで再起動を再現したものではありません。

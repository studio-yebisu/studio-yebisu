好みを覚えて、次に引き出す。

架空の2人の好みを Mem0 のオープンソース版 Memory API に保存し、検索・明示的な更新・別プロセスでの読み直しを実行した記録から描く、28秒・無音の解説映像の編集元です。

0.0秒 / 28.0秒

スライダーでは、矢印キーで0.1秒、PageUp・PageDownで2秒、Home・Endで先頭・末尾へ移動します。自動では再生しません。

保存済みの記録と実画面を確かめています…

この映像が示すこと・示さないこと

  • 固定版 mem0ai/mem0（0724291・SDK 2.2.1・Apache-2.0）のオープンソース版 Memory を改変せずに使い、7件を infer=False で渡した文のまま保存した記録です。LLMによる要点の抽出・重複の統合・回答の生成は使っていません。Mem0 Platform・プラグイン・アカウント連携もありません。
  • ベクトルは固定版の多言語埋め込みモデル（e8f8c21・384次元）が手元のCPUで計算しました。文章を書くモデルではありません。保存先は埋め込み型の Qdrant と SQLite です。
  • Memory は設定上LLMのクライアントを必ず作るため、公式の Ollama 設定を閉じたポートに向けて置き、一度も呼んでいません。モデルのサーバーも動かしていません。
  • 検索の filters={"user_id": ...} は検索範囲の指定で、認証や権限の仕組みではありません。映像では検索スコアを省いています（全文と値はサイトで読めます）。
  • 20秒から30秒への書き換えは、実行スクリプトが Memory.update を明示的に呼んだものです。Mem0 が自動で判断したのではありません。
  • 削除（M06）は映像では扱いません。削除した記録は取得・一覧・検索から外れますが、SQLite の履歴には残ります。物理的な消去は確かめていません。
  • 検索の質・認証・プライバシー・速さの評価ではありません。実行時間も映像に出しません。
  • 映像は保存した実結果と実画面の静止画を編集したもので、APIの実行や操作の連続した録画ではありません。記録カードは保存した値を描き直したもので、実画面の画素は等倍の切り抜き以外に手を加えていません。このページでも映像でも、Mem0・Python・AI は動きません。

照合してから使うファイル

照合表 assets/data-hashes.json の生のバイト列を制作記録の SHA-256 で確かめ、そこに書かれた8ファイルの生のバイト列を照合してから描きます。合わなければ理由を出して止まり、代わりの映像は描きません。

# 無音32秒の構造図（編集用ソース）

SolidCraft が何でできていて、AIとツールに何を渡し、何が出てきて次に何に使えるかを、1枚のつながった図が動いて見せる動画のソースです。音声・ナレーション・読み上げはありません（`audioEvents: []`、音声トラックも作りません）。

- 縦 720×1280 と 横 1280×720。同じ時刻の流れを、それぞれの向きで配置し直して描きます（縮めた縦長を横に置くのではありません）。
- 32秒・30fps・ポスターは31秒。
- 元の制作の28秒の紹介動画（`legacy.html`・`legacy.mp4`）とは別のものです。どちらもそのまま残しています。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | プレビューと書き出しの入口。`canvas#film` と操作の欄 |
| `video.js` | 時刻の契約（`motionConfig`・`motionReady`・`seek`）とプレビューの再生 |
| `video.css` | プレビューの見た目。書き出しでは canvas だけを原寸で表示 |
| `storyboard.json` | 7つの場面の「伝えること・入る状態・出る状態・動き」 |
| `../concept.js` | 構造図ページと共通のローダー・検証・描画（`sceneAt(t)`・`drawConcept`） |

図に使うデータは、隣の作例フォルダーにある保存済みの31ファイル（`../concept/manifest.json` に一覧）だけです。描く前に、manifest 自体のSHA-256と、31ファイルそれぞれの大きさ・SHA-256を確かめ、PNG 4枚を展開します。1つでも合わなければ描かずに止まります。CAD・AI・寸法の再計算、外部の通信・フォント・音声は使いません。

## 7つの場面

| 秒 | 場面 | 動くもの |
|---|---|---|
| 0 | 手順書と依頼 | 3冊のページと依頼の紙が、同じ作者AIへ |
| 4 | 作者と制作担当 | 作者がコマンドと予測値を別々に書き、コマンドだけが制作担当（別工程）からCADへ |
| 8 | 値→式→履歴→形 | 名前付きの値6つ→式→順番どおりの履歴3つ→ボディ1つ（模式図が箱→くぼみ→穴） |
| 14 | 4つの値を変える | 4つの札が同じ式の線を通り、同じ形が変わる。壁と底の3 mmは固定、穴は中央 |
| 20 | 予測と実測 | 予測値（CADの外）と実測（CADから）が照合で合う。端点の往復11状態・6形 |
| 26 | 3形式とビューア | JSON（正本）・STEP・STLに分かれ、保存結果ビューアで実PNG |
| 29 | 全体図 | 止まった全体図 |

詳しくは `storyboard.json` にあります。場面の時刻は `../concept.js` の `FILM_SCENES` と `sceneAt(t)` が正本です。時刻を変えるときは両方を合わせてください。

## 図の約束

- トレーの絵は「模式図」と表示した説明用の絵です。CADが出力した画像ではありません。存在しない途中のCAD画像は描きません。
- 実PNGは元の制作で保存した4枚のうち等角の2枚を、ビューアの同じ枠の中で重ねて切り替えます。各画像は個別に自動フィットしているので、拡大・変形して寸法の差に見せることはしません。大きさの差は数字で示します。
- 値の数字は端点（120→150 など）だけを出し、途中の数字は出しません。確かめたのは範囲の端と初期値を往復した11状態（6種類の形）だけです。
- 1 mmの工具のはみ出しは、面が一致するのを避けるためのもので、材料としては描きません。
- MCPの25本の目盛りの点灯は、作る3段と変更1回の流れに合わせた説明の並びで、元の実行の時刻ではありません。

## プレビュー

`video/` だけを別の場所へ写すと `../concept.js` と素材が見つかりません。作例フォルダー（`video/` の1つ上）をローカルのWebサーバーで開いてください。

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
# http://127.0.0.1:8000/video/index.html （横向きは ?orient=wide）
```

- 「縦」「横」のボタンで向きを切り替えます。ほかのボタンは向きを変えません。
- `#time` は0〜32秒を0.1秒刻みで動かせます。7.2秒のような任意の時刻もそのまま描けます。
- 場面のボタン（0・4・8・14・20・26・29秒）、再生・最初へ・最初から再生・最後へ。
- 動きを減らす設定では自動では動きません。

## 時刻の契約（書き出し用）

- `window.motionConfig = {duration: 32, fps: 30, width: 720, height: 1280, posterTime: 31, audioEvents: []}`。`window.renderConfig` に `width`・`height`・`fps` があればそれを使い、`motionConfig` にも同じ値を入れます。
- `window.motionReady` は、フォントの準備・31ファイルの検証・PNG 4枚の展開が終わると解決し、どれかが失敗すると reject します。失敗したら canvas を消し、操作を止めます。
- `window.seek(秒)` はその時刻の画を背景から描き直します。前に描いた画・呼んだ順番・壁時計・fps には左右されません。乱数・タイマー・CSSアニメーションは使いません。検証が終わる前は reject します。
- `window.__MOTION_RENDER__` が真なら、操作の欄と説明文を出さず、プレビューの再生（requestAnimationFrame）を動かしません。

書き出しは Motion Reel のレンダラーで親工程が行います（未実行）。レンダラーは作例フォルダー全体を配信し、この `video/index.html` を開く必要があります。縦 720×1280 と横 1280×720 の2本を、音声なしで書き出す想定です。

## 実データと保存形式

- 設計の `.json`（`outputs/tray-default.json`・`tray-resized.json`）は編集できる正本で、6つの値・式・3つの履歴が残ります。
- STEP は別のCADへ渡すための形で、開くと基礎の固体1つになり、式は残りません。STL は三角形のメッシュで、式も履歴も残りません。
- 元の制作の再現手順（CLI・MCP・チェッカー）は作例フォルダーの `README.md` にあり、この動画のために変更・再実行はしていません。

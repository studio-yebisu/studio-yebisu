# 解説動画のブリーフ：寸法を4つ変えても、穴は中央、壁は3 mmのまま

Motion Reel の「ブリーフ」と「時間の契約」に沿って書いた、28秒の音声なしの解説動画です。ソースは同じフォルダーの `index.html` です。

## 目的

| 項目 | 内容 |
|---|---|
| 残す一文 | 名前の付いた寸法を変えると SolidCraft が形を計算し直し、穴は中央、壁は3 mmのまま。それを実測で確かめ、編集できる設計・STEP・STL で保存した。 |
| 視聴相手 | CAD を AI のエージェントやスクリプトから動かしてみたい人。CAD の専門家でなくてもよい。 |
| 次の行動 | 作例のページで2つの状態を見比べ、ファイルと再現手順（README）を開く。 |

## 事実と出典

- 寸法・体積・外接箱・確認の件数・ファイル名は、すべて `../measurements.json` から読みます。動画の中に数値を直接書いていません。
- 画像は SolidCraft 0.11.1 の MCP の `screenshot`（`source: model`、1280×960）で撮った `../renders/` の4枚を読み込み、映像には初期の等角、変更後の等角と上面の3枚を、加工せずに使います。CAD の形を描き直した図や、作り物の端末画面は使いません。
- 上面の画像に重ねる朱色の丸と枠は、`measurements.json` の `top_image_checks`（画像の線の位置）から置く「印」で、形の代わりではありません。
- 画像は状態ごとにモデルへ合わせて収められているため、画像の大きさの変化を寸法の変化の証拠として動かしません。2つの画像は同じ枠に置き、大きさは数値で比べると画面に書きます。
- 確かめていないこと（製造・強度・3Dプリントの品質）は最後の場面に書きます。

## 見た目

- Studio Yebisu の紙 `#f2eee3`・墨 `#17150f`・朱 `#ff4f00`（文字には濃い朱 `#a83500`）。
- 書体は OS の明朝とゴシックだけ。Web フォントは読み込みません。
- 見出しは2行以内、本文と字幕は24px以上。1つの場面で伝えることは1つ。

## 出力

1280×720、30fps、28秒、音声なし（`audioEvents: []`）、ポスターは12秒。`window.renderConfig` の幅・高さ・FPS を反映し、縦長のサイズでは画像を上、文字を下に並べ直します。

## 時間の契約

- `window.seek(秒)` は、その時刻の画面を毎回すべての要素について計算し直して描きます。前の呼び出し・タイマー・CSS のアニメーションやトランジション・壁時計を使いません。
- `window.motionReady` は、フォント、`../measurements.json` の読み込みと検証、4枚の PNG のデコード（各1280×960）を待ちます。どれかが欠けたり大きさが違ったりした場合は失敗し、代わりの図は描きません。
- `window.__MOTION_RENDER__` が真のときは、プレビューの再生と操作の欄を出しません。

## 制作担当による確認結果

28秒・1280×720・30fps・無音の実MP4を出力し、コンタクトシート、代表フレーム、連続フレームと、ブラウザーで終端28秒までの再生を確認しました。16.8秒は任意順と新しいページで同じPNGになりました（同じ実行環境内）。実CADの画像と実測JSONのハッシュも照合しています。自動検査と制作担当による画面確認で、人による承認ではありません。

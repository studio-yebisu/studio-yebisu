保存する形式

「保存」は、読み込み時に大きさとSHA-256を確かめた元のファイルを、そのままブラウザーの保存処理へ渡します。中身を書き直したり、新しく作り直したりはしません。ディスクへの保存が終わったかどうかは、このページからは分かりません。

2つの役割と3つの手順書

作者AI（Claude Opus 5.5）

3つの手順書と依頼を読み、寸法・体積・重心を先に計算した計画（cad/plan.md）、作るコマンド（build.json）、4つの値を変えるコマンド（resize.json）、範囲の端を往復するコマンド（walk.json）、予測値（expected.json）と独立したチェッカー（check_design.py）を書きました。作者AIはCADを実行していません。

制作担当（別工程）

SolidCraft 0.11.1 を画面のない headless の MCP stdio で起動し、元の制作で回の操作（batch 回＝作る段＋変更回）を送りました。CLI・原典の run.py・独立チェッカーも別に実行しています。共有のGUIやほかの設計には接続していません。MCPはエンジンのコマンドを送る仕組みで、遠くのAIに形を作らせるものではありません。今回の図の制作では、CAD・MCP・チェッカーを実行し直していません。

AIが読む3つの手順書（SKILL.md）

  • solidcraft-modeling：数値を先に決め、少ない batch と段ごとの measure で新しい部品を作る。
  • solidcraft-editing：保存した設計の値を変え、作り直さずに同じ履歴で計算し直す。
  • solidcraft-checking：SolidCraft が報告しない誤りを、別の根拠（解析値・範囲の端の往復）で調べる。

SolidCraft は AI モデルでも、形を生成するホスト型のAPIでも、3つの別々のAIでもありません。Rust で作られたパラメトリック3D CADアプリで、headless の CLI と MCP サーバーを持ち、AIが読む Markdown の手順書を同梱しています。

確かめたこと・確かめていないこと

  • 作る3段外形の箱・くぼみ・中央の穴を段で作り、段ごとに測った値を予測値と比べた（元の制作）。
  • 変更は1回保存した初期の設計へ parameters.change を4つまとめて送った。形は作り直していない。壁と底の3 mmは固定のまま。
  • 予測と実測初期は実測 mm³・解析 mm³、変更後は実測 mm³・解析 mm³。外接箱は 120×80×18 → 150×90×24 mm。許容差は実行の前に決めたもの（measurements.json）。
  • 範囲の端だけ各値を上の端へ動かして戻し、最後に4つ同時に動かして戻した状態（種類の形）。途中の値・ほかの組合せ・壁や底の変更は試していない。範囲はコメントで、CADは強制しない。
  • 開き直し保存した JSON・STEP・STL のファイルを 0.11.1 で開き直し、ボディ1つを確かめた。
  • まだ製造・強度・3Dプリントの品質・水はけ・人による承認は確かめていない。

    図を文章で読む

    1. 手順書3冊（solidcraft-modeling・solidcraft-editing・solidcraft-checking）と架空の依頼（初期 、変更後 ）が、同じ作者AIへ渡る。
    2. 作者AIは、コマンド（build・resize・walk の JSON）と、それとは別の予測値（expected.json と check_design.py）を書く。CADは動かさない。
    3. 制作担当が別工程で、headless MCP stdio の回の操作と CLI・原典 run.py・独立チェッカーを実行した。
    4. CADの中：名前付きの値6つ（変える4つ：幅 width・奥行 depth・高さ height・穴径 hole_diameter／固定2つ：壁 wall・底 floor_thickness、どちらも3 mm）が式を通り、順番どおりの履歴3つ（TrayBlock 新規ボディ、Pocket 切り取り、DrainHole 切り取り）がボディ1つ（Tray）を作る。
    5. 4つの値を変えると、同じ式と同じ3つの履歴でボディが計算し直される。コマンドで作り直さない。穴は中央のまま、壁と底は3 mmのまま。
    6. 予測値と実測（measure・inspect）を別々の道で照合する。範囲の端の往復は状態・種類の形だけ。
    7. 同じ設計はJSON（値・式・履歴が残る正本）に、形だけがSTEP（CAD受け渡し）とSTL（三角形メッシュ）に残る。保存結果ビューアで実際のPNGを開ける。

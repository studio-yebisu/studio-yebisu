6つの部品

今回の使い方を説明するための整理で、公式の部品の区分ではありません。それぞれ固定版の原典の該当行を引用しています。

だれが何をしたか

  1. 作者AI（Claude Opus 5.5）：実行用の Python スクリプト run_example.py、3件の入力 jobs.json、実装計画を書きました。推論の実行や試聴はしていません。
  2. 制作担当：専用の環境と固定版の重みを別に用意し、元の Python API で from_local を1回、generate を3回呼びました（—・CUDA・—スレッド）。固定版の照合の入力を同梱の場所へ移すなどの包装の補正は制作担当が別に記録しており、作者の作業ではありません。
  3. ブラウザー：保存した26ファイルを確かめて読み、図を描き、実WAVを再生・保存します。音声の合成はしません。

実際に返った3本

3件とも同じ seed（20261019）で、一度ずつ合成しました。default と expressive は同じ文で、exaggeration と cfg_weight の2つを同時に変えた対の比較です。どちらか一方の効果、品質の順位、感情表現、別の機械での再現を示すものではありません。

項目defaultexpressivesecond

次に使う

  1. 聞く：上の3つのボタンで選び、標準の再生ボタンで聞きます。選び直すと再生は止まり、頭へ戻ります。
  2. 比べる：default と expressive を続けて聞き、同じ文で2つの設定を同時に変えたときの違いを確かめます。
  3. 保存する：「WAVを保存」で、確認済みの元のWAV（PCM16・24kHz・モノラル）をそのままブラウザーへ渡します。
  4. 使う：音声編集ソフトや動画編集に読み込み、英語の案内音声の下書きとして使えます。音量を整えるなどの加工は使う側で行います。WAVには Perth の透かしが入っています。

確かめたこと・まだ確かめていないこと

  • 表示する前に、一覧（manifest）のSHA-256と、—ファイルそれぞれの大きさとSHA-256を確かめ、3本のWAVの見出し・長さ・振幅の包絡と原典の引用行を照合しています。1つでも合わなければ図も音声も出しません。
  • 固定版：原典 resemble-ai/chatterbox 5de7a54（0.1.7、MIT）、重み ResembleAI/chatterbox 5bb1f6e（公開・ゲートなし、MIT）、Perth ff1c8ac。重み —ファイル・合計 —バイトは同梱しません。
  • Perth：導入した —ファイル（同梱の重みを含む）を照合し、—件は生のバイトが一致、—件は改行（CRLF）だけを直すと一致しました。生のバイトが22件とも一致したのではありません。公開した抜粋は公式の LF のままです。
  • WAV への変換：返った値を [-1, 1] で切り詰め、×32767・偶数丸めで int16 にしています。second は1サンプルが上限32767に達しました。WAVは正規化・修正せず、そのまま置いています。この1サンプルは、聞こえる不具合や品質を示すものではありません。
  • 透かしは各ジョブで1回かかり、前後のハッシュが違うことを確かめました。透かしの検出や耐性は試していません。
  • 環境：Python —・torch —。1回ずつの時間は記録していますが、速さの目安ではありません。

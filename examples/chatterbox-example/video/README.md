# 無音32秒の構造図（編集用ソース）

Chatterbox が何でできていて、何を渡し、何が返るかを、1枚のつながった図が動いて見せる動画のソースです。音声・ナレーション・読み上げ・効果音はありません（`audioEvents: []`、音声トラックも audio 要素もありません）。

- 縦 720×1280（優先）と 横 1280×720。同じ時刻の流れを、それぞれの向きの配置で描き直します（縦長を縮めて横に置くのではありません）。
- 32秒・30fps・ポスターは31秒。29.4秒以降は完全に静止し、30〜32秒は同じ画です。

## Opus 執筆時点の確認状態

**執筆後に制作担当が描画と確認を行いました。** 縦横32秒・960フレームの無音MP4、代表16コマと連続12コマ、通常プレビューとMP4の自然終端を確認しました。人の審美的承認や実機iOSでの確認ではありません。詳細は `../visual-verification.json` にあります。

実際の音声合成は、この動画とは別に済んでいます。制作担当が元の Python API で `from_local` を1回、`generate` を3回呼び、3本の WAV を保存しました。この動画はその保存データを描くだけで、合成を動かしません。3本の WAV を人が聞いて確かめたことはありません。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | プレビューと書き出しの入口。`canvas#film` と操作の欄 |
| `video.js` | 時刻の契約（`motionConfig`・`motionReady`・`seek`）とプレビューの再生 |
| `video.css` | プレビューの見た目。書き出し（`body.render`）では canvas だけを原寸で表示 |
| `storyboard.json` | 7つの場面の秒・伝えること・入る状態・出る状態・動き |
| `../concept.js` | 構造図ページと共通のローダー・検証・描画（`loadConcept`・`sceneAt(t)`・`drawConcept`） |

図に使うのは、作例フォルダーの保存済み26ファイル（`../concept/manifest.json` に一覧）だけです。描く前に、manifest 自体の SHA-256（`f145d0fc…df664`）と、26ファイルそれぞれの大きさ・SHA-256 を確かめます。続けて、3件の文・設定・seed、ID の数、WAV の形式とピーク、原典の引用行を照合し、3本の WAV の PCM から240区間の包絡を計算し直して `concept/waveforms.json` と比べます。1つでも合わなければ描かずに止まり、再読み込みのボタンを出します。外部の通信・フォント・音声・推論は使いません。

## 図の約束

- 場面の秒数と動く印は説明の演出です。実際の読み込み・推論・透かしの時間には対応させていません。
- 数値（語数・文字ID数・音声ID数・長さ）と WAV の包絡は保存データから描きます。包絡は振幅の最小・最大で、スペクトログラムや注意の地図ではありません。カードの中の包絡の長さは、3本の実際の長さの比です。
- 文字ID と音声ID は別の箱・別の色で描きます。どちらも単語・確率・点数ではありません。目盛りの本数は実際の個数です。
- 「メル→波形」の段（CFM とボコーダー）は原典に基づく説明で、内部の各ステップは計測していません。注意や内部の活性は描きません。
- 組み込み条件は「組み込み条件のみ」と書き、別の参照音声を渡していないことを示します。声の持ち主や人の声との関係を示す絵（顔・人物・声のアイコン）は描きません。
- 品質・感情・自然さの優劣を示す表示はありません。

## プレビュー

`video/` だけを別の場所へ写すと `../concept.js` と素材が見つかりません。作例フォルダー（`video/` の1つ上）全体をローカルの Web サーバーで開いてください。

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
# http://127.0.0.1:8000/video/index.html （横向きは ?orient=wide）
```

- 「縦」「横」のボタンだけが向きを変えます。ほかのボタンは向きを変えません。
- `#time` は0〜32秒を0.1秒刻みで動かせます。7.2秒のような任意の時刻もそのまま描けます。
- 場面のボタン（0・4・8・13・18.5・23.5・28.5秒）、再生／一時停止・最初へ・最初から再生・最後へ。
- 「明」「暗」はプレビューの色だけを変えます。書き出しは明るい色で描きます。
- 自動では再生しません。動きを減らす設定に変わると再生を止めます。

## 時刻の契約（書き出し用）

- `window.motionConfig = {duration: 32, fps: 30, width: 720, height: 1280, posterTime: 31, audioEvents: []}`。初期化の前に `window.renderConfig` の `width`・`height`・`fps` があればそれを使い、`motionConfig` にも同じ値を入れます。幅が高さより大きければ横の配置で描きます。
- `window.motionReady` は、フォントの準備と26ファイルの検証・中身の照合が終わると解決し、どれかが失敗すると reject します。失敗したら canvas を消し、操作を止めます。
- `window.seek(秒)` は Promise を返し、その時刻の画を背景から描き直します。前に描いた画・呼んだ順番・壁時計・fps には左右されません。乱数・タイマー・CSS アニメーション・前のコマの積算は使いません。検証が終わっていなければ reject します。
- `window.__MOTION_RENDER__` が真なら、操作の欄と説明文を出さず、プレビューの再生（requestAnimationFrame）を動かしません。canvas は要求された大きさのまま、余白とスクロールバーなしで表示します。

## 書き出し（制作担当による再現用ラッパー）

作例フォルダー全体と同梱の `render-runtime/` を使います。Node.js 20以上、Python 3、Chrome、FFmpeg/ffprobeが必要です。`render-runtime/` で `npm ci --ignore-scripts` を行い、作例フォルダーのルートから次を実行します。出力先はソースの外の新しい空フォルダーにします。

```text
python render-visual.py --out <NEW_OUT>/portrait --width 720 --height 1280
python render-visual.py --out <NEW_OUT>/wide --width 1280 --height 720
```

`--stills-only` は代表と連続コマのみ、`--strip-at 14.4` は連続コマの開始秒です。ラッパーは作例フォルダーを一時コピーし、編集HTMLを入口へ置き、相対URLを保って描きます。直接レンダラーへ作例ルートを渡すと紹介ページを開くため、このラッパーを使います。音声の指定はなく、TTS・ASR・モデルのダウンロードも呼びません。実際の確認は、既存の同じレンダラー依存を使った同一Windows環境で行っています。新しい環境での npm 導入や同じフォントの表示を保証するものではありません。

公開動画は `media/chatterbox-example.mp4`（縦）と `media/chatterbox-example-wide.mp4`（横）、ポスターは `media/chatterbox-example.webp` です（サイトルート基準）。`review/portrait/` と `review/wide/` に代表・連続コマと描画記録を置いています。ソースから再描画した62PNGの全バイト一致と30/31秒の静止を別に確認しています。

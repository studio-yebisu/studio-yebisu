      このページで動いているもの
      
      
      制作側が node run.mjs で実行して保存した outputs/automation-runs.json を読んで表示するだけです。ブラウザーの中で Agent Canvas・エージェント・AI は動きません。表示の前に、入力2ファイルとロックの SHA-256、固定版、8件の入力と記録の一致、形が通った数と止まった数、確認の合否を照合し、合わなければ結果を出しません。
      
      
        
        
      1. 設定を書く　名前・きっかけ（時刻か event）・prompt・参照先など
        2. 
        
      2. 書き出す　serializeAutomation が持ち運べる .automation.json の形にする
        3. 
        
      3. 読み戻す　parseAutomationFile が形を確かめ、通らなければ誤りの一覧を返す
        4. 
        
      4. 直して再確認　O03 と O04 のように、誤りの1か所だけを戻して通るか見る
        5. 
        
      5. 保存する　形が通ったファイルを、そのまま .automation.json で保存
        6. 
      
      
    
      

    
      
      
      「形が通った」は「動く」ではない
      
      
        
        
      • 6件が通ったのは、ファイルの形の検査です。動く自動化が6件できたわけでも、予定を登録したわけでも、品質の点数でもありません。
        • 
        
      • O06：parseAutomationFile は schedule が空でない文字列かだけを見ます。not-a-cron でも通り、cron の書き方や、実際にいつ動くかは確かめていません。
        • 
        
      • O07：書き出すファイルに入る参照先は先頭の1件だけです。2件目は落ち、古い repository・branch も先頭の値で上書きされます。参照先が複数ある設定の完全な控えにはなりません。
        • 
        
      • 形が通った6件はすべて enabled: false（無効）のままです。O05 の "false" は文字列なので止まりました。
        • 
        
      • 参照先の example.invalid はすべて架空で、取得していません。通信・ログイン・API キー・外部サービスは使っていません。
        • 
        
      • O08 のタグや波かっこは、このページでもただの文字として表示します。安全性や内容の正しさを確かめたものではありません。

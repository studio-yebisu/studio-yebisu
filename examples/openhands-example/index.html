    この作例で確かめた範囲

    Agent Canvas の自動化は「いつ動くか（きっかけ）」「何を頼むか」「どの参照先を見るか」などの設定です。別の環境へ持ち運ぶときは .automation.json というファイルになり、読み込むときに形式が点検されます。この作例は、その書き出しと読み込みだけを原典の関数そのもので試したものです。

    8件のうち6件が形式OK、2件が止まりました。形式OKは、ファイルの形の点検を通ったという意味です。時刻（cron）の書き方が正しいか、実際にいつ動くか、参照先が存在するか、頼む内容が正しく安全かは確かめていません。形式OKの6件はすべて無効（enabled: false）のままです。

    参照先が複数ある設定を書き出すと、ファイルに入るのは先頭の1件だけです（O07）。複数の参照先の完全な控えにはなりません。参照先はすべて架空の example.invalid で、取得していません。

    Agent Canvas のアプリ・サーバー、エージェント、モデル、予定の登録と実行、Webhook の配信、リポジトリの取得、OpenHands Cloud は使っていません。OpenHands の機能全体を試したものではありません。

    確認：記録の自動確認107件、別に書いた Python の照合155件（independent-checks.json）、新しい Node のプロセスで記録と6つのファイルが1バイトも違わずに再現（reproduction-checks.json）。実機の iPhone・Safari での確認と、人による内容の承認は記録にありません。

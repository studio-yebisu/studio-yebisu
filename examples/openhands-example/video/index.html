      固定版 OpenHands/OpenHands（コミット e4775b4ba61a83ba80af5f7b0b826201b8e8ea05・Agent Canvas 1.27.1）の、改変していない serializeAutomation・getAutomationExportFilename・parseAutomationFile・AutomationFileValidationError と、hasAutomationInterface・getImportExportSpec を Node v24.18.0 で呼び、架空の8つの設定を書き出し・読み込みした記録です。ファイルの封筒は、原典の package-lock.json が固定する @openhands/extensions 0.30.0 の実物の interface manifest を、原典の審査が通したものです。

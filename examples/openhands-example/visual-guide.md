# 図で確かめ、設定を保存する

最初は時刻のないO03です。図の「時刻を戻す」を選ぶと、保存済みのO04に切り替わります。時刻だけを追加した入力が形式の点検を通り、実際のO04.automation.jsonを保存できます。この切り替えで原典APIを再実行しているわけではありません。

O06は時刻の書式を確かめない例、O07は2つある参照先の先頭だけが書き出される例です。残りを含む8件の入力・出力・エラー全文はcomparison.htmlから開けます。

動画は同じ設定ファイル・点検ゲート・保存ファイルの図を動かし、5区間の日本語TTSで説明します。33秒の縦版を主にし、横版も用意しました。説明図は編集された図形で、稼働中のエージェントやスケジューラーを録画したものではありません。

音声は固定版Irodori-TTS-v4.1-Smallによる合成ナレーションです。参照の声も私たちがcaptionから作った合成声で、実在者の録音ではありません。audio/script.jsonに原稿、audio/generation.jsonに固定版・生成条件と成果のハッシュ、video/assets/narration-cues.jsonに実際の時刻があります。学習済みモデルは配布していません。IrodoriのコードとモデルのMIT Licenseおよび同梱モデルカードの条件も参照してください。

## 確認した範囲

33秒・30fps・990フレームの縦版720×1280と横版1280×720を、実生成した日本語Irodori-TTSナレーション5区間と同じ時刻で書き出しました。代表・連続・スマホ幅・終端の画、別順序と新ページの同時刻PNG一致、全デコード、ブラウザーでのMP4再生終了と編集ソースの実音源再生・シークを確認しました。音声の聴取、人による承認、実機iOS/Safari/VoiceOverは未確認です。
